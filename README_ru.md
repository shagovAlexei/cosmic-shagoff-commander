# Shagoff Commander

[English](README.md) | Русский

Двухпанельный файловый менеджер в духе Total Commander на libcosmic для рабочего стола COSMIC (Pop!_OS 24.04).

![Shagoff Commander, классический облик](res/screenshots/classic.png)

**Статус:** активная разработка, используется каждый день. См. [.claude/docs/ROADMAP.md](.claude/docs/ROADMAP.md).

## Два облика

*Конфигурация → Настройки… → Вид* (Ctrl+,) — переключается сразу.

| Классический (Total Commander) | Современный (COSMIC) |
|---|---|
| ![Классический](res/screenshots/classic.png) | ![Современный](res/screenshots/modern.png) |
| Панель инструментов, список дисков, полоса вкладок и строка пути, плотные строки | Кнопки дисков, «хлебные крошки», панели-карточки, строки крупнее |

## Возможности

- Две панели с вкладками (блокировка, переименование, перенос между панелями), клавиши Total Commander: F3–F8, Shift+F5/F6, выделение Insert / Space / Num+ / Num−, быстрый поиск Alt+буква, история и избранное (hotlist)
- Копирование / перемещение / удаление с ответами на конфликты (заменить, пропустить, заменить более старые, переименовать, оставить оба), корзина или удаление насовсем, буфер обмена, совместимый с COSMIC Files
- Архивы как папки: zip, tar.gz / bz2 / xz / zst, 7z — просмотр, копирование внутрь и наружу, упаковка / распаковка
- Встроенный просмотрщик (F3): текст с переносом строк и кодировками (определяются сами: кириллические 1251 / KOI8-R / 866, западные, центральноевропейские, греческая, японские, китайские…), hex, картинки; быстрый просмотр в другой панели (Ctrl+Q), в том числе внутри архивов
- Поиск файлов (маски или regex, текст внутри, размер / дата, внутри архивов), сравнение и синхронизация папок, сравнение файлов бок о бок
- Свойства с битами прав, групповое переименование, командная строка `path>`, сетевые подключения через gvfs
- Терминал на выбор (Команды → Терминал…: системный или любой установленный) открывается в папке панели и выполняет Shift+Enter
- Встроенный терминал под панелями вместо командной строки (Ctrl+` или Вид → Встроенный терминал, по умолчанию выключен): ходит за папкой активной панели, Ctrl+O — на всё окно, оболочка — Команды → Оболочка…
- Правая кнопка отмечает файлы, как в Total Commander (протянуть по строкам — отметить их), удержание — меню (или меню сразу — настройка), полный / краткий вид, иконки типов файлов, два облика: Классический (Total Commander) и Современный (COSMIC)

## Кнопки панели инструментов

Правый клик по панели инструментов (классический облик) или *Конфигурация → Панель инструментов…* открывает редактор кнопок: добавить, удалить, переместить, выбрать иконку. Кнопка запускает внутреннюю команду (`cm_*`, выбирается из списка) или программу с параметрами:

| | |
|---|---|
| `%P` / `%T` | папка активной / другой панели |
| `%N` | имя под курсором; `%O` без расширения, `%E` расширение |
| `%S` | выделенные имена |

Каждое значение подставляется как одно слово оболочки. Команда выполняется через `sh -c` в папке панели, без терминала. Пример — терминал, который показывает файл под курсором и ждёт Enter:

- Команда: `cosmic-term -e`
- Параметры: `sh -c "ls -l %N; read x"`

Скрипт берите в двойные кавычки (подставленные имена несут свои одинарные), и пишите `read x`, а не голый `read`: `sh` — это dash, где `read` без переменной сразу падает, и терминал закрывается. Ошибка команды показывается в строке состояния.

## Установка

К каждому [релизу](https://github.com/shagovAlexei/cosmic-shagoff-commander/releases) приложен `.deb` для Pop!_OS 24.04 / Ubuntu 22.04 и новее (Mint 21+, Debian 12+; собран под glibc 2.35):

```sh
sudo apt install ./shagoff-commander_*_amd64.deb
```

Fedora / openSUSE: `.rpm` из того же релиза (`sudo dnf install ./shagoff-commander-*.x86_64.rpm`).
`man shagoff-commander` — запуск, файлы и главные клавиши.

## Обновление

Какая версия стоит: **Справка → О программе** или `dpkg -s shagoff-commander | grep Version`.
Кнопка **Проверить обновления** там спрашивает у GitHub последний релиз (только по нажатию).
Самая новая — на [странице релизов](https://github.com/shagovAlexei/cosmic-shagoff-commander/releases/latest).

Поставьте новый `.deb` поверх старого — настройки, вкладки и история сохранятся (они лежат в
`~/.config/cosmic/` и `~/.local/state/cosmic/`):

```sh
# скачать .deb последнего релиза
curl -sL https://api.github.com/repos/shagovAlexei/cosmic-shagoff-commander/releases/latest \
  | grep -o 'https://[^"]*_amd64\.deb' | xargs curl -L -o /tmp/shagoff-commander.deb
sudo apt install /tmp/shagoff-commander.deb

# или через GitHub CLI
gh release download -R shagovAlexei/cosmic-shagoff-commander -p '*.deb' -O /tmp/shagoff-commander.deb --clobber
sudo apt install /tmp/shagoff-commander.deb

# или из клона исходников
git pull && sudo just install
```

Потом закройте запущенный Shagoff Commander и запустите снова.
