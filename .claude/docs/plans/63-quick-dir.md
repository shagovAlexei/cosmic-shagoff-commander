# 63. План: Ctrl+Q на каталоге

Спек: `.claude/docs/specs/63-quick-dir.md`.

1. `quick_follow`: каталог → «Подсчёт…», `props::usage` в `spawn_blocking`, флаг остановки
   `quick_stop` заменяется при каждом переходе.
2. Размер — `view::human` (единицы из локали); в просмотре без содержимого нет кнопок режима.
3. Тест: «Подсчёт…» на каталоге, остановка при уходе, `..` — пояснение. Версия 0.7.0, документы.
