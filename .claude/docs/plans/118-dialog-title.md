# 118 — план

1. `dialogs::what_to(paths, to, field)`: столбец «имя (title4, Accent) / caption „в:“ + поле».
2. Input Copy / Move / Link, Pack, Unpack: заголовок — ключ действия, `control` через `what_to`.
3. i18n: `copy`, `move`, `link`, `to` вместо `*-to` (en, ru).
4. Иконка: `Dialog::sources`, в `App::dialog` — запись панели с этим путём → `view::entry_icon(e, 32)`.
