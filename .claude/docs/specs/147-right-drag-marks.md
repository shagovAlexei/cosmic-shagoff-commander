# 147 — Протягивание правой кнопкой отмечает

Бэклог («дальше» к 105). TC, «Выделение правой кнопкой»: зажать правую кнопку и провести по строкам — они отмечаются.

Решение пользователя: при включённом `right_marks` правая кнопка не начинает перетаскивание (72) — протягивание отмечает; перетаскивание правой — при выключенном.

- `Hold.drag: Option<(bool, usize)>` — состояние отметки и последняя строка. Первый уход со строки нажатия: протягивание, отметка = обратная той, что была у строки нажатия.
- Строки шлют `Message::RowEnter(side, i)` только пока зажата правая кнопка в этой панели (`view::row_area`, общий для таблицы, Brief и миниатюр).
- `Panel::mark_range(from, to, on)`: строки от последней достигнутой до текущей (быстрый рывок пропускает события строк), `..` никогда. Курсор — за указателем.
- При протягивании удержание не открывает меню, отпускание ничего не переключает.
- `dnd::drag_source(…, right, …)`: правое нажатие начинает перетаскивание только при `!right_marks`.
