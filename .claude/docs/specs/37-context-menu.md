# 37. Контекстное меню по правому клику

Статус: решения приняты сами (пользователь: «давай реализуем следующую фишку, pop up меню, вызов по правому клику мыши»).

## Решения

| Вопрос | Решение |
|---|---|
| Где | По правому клику в списке файлов (оба вида, обе темы) и по вкладке. Меню — `widget::context_menu` libcosmic как всплывающая поверхность Wayland (xdg_popup, `on_surface_action` → `cosmic::app::Action::Surface`). Вариант в окне (overlay) в этой ревизии libcosmic закрывается от нажатия левой кнопки раньше, чем срабатывает пункт |
| Закрытие окна | `on_close_requested` выходит только для главного окна: закрытие всплывающего меню приходит туда же и завершало приложение |
| Курсор и отметки | Правое нажатие на строке делает панель активной и ставит на строку курсор (как в TC с правой кнопкой «как в Windows»). Строка не отмечена, а другие отмечены — отметки снимаются (как в Проводнике: меню всегда о том, на чём щёлкнули). Строка отмечена — меню для всех отмеченных |
| Пункты на файле / каталоге | Открыть (Enter), Просмотр F3, Правка F4 · Копировать F5, Переместить F6, Переименовать Shift+F6, Удалить F8 · Вырезать Ctrl+X, Копировать Ctrl+C, Вставить Ctrl+V · Упаковать Alt+F5 (архив — Распаковать Alt+F9) · Каталог в новой вкладке Ctrl+↑ (каталог, архив), Свойства Alt+Enter. Не больше 12 пунктов — столько помещается в окно 530 px; Shift+F5, F9/F10 и Правка архива остаются в главном меню |
| На `..` и пустом месте | Новая папка F7, Вставить Ctrl+V, Перечитать Ctrl+R, Выделить всё, Найти файлы Alt+F7, Новая вкладка Ctrl+T |
| На вкладке | Правое нажатие выбирает вкладку; Новая вкладка, Перечитать, Копировать / перенести в другую панель, Закрепить (флажок), Переименовать…, Закрыть, Закрыть остальные |
| Клавиши в меню | Подписаны из той же таблицы, что и главное меню (`menu::table`); добавлены Enter и Ctrl+C / X / V |
| Логика | Пункт = тот же `Action`, что и клавиша (`Message::Key`) — новой логики нет |
| Строка или пустое место | Правое нажатие libcosmic не перехватывает: сначала строка шлёт `RightClick`, затем список — `RightEmpty` для того же нажатия; `RightEmpty` сразу после `RightClick` не сбрасывает меню строки |
| Проверка мышью | `headless.sh click X Y [right]` — виртуальная мышь (`vpointer`, протокол zwlr_virtual_pointer_v1) в невидимом sway; после отпускания сдвиг на пиксель: libcosmic раскладывает контекстное меню на следующем движении |

## Тесты

App: правое нажатие на строке — активная панель и курсор, отметки сняты, если строка не отмечена, и сохранены, если отмечена; на пустом месте — меню каталога; правое нажатие на вкладке выбирает её. Меню: пункты на файле / каталоге / архиве / пустом месте (по `Action`), клавиши пунктов совпадают с `keymap` (общий тест таблицы).
