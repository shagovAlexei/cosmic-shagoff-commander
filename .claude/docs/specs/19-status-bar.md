# 19. Строка состояния окна

Статус: решения приняты сами (пользователь: «давай дальше»; пункт бэклога «строка состояния внизу окна, что показывать — решим при проектировании»).

## Решения

| Вопрос | Решение |
|---|---|
| Где | Отдельная строка внизу окна, под F-кнопками (видна и когда F-кнопки выключены в настройках) |
| Слева: сообщения | Результаты действий: «Скопировано…», «Каталоги одинаковые», «Архив только для чтения», «Монтирование… / Подключение… / Отключение…», ошибки F3/F4/F7/операций/монтирования. Три вида: обычное (цвет текста), «идёт» (акцентный), ошибка (красный). Держится до следующего действия; «идёт» — до результата |
| Что остаётся в панели | Ошибка чтения каталога («не удалось прочитать …»): это состояние панели, а не результат действия |
| Справа: файл под курсором активной панели | Имя (у ссылки — `имя → цель`), размер в байтах с пробелами (у каталогов нет), дата, права `rwxr-xr-x (755)`, `владелец:группа`. Для `..` — пусто. Внутри архива — без владельца |
| Откуда владелец и цель ссылки | Читаются при чтении каталога (`Entry.owner`, `Entry.target`), а не при отрисовке: отрисовка не должна обращаться к диску (мёртвый сетевой диск). Имена — из `/etc/passwd` и `/etc/group` один раз при запуске; нет имени — число |

## Тесты

Core: разбор passwd/group; строка сведений (файл, каталог, ссылка, без владельца, `..`); `scan` заполняет владельца и цель ссылки.
App: «Скопировано» — обычное сообщение в строке окна, а не ошибка панели; «Монтирование…» переживает следующую клавишу, обычное сообщение — нет; ошибка чтения каталога остаётся в панели.
