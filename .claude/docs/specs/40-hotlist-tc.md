# 40. Избранное как в TC

Было: диалог-список с «Добавить текущий каталог» сверху, длинный путь переносился на две строки, управлять можно было только Delete.

Стало:
- Ctrl+D — как всплывающее меню TC: каталоги (название и путь в двух колонках, обрезка «…», разделители), черта, «Добавить текущий каталог», «Настроить…». Выделение — как курсор панели. ↑/↓ перешагивают разделители. Те же строки у Alt+F1/F2 и Alt+↓ (`dialogs::menu_row`).
- «Настроить…» (`hotlist.rs`, `Dialog::Hotlist(HotEdit)`): список слева; справа «Добавить», «Разделитель», «Удалить», «Вверх», «Вниз», «Сортировать»; внизу «Название», «Каталог» + «Текущий». Правится копия, OK сохраняет `config.hotlist`, Отмена/Esc — нет.
- Разделитель в конфиге — запись `name: "-"`, пустой путь (старые конфиги читаются как есть).
- `ListItem.mount: bool` → `ListItem.kind: Item { Dir, Mount, Sep, Add, Configure }`.

Не делаем: подменю, перетаскивание, горячие буквы `&`, команды кроме перехода в каталог.
