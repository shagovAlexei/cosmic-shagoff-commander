# 190. Размер эскизов и перечитывание

TC: `cm_ZoomIn`, `cm_ZoomOut`, `cm_ReloadSelThumbs`.

- `Config.thumb_size` (px, по умолчанию 96, от 48 до 256 шагом 32); `thumbs::size()` — глобальное значение, как переключатели core (ставит `set_core_switches`), от него размер ячейки, декодирования и запроса к внешнему эскизатору (не меньше 128).
- Вид: «Эскизы крупнее» / «мельче» (`ThumbZoomIn` / `ThumbZoomOut`), кнопки `cm_ZoomIn` / `cm_ZoomOut`; смена размера сбрасывает кэш эскизов и пересчитывает прокрутку по новой высоте ячейки. Клавиш у TC нет.
- «Перечитать эскизы выделенных файлов» (`ReloadThumbs`, `cm_ReloadSelThumbs`): убирает из кэша картинки отмеченных (или файла под курсором); `want_thumbs` делает их заново.
