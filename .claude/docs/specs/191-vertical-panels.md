# 191. Панели одна над другой

TC: `cm_VerticalPanels`.

- `State.vertical` (`App.vertical`): Вид → флажок «Панели одна над другой», кнопка `cm_VerticalPanels`. Левая панель сверху, правая снизу, высота поровну, зазор как у разделителя.
- Разделитель (фаза 201) тянется по высоте, двойной щелчок — пополам; линия между панелями рисуется. Не делаем: перенос вкладки перетаскиванием на другую панель в этом виде (нет `y` у события). Строка состояния — как была, итоги двух панелей рядом.
- «Панель на 100 %» сильнее: при ней видна одна.
