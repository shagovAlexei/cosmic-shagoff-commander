# 34. Свойства (Alt+Enter)

Статус: решения приняты сами (пользователь: «давай по плану идём всё что можно сделать»). Пункт tc-reference «Alt+Enter — Свойства (backlog)».

## Решения

| Вопрос | Решение |
|---|---|
| Что показывается | Отмеченные или файл под курсором (`Panel::targets`). Один объект: имя, тип (каталог / ссылка на … / MIME по расширению), дата изменения, владелец:группа. Несколько: «объектов: N». Всегда: размер, файлов и каталогов с вложенным — считается в фоне (`core::props::usage`, ссылки не раскрываются), закрытие диалога останавливает счёт |
| Права | Сетка 3×3 (владелец / группа / остальные × чтение / запись / выполнение): флажок стоит, если бит есть у всех объектов; различающиеся биты в строке `rw?r--r--` — `?`. «Применить» (или Enter) ставит или снимает ровно те биты, которые трогали, у всех объектов; остальные биты у каждого свои (замена трёхпозиционных флажков TC). setuid/setgid/sticky сохраняются, но не показываются |
| Порядок при рекурсии | Каталогу сначала добавляются биты, потом обрабатывается содержимое, потом снимаются биты (иначе снятие r/x закрыло бы содержимое); каталог, который не прочитать, — в списке ошибок |
| Рекурсивно | Флажок «И всё внутри каталогов», если выбран каталог. Ссылки не трогаются нигде (chmod изменил бы цель) |
| Владелец | Не меняется: chown требует root |
| Архив | Отказ («архив только для чтения»), как другие изменения без перепаковки |
| Ошибки | chmod в фоне; число неудач и первая из них — в строке состояния; обе панели перечитываются |

## Ядро

`props.rs`: `usage(paths, stop) -> Option<Usage>`, `mode(path)`, `chmod(paths, set, clear, recursive) -> Vec<(PathBuf, io::Error)>`. `format::mime_type(ext)`.

## Тесты

Core: размер дерева с петлёй-ссылкой, остановка; chmod меняет только переключённые биты у файлов с разными правами; рекурсия только с флажком, цель ссылки не меняется.
App: Alt+Enter на файле — биты и сведения, счёт запущен, устаревший результат счёта игнорируется, Enter применяет; на `..` — ничего.
