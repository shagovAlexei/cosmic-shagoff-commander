# 23. Синхронизация: зеркало и маска

Статус: решения приняты сами (пользователь: «продолжай» — следующий пункт бэклога «Синхронизация: режим «зеркало» (удалять лишнее), фильтр по маске, синхронизация с архивом»).

## Решения

| Вопрос | Решение |
|---|---|
| Объём | Зеркало, маска, удаление строкой. Синхронизация с архивом — нет (архив переписывается целиком на каждое изменение — фаза 21; для синхронизации это слишком медленно) |
| Зеркало (Asymmetric в TC) | Флажок «Зеркало: справа станет как слева». Левая сторона — источник: есть только слева, новее слева, новее справа, равная дата и другой размер → «→»; есть только справа → «✕» (удалить); файл против каталога или ссылки — без стрелки. Направление всегда слева направо (поменять — Ctrl+U) |
| Удаление | Новое действие строки «✕»: удалить ту сторону, где запись есть (только для односторонних строк). В корзину, не безвозвратно. Клик по стрелке перебирает то, что строке доступно: → ← ✕ пусто |
| Подтверждение | Если есть «✕», первое «Синхронизировать» превращает кнопку в красную «Удалить и синхронизировать» и показывает «В корзину: N»; второе нажатие запускает. Новое сравнение или клик по стрелке снимают подтверждение |
| Маска | Поле «Файлы (маска)», синтаксис Num+; применяется по Enter или «Сравнить». Только имена файлов; каталог, который есть с одной стороны, при маске раскрывается — в списке только подходящие файлы, недостающие каталоги создаются при копировании. Пусто, `*`, `*.*` — все. С зеркалом удаляются только подходящие под маску |
| Порядок | Копии вправо, копии влево, затем удаления |

## Тесты

Core: стрелки зеркала (только справа → ✕, новее справа → →, одинаковые и разные типы — без стрелки); `plan` кладёт удаления на существующую сторону; маска оставляет подходящие файлы и раскрывает односторонний каталог; клик перебирает доступные действия.
App: зеркало даёт «✕», первое «Синхронизировать» только просит подтверждения (само удаление в тестах не запускается — оно идёт в настоящую корзину), новое сравнение снимает его; маска ограничивает строки.
