# 138 — F3 / F4: причина, почему файл не открыть

F3 / F4 проверяли `exists()` и на любой неудаче писали «ссылка никуда не ведёт» — и для удалённого снаружи файла, и для файла в каталоге `r--`.

- `unopenable(file, name)`: `metadata` удалась — открываем; ссылка на несуществующее — `broken-link`; иначе `file-unreadable` с причиной от системы.
