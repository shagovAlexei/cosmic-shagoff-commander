# 131 — Alt+буква дописывает открытый быстрый поиск

Поле быстрого поиска открыто, но без фокуса (щелчок по строке пути): буквы приходят как клавиши, и любая клавиша, кроме ↑ / ↓, закрывала поле — Alt+буква начинала поиск заново.

- `Message::Key` при открытом поиске (не фильтре): `QuickSearch` поле не закрывает, `quick_search` дописывает букву к его тексту (нет совпадения — буква не берётся, поле остаётся).
