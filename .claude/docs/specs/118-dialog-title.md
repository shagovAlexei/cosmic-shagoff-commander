# 118 — Диалоги F5 / F6 / Alt+F5: имя отдельно от действия

Заголовок «Копировать <длинное имя> в:» сливался в одну строку текста. Теперь заголовок — только действие («Копировать», «Переместить», «Создать символические ссылки», «Упаковать», «Распаковать»), под ним имя (или «N файлов») крупно и акцентным цветом, слева иконка файла (из строки панели, без обращения к диску; у нескольких файлов её нет), ниже мелкая подпись «в:» и поле пути (`dialogs::what_to`).
