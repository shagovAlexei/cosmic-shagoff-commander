# 73. Цвета по типам файлов

Как TC «Конфигурация → Цвета → Цветовая схема по типам файлов»: имя файла раскрашивается по
первому подходящему правилу.

- Правило (`core::colors::Rule`): маска как у Num+ (`*.rs;*.toml`, пусто — любое имя), «для чего»
  (`What`: всё / файлы / каталоги / ссылки / исполняемые — файлы с битом `x`), цвет `#RRGGBB`
  (пусто — цвет акцента темы; неверный — правило пропускается). `pick` — первое подходящее.
- `Config.colors`; по умолчанию: ссылки — голубой `#33c7de`, исполняемые — оранжевый `#ff7800`.
- Палитра под полем цвета: 3 × 10 образцов (светлые / средние / тёмные оттенки палитры GNOME + цвет акцента, серые); щелчок ставит `#RRGGBB`. Переключатель «Названия»: поле показывает название цвета палитры («Оранжевый»), ввод названия (любой регистр) — его код; хранится всегда код.
- Окно «Конфигурация → Цвета по типам…» (`colorrules.rs`, как «Избранное → Настроить…»): список с
  образцами, Добавить / Удалить / По умолчанию / ↑ ↓, поля маски, «для чего», цвета; правит копию,
  сохраняет по OK.
- Под курсором и отмеченные строки — цвет подсветки; Brief — те же правила.

Не делаем: выбор цвета палитрой, фон строки, цвет по дате / размеру (TC умеет) — в ROADMAP.
