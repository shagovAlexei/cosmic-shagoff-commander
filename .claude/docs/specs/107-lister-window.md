# 107 — F3 в отдельном окне (как Lister в TC)

- F3 открывает просмотр в своём окне (900×650), панели остаются видны и работают. Окно: своя полоса заголовка — имя файла, перетаскивание, развернуть (двойной щелчок / кнопка), закрыть.
- Клавиши — окну в фокусе: в окне просмотра — клавиши Lister (поиск, N / P, 1 3 4, W, кодировки, Esc / Q / F3 — закрыть), в главном — панели. F3 в главном окне при открытом просмотре — показать новый файл в том же окне (как N / P), окно — на передний план.
- Закрыть окно (×, Esc, Q, F3) — просмотр закрыт; закрытие главного окна закрывает и просмотр.
- Настройка Ctrl+, → «Программы» → «Просмотр F3 в отдельном окне» (по умолчанию включена, как в TC); выключена — как до 107, вместо панелей. Ctrl+Q — всегда в панели.

Не делаем: несколько окон просмотра сразу (TC умеет), запоминание размера и положения окна.
