# 159. Правка текста в сравнении файлов

ROADMAP «Сравнение файлов, дальше: свободная правка текста». TC: в окне сравнения кнопка «Правка» —
текст можно менять прямо там, потом сохранить.

- Строки сравнения рисуются только видимые (виртуально), правка в них — сложна. Поэтому «✎ ←» / «✎ →»
  открывают текст стороны целиком в редакторе (`iced text_editor`, моноширинный) на месте её половины;
  в панели — «Готово» / «Отмена». «Готово» — текст меняется (`diff::edited`), сравнение заново, как
  после копирования блока: сторона «не сохранена», «Отменить» откатывает, «Сохранить» пишет. Esc —
  выйти из правки, окно остаётся.
- Переводы строк сохраняет редактор (у каждой строки свой).
- Кнопки — «✎ ←» / «✎ →» с подсказками; русские «↑ Пред.» / «↓ След.» короче — иначе «Закрыть»
  обрезалась на 1036 px.

## Не делаем

- Правку прямо в строках сравнения; редактор открывается в начале текста, не у текущего отличия.
