# 60. Очистка истории и «Помнить историю после перезапуска»

- **«Очистить»** — кнопка в окнах «История» (Alt+↓) и «История команд» (Alt+F8). Alt+↓: у вкладки
  остаётся только текущий каталог (Alt+← / → больше некуда); Alt+F8: история командной строки
  пустая. Окно закрывается.
- **«Помнить историю после перезапуска»** — переключатель в настройках (Интерфейс), по умолчанию
  включён. Выключен: история командной строки, команды «Другой программы…» и маски Num+ живут
  только до выхода; в файл состояния пишутся пустыми (сохранённое стирается сразу). Включили снова —
  текущие записываются.
- История каталогов (Alt+↓, Alt+← / →) и так не сохраняется между запусками.

Где: `core::history::History::clear`; `Config.keep_history`; `App::save_state`; `Message::ListClear`.
