# 104 — Эскизы (TC Ctrl+Shift+F1)

Третий вид вкладки рядом с Brief / Подробно: плитки с эскизами картинок.

- Ctrl+Shift+F1 (меню «Вид», F1-справка, кнопка `cm_SrcThumbs`) — эскизы; Ctrl+F1 / Ctrl+F2 — обратно. Вид у каждой вкладки свой и помнится (`PaneState.thumbs`).
- Плитки слева направо, сверху вниз; список прокручивается по вертикали (колесо, полоса). ← / → — соседняя плитка, ↑ / ↓ — ряд, PgUp / PgDn — экран рядов.
- Плитка: квадрат 96 px (эскиз с сохранением пропорций или крупная иконка типа), под ним имя в одну строку. Курсор, отметки, цвета, щелчки, перетаскивание — как у строк Brief.
- Эскизы делаются в фоне (`image`, с поворотом по EXIF, как в F3), не больше 4 сразу, только видимым плиткам. Кеш на время работы: путь → (mtime, эскиз); изменённый файл переделывается. Файл больше 64 МБ, svg, нераспознанный, внутри архива — иконка.

Не делаем: размер эскиза в настройках, кеш `~/.cache/thumbnails`, эскизы видео / PDF.
