# 184. Новый файл по шаблону

TC: `cm_EditFileMenu` («Choose from various file types to create a new file»). В Linux шаблоны — файлы каталога `XDG_TEMPLATES_DIR` (`~/Шаблоны`), как «Создать документ» в файловых менеджерах.

- Файлы → «Новый файл по шаблону…» (кнопка `cm_EditFileMenu`): `core::templates::dir` (`user-dirs.dirs`: `$HOME/…` или абсолютный путь; нет — `~/Templates`), `list` — файлы каталога без скрытых, по имени; каталог равен домашнему (так xdg-user-dirs пишет «нет») — шаблонов нет.
- Список (`ListKind::Templates`) → окно имени (`InputOp::FromTemplate`, по умолчанию имя шаблона) → `templates::create`: копия с правами шаблона (скрипт остаётся исполняемым), `create_new` (не поверх файла; при ошибке недописанный файл удаляется) → `load` с курсором на нём (из результатов поиска тоже).
- В редакторе не открывается: шаблон может быть не текстом (`.odt`); F4 / Enter — дальше.
- В архиве — отказ (`read_only`, как Shift+F4). Нет шаблонов — сообщение с путём каталога.
- Не делаем: подкаталоги шаблонов как подменю.
