# 45. Окно сравнения файлов как в TC

Ручная проверка (пункты 5, 14): окно непохоже на TC, нет «Перечитать» и «Отмена», строка путей далеко от текста.

- Сверху одна панель кнопок, как у TC: «Перечитать», «↑ Предыдущее», «↓ Следующее», «Блок →», «← Блок», «Сохранить»; справа «Закрыть» (= Esc, с предупреждением о несохранённом).
- Пути файлов — заголовками прямо над своей половиной текста (длинный путь обрезается с начала, имя файла видно).
- Под текстом: «Отличие i из N» / «Не сохранено» и флажки «Без учёта пробелов», «Без учёта регистра».
- Каждая сторона — своя прокручиваемая половина (как в TC): длинная строка не выталкивает второй файл за край. Прокрутка одной (вниз и вбок) двигает другую (`DiffScrolled(side, x, y)`); ширина содержимого одна на обе, чтобы одна не упиралась в край раньше другой.
- «Перечитать» (`Message::DiffReread`) читает оба файла заново, курсор на первом отличии; неактивна, пока есть несохранённое (иначе правка пропала бы молча) и пока идёт сравнение.

Не делаем: правку текста в окне, переключение текст/двоичный, синхронную прокрутку с выключением.
