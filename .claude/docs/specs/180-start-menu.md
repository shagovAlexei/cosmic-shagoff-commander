# 180. Меню «Запуск» (TC Start menu)

TC: `cm_UserMenu1…` (пункты меню «Запуск»), `cm_ChangeStartMenu` (его настройка). Пункт — название, команда, параметры, каталог запуска; как кнопка панели.

- В шапке меню «Запуск» (перед «Справкой»): «Изменить меню «Запуск»…», линия, пункты пользователя. Пустое — только первый пункт.
- Пункт — `ToolButton` (`config.start_menu`): `tip` — название в меню, `cmd` — программа или внутренняя команда `cm_*` (список, как у кнопок), `params` с `%P %N %T %S …`, `dir`. Разделитель — `toolbar::SEP`. Запуск — `App::run_button`, тот же путь, что у кнопок и F12.
- Правка — то же окно, что у панели инструментов (`ToolEdit::menu`): заголовок «Меню «Запуск»», поле «Название», без значков и «Сброса»; OK сохраняет `start_menu`, панель не трогает.
- Не делаем (позже, по запросу): подменю (`-Имя` / `--`, как в Ctrl+D), клавиши у пунктов (TC Shortcut) — свои клавиши (154) пока на пункты не назначаются.
