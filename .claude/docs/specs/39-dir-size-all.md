# 39. Размер всех папок (Alt+Shift+Enter)

TC: Alt+Shift+Enter считает размер всех папок текущего каталога.

- `Action::CountDirs`: Alt+Shift+Enter, меню «Файлы», контекстное меню каталога (правый щелчок ниже строк).
- Все папки панели без посчитанного размера, без отметки; тот же путь, что Space (38): `count_dirs` → по задаче на папку → `Message::DirSize` по мере готовности.
- В архиве и во время загрузки каталога — ничего.

Не делаем: остановку при уходе из каталога, очередь вместо задачи на папку.
