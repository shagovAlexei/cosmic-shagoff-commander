# 143 — Enter при зависшем чтении

Техдолг-1. Пока идёт переход (`target != cwd`), Enter глушился: строки на экране — прежнего каталога, двойной Enter открыл бы его строку. Чтение на мёртвом диске не приходит — Enter не работал вовсе.

- `Tab.pending_at` — когда начато чтение. Enter глушится только первую секунду (`ENTER_WAIT`); дальше открывает строку на экране и этим отменяет зависший переход, как Backspace.
