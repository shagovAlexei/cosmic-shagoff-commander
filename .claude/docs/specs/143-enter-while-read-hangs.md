# 143 — Enter при зависшем чтении

Техдолг-1. Пока идёт переход (`target != cwd`), Enter глушился: строки на экране — прежнего каталога, двойной Enter открыл бы его строку. Чтение на мёртвом диске не приходит — Enter не работал вовсе.

- `Tab.pending_at` — когда начато чтение. Enter глушится только первую секунду (`ENTER_WAIT`); дальше открывает строку на экране и этим отменяет зависший переход, как Backspace.
- Найдено при проверке (F7 повесил окно на мёртвом sftp): `archive::split_path` — «путь внутри архива?» — делал `metadata` каждого предка, а зовётся из UI-потока повсюду. Теперь на диске смотрятся только компоненты с архивным именем (`is_tree_name`); обычный путь диск не трогает. Итог тот же: настоящий каталог не бывает внутри файла.
- F7: `create_dir_all` — в фоне (`Message::Made`); готово — перечитать с курсором на новом, если вкладка всё там же; ошибка — в строку.
