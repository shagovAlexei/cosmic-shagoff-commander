# 134 — Сообщения — всплывающей карточкой

Сообщение (ошибка, сведения, «идёт работа…») показывалось в правой части строки состояния активной панели, в одну строку: длинное обрезалось («В имени папки байты не в U…»).

- Сообщение — карточка над низом панелей (`view::status_popup`, слой `stack` поверх `main_view`): во всю ширину, текст целиком с переносами, значок по виду (сведения / работа / ошибка), цвет как был, × (`Message::StatusClose`). Фон — `Container::Dialog(true)`: непрозрачный и в полупрозрачной теме.
- Время жизни прежнее: до следующего действия, «работа…» — до результата.
- Строка состояния — только итоги панелей и сведения о файле под курсором.
- Вьюер на месте панелей — та же карточка.
