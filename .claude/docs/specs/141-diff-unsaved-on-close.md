# 141 — Выход не теряет переносы в сравнении

Техдолг 25. Выход (×, Alt+F4, «Выход») с 69 идёт через `Message::Quit`, его можно не выполнить.

- Сравнение (Ctrl+Shift+D) открыто, есть несохранённые переносы блоков, предупреждения ещё не было: `Quit` только ставит `confirm_close`, как первый Esc; строка — «ещё раз Esc или × — закрыть без сохранения».
- Второй × (или Esc) — как прежде: выход (или закрытие сравнения) без сохранения.
