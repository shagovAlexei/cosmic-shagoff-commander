# 124 — F4 из архива: неудачное обновление спрашивается снова

`Edited.mtime` запоминался в момент вопроса «Обновить архив?». Если ответ «Обновить», но обновление закончилось ошибкой или отменой, то же изменение больше не предлагалось — правка могла не попасть в архив.

- `App.updating`: файл, который кладётся обратно (ответ «Обновить»).
- `finish_job`: такая задача отменена или ничего не сделала → `mtime` этого файла сбрасывается, на следующем тике вопрос снова.
- Ответ «Отмена» — как раньше: не спрашиваем до следующего сохранения.
