# 151. Shift+Enter из панели

ROADMAP «Командная строка, дальше»: Shift+Enter, когда фокус ушёл из строки. TC: Shift+Enter —
выполнить командную строку / программу под курсором с `cmd /k` (окно не закрывается).

- Строка набрана (фокус в панели после щелчка) — она во внешнем терминале, как Shift+Enter в поле.
- Строки нет: файл под курсором — `./имя` во внешнем терминале (выбранном, 148), в каталоге панели;
  папка или `..` — как Enter; внутри архива — «только чтение» (на диске файла нет).
- Встроенный терминал (149) не трогаем: в него набираем только у приглашения, а это — свой запуск.

Остальное из пункта: поле `terminal` в настройках — заменено выбором «Команды → Терминал…» (148);
вывод без терминала — встроенный терминал (149). Ctrl+X и имена не в UTF-8 — дальше.
