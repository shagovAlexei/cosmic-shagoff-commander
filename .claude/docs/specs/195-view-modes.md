# 195. Режимы вида

TC: `cm_ConfigViewModes`, `cm_*CustomView…`.

- `Config.view_modes: Vec<ViewMode { name, cols }>`; по умолчанию четыре (обычный, короткий, подробный, только имена). Вид → «Колонки» ▸ под флажками колонок: режимы (галочка у того, чей набор показан), «Сохранить колонки как режим вида…» (`InputOp::ViewMode`, имя; одинаковое заменяет).
- Режим = набор колонок (`Action::ViewMode(i)` → `Setting::ColSet`), одинаковый в обеих панелях.
- Не делаем: режим на панель, привязку к маске файлов, удаление и переименование из интерфейса (правка конфига), порядок колонок, Brief / эскизы в режиме.
