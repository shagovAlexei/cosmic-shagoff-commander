# 199. Сузить и обменять выделение

TC: `cm_ShrinkSelection`, `cm_ExchangeSelection` (по их названиям: в справке TC подробностей нет).

- `Panel::shrink_marks(mask)`: у отмеченных файлов, не подходящих под маску, отметка снимается (каталоги остаются). `MaskOp::Shrink` — то же окно маски, что у Num+.
- `Panel::exchange_marks(a, b)`: отметки a — на b по именам (есть такая запись), b — на a.
- Не делаем: клавиши по умолчанию, обмен по путям из разных каталогов.
