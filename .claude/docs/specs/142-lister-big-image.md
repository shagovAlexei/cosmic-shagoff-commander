# 142 — Картинка больше 32 МБ во вьюере

Техдолг 20. Декодирование в фоне уже сделано (`1f32074`, `Loaded::read`, в `Handle` — пиксели).

Оставалось: файл больше `LIMIT` читается окном (32 МБ), обрезанные байты не декодируются, режим «Картинка» показывал пустое поле.

- `Loaded::read`: картинка — только если файл прочитан целиком.
- `set_loaded`: «картинка» без картинки — режим Hex.
- Строка сведений (`Lister::too_big`): «N б: картинка больше 32 МБ не показывается, только её байты».
