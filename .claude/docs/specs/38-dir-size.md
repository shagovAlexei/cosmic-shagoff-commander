# 38. Размер папки по Space

Как в TC: Space на папке отмечает её и считает размер со всем вложенным.

- Подсчёт в фоне — `core::props::usage` (тот же, что в Alt+Enter: ссылки не раскрываются, нечитаемое пропускается).
- Результат хранится в `Panel` по имени (`dir_size` / `set_dir_size`), переживает пересканирование того же каталога, сбрасывается при смене каталога; ответ для другого каталога отбрасывается.
- Колонка размера показывает посчитанный размер вместо `<DIR>`; `totals` / `marked_totals` включают его.
- Повторный Space по уже посчитанной папке не пересчитывает. В архиве и во время загрузки каталога — только отметка.
- Колонка «Размер» в Классической теме: от 1 ГБ — человекочитаемо (в 90 px не влезает больше 11 знаков; касается и файлов).

Не делаем сейчас: Alt+Shift+Enter (все папки), сортировку по посчитанному размеру, остановку подсчёта при уходе из каталога.
