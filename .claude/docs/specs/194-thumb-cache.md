# 194. Дисковый кэш эскизов

Стандарт: freedesktop Thumbnail Managing Standard.

- `core::thumbcache`: `~/.cache/thumbnails` (`$XDG_CACHE_HOME`), `normal/` (128 px) и `large/` (256 px; от нашего размера больше 128), имя — md5 от `file://` URI (проценты по RFC 3986), PNG с текстом `Thumb::URI`, `Thumb::MTime` (секунды), `Thumb::Size`. Каталоги `0700`, файлы `0600`, запись во временный файл и `rename`.
- `thumbs::make`: картинка из кэша, если URI, mtime и размер совпали (общий с Files / GNOME), иначе делается как раньше (наш декодер или системный эскизатор), сохраняется в размере класса и сжимается до нашего. Нет кэша / нельзя писать — как раньше.
- «Перечитать эскизы» стирает и файл кэша. Ctrl+R чистит только память (файл проверяется по mtime).
- Не делаем: каталог `fail/` (неудачи), чистку кэша, старый `~/.thumbnails`.
- Настройка `thumb_cache` (Ctrl+, → Панели, по умолчанию да): выкл. — кэш не читается и не пишется.
