# 114 — «В панель» из поиска по Alt+L

В окне поиска Alt+F7 Alt+L — «В панель» (TC: Feed to listbox, Alt+L), как кнопка; без результатов ничего не делает.

- Клавиша по физической L: работает и в русской раскладке (Alt+Д).
- Поле ввода libcosmic вставляет «l» и при зажатом Alt. Не мешает: поля запоминаются при запуске поиска, а Alt+L закрывает окно. Без результатов «l» останется в поле (фильтровать ввод по Alt ненадёжно: `ModifiersChanged` может прийти после клавиши).
- Вне окна поиска Alt+L — по-прежнему быстрый поиск с буквы «l».
