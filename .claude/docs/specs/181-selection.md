# 181. Выделение: запомнить, файл, буфер, то же имя, только выделенные, переходы

TC: `cm_SaveSelection`, `cm_SaveSelectionToFile`, `cm_LoadSelectionFromFile`, `cm_LoadSelectionFromClip`, `cm_SelectCurrentName` / `…NameExt` и `cm_Unselect…`, `cm_GotoNextSelected` / `…Prev…`, `cm_ShowOnlySelected`. Клавиш по умолчанию в TC нет; пункты — в меню «Выделение» (только выделенные — в «Вид»), кнопки панели, свои клавиши.

- **Запомнить** — `Panel::keep_marks` (то, что уже хранится перед «снять разом»); Num / возвращает.
- **То же имя / имя и расширение** — `Panel::mark_like(Like, on)`, обобщение Alt+Num + (`Like::Ext`): имя без расширения или целиком, без учёта регистра; файлы, курсор на каталоге — ничего.
- **В файл** — окно ввода с `<каталог панели>/selection.txt`, пишет `marked_names()` по строке (в ветви / результатах поиска — относительные пути, как показаны). Ничего не выделено — окна нет; файл уже есть — не перезаписывается, сообщение; в архиве предлагается каталог рядом с ним.
- **Из файла / буфера** — `Panel::mark_listed(text)`: строки — имена (или полный путь в этот каталог), добавляются к выделенным; сообщение «выделено N».
- **К следующему / предыдущему** — `Panel::goto_marked`; без кольца.
- **Только выделенные** — `Panel::show_only_marked`: скрываются невыделенные на тот момент (новый / переименованный файл виден), галочка в «Вид», «Показаны: выделенные» в строке состояния; сбрасывается сменой каталога и Ctrl+F10 / F11 / F12 (`set_show`).
- Не делаем: ANSI / Unicode варианты файла (у нас всегда UTF-8), `cm_SelectCurrentPath` (ветвь, по пути).
