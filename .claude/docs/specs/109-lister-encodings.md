# 109 — Автоопределение кодировок в просмотре (кроме кириллических)

- Файл без BOM, не UTF-8 (UTF-8 с единичными испорченными байтами остаётся UTF-8), по первым 64 КБ:
  - наш счётчик строчных русских букв выбирает 1251 / KOI8-R / 866, как раньше — если `chardetng` (детектор Firefox) не видит там другую письменность (греческую, иврит, арабскую, тайскую, азиатские); его латинские догадки русский не перебивают (на слове-двух он говорит Windows-1252);
  - KOI8-U — только если есть байты украинских і ї є ґ; ISO-8859-5 — своя, не одна из наших;
  - иначе — найденная `chardetng` (`Encoding::Other`).
- Декодирование всех кодировок — `encoding_rs`; свои таблицы 1251 / KOI8-R / 866 удалены.
- Выпадающий список в строке просмотра: UTF-8, 1251, KOI8-R, 866, затем все, что умеет находить `chardetng`. Клавиши A / S / K / 8 — как были.
- Выбранная вручную кодировка сохраняется при N / P, угаданная — нет (как было).

Не делаем: UTF-16 без BOM, ISO-2022-JP (небезопасна, выключена в детекторе); русский текст в KOI8-R целиком заглавными и бинарные файлы без нулевых байт по-прежнему могут открыться не той кодировкой.
