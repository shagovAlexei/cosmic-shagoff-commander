# 55. Подменю в избранном (Ctrl+D)

Из ROADMAP («Избранное, дальше: подменю»). Как в TC: в списке `config.hotlist` пункт `-Имя` без пути начинает подменю, `--` его заканчивает (`-` — по-прежнему разделитель). Подменю вкладываются.

- Ctrl+D: подменю — строка со «▸»; Enter, → или щелчок открывают его (курсор на первом пункте), сверху строка «‹ Имя»: она, ← или Backspace — назад, курсор на покинутом подменю. «Добавить текущий каталог» добавляет в открытое подменю (перед его `--`). Delete удаляет только каталог, не подменю. Каждое Ctrl+D открывается с верхнего уровня.
- «Настроить…»: кнопка «Подменю» вставляет `-Новое подменю` и `--` после выделенного; вложенность видна отступом, `--` показан как «◂ конец подменю». У подменю правится только название (без `-`, пустое не принимается), у `--` — ничего. «Сортировать» сортирует каждый кусок между разделителями и границами подменю отдельно. «Вверх» / «Вниз» — значками.
- Логика — `hotlist::{children, sub_end, depths, is_sub, is_end}` с тестами.
