# 127 — Вьюер в архиве: N / P отменены — курсор на показанном файле

N / P во вьюере внутри архива ставят курсор на следующий файл и извлекают его (задача). Если извлечение отменено или не удалось, вьюер показывал прежний файл, а курсор панели стоял на новом.

- `finish_job`: задача открывала вьюер (`Open::Lister`), отменена или файла нет → курсор на файл, который во вьюере (`Lister.name`), и он же `focus` перечитывания.
