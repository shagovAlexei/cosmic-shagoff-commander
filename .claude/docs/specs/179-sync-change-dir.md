# 179. Синхронная смена каталогов и «другая панель — в этот же каталог»

TC: `cm_SyncChangeDir` (try to go to the same subfolder in the other panel too), `cm_MatchSrc` (inactive panel: go to the same folder as active panel). Клавиш по умолчанию в TC нет.

- **`cm_MatchSrc`** — Команды → «Другая панель — в этот же каталог», кнопка панели: другая панель (её активная вкладка) открывает каталог активной. Внутри архива — тот же путь через архив.
- **`cm_SyncChangeDir`** — Команды → «Синхронная смена каталогов» (галочка), кнопка панели; сообщение «включена / выключена». Пока включена, каждый переход активной панели `from → to` (`App::load`):
  - на один уровень вниз: другая идёт в тот же подкаталог, если он у неё есть (и скрытый фильтром Ctrl+S / Ctrl+F12); нет — стоит; глубже сразу (избранное, `cd a/b`) — стоит;
  - вверх на N уровней: другая тоже на N (не выше корня), курсор на каталоге, из которого вышла;
  - иначе (переход в другое место, диск, избранное) — другая стоит; закреплённая вкладка в другой панели и временная копия вложенного архива тоже стоят.
  - `from` / `to` и путь другой — куда они уже идут (`target`), чтобы быстрые шаги на медленной ФС не терялись.
- Состояние не сохраняется (до выхода), как и в TC без записи в ini.

Логика — `core::panel::sync_step` (чистая функция, тест); приложение только спрашивает её в `load` активной стороны.
