# 53. Настраиваемая панель инструментов

Из ROADMAP («Ручная проверка 05.10.2026»): как TC «Настройка панели инструментов».

- Кнопки — в конфиге (`Config.toolbar`, список `ToolButton { cmd, params, icon, tip }`); по умолчанию — прежний набор (`toolbar::default_bar`).
- `cmd`: внутренняя команда `cm_*` (имена TC: `cm_RereadSource`, `cm_Copy`, …; таблица `toolbar::builtins`), программа или скрипт, `-` — разделитель. Пустые значок и подсказка берутся у команды.
- Параметры как в TC (`core::cmdline::expand`): `%P` каталог панели, `%T` другой панели, `%N` имя под курсором, `%O` без расширения, `%E` расширение, `%S` выделенные (каждое — отдельное слово в кавычках), `%%`. Запуск: `sh -c "<cmd> <params>"` в каталоге панели, без терминала (терминал — сам вписать, `cosmic-term -e …`).
- Правый клик по панели или «Конфигурация → Панель инструментов…» — окно: список кнопок; «Добавить кнопку», «Разделитель», «Удалить» (скрыть), ↑ ↓ (переместить), «По умолчанию»; поля «Команда» (+ выпадающий список внутренних), «Параметры», «Значок» (имя значка темы, рядом предпросмотр), «Подсказка». Сохраняется по OK.
- Не сделано (как в TC, но позже): перетаскивание кнопок по самой панели, рабочий каталог кнопки, выбор значка из файла.
