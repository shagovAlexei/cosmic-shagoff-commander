# 116 — Свойства (Alt+Enter) внутри архива

Раньше внутри архива Alt+Enter отказывал («только чтение»). Теперь окно свойств открывается, но только показывает:

- одна запись: имя, тип (каталог / MIME по расширению / ссылка), дата; несколько — «Выбрано: N»;
- «Архив» — путь файла архива;
- размер с вложенным — по оглавлению (`archive::usage_of`: файл считается сам собой, каталог — с содержимым);
- права — серыми флажками (не нажимаются), строка `rw-r--r-- (644)`; группы нет (в архиве её не храним);
- одна кнопка «Закрыть»; Enter и Esc закрывают.

Менять права в архиве (перепаковкой) — не делаем: zip хранит их не всегда, а TC в архиве свойства тоже только показывает.
