# 63. Ctrl+Q на каталоге: сведения о нём

Как в TC: быстрый просмотр на каталоге показывает не «нет просмотра», а сколько в нём файлов,
подкаталогов и общий размер (с вложенными, ссылки не разыменовываются — `props::usage`, как Alt+Enter).
Сначала «Подсчёт…», итог приходит из фона; курсор ушёл — подсчёт останавливается. Кнопок режима
(текст / hex / перенос) на каталоге нет. `..` и путь внутри архива — по-прежнему пояснение.

Где: ветка каталога в `App::quick_follow`; `App::quick_stop`; ответ — `ListerLoaded(id, Err(текст))`.
