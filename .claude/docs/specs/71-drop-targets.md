# 71. Бросок на вкладки и кнопки дисков

Продолжение 67 (ROADMAP «Drag & drop, дальше»). Как в TC: файлы, брошенные на вкладку, идут в её
каталог; на кнопку диска — на диск (у TC — в текущий каталог диска, у нас — его корень: каталогов
по дискам мы не помним). Тот же диалог F5 / F6 (`Message::Drop { dir: Some(..) }`), Shift — перенос.

- Вкладка: `clip::drop_zone` снаружи `context_menu` (меню прячет зоны приёма внутри). Вкладка с
  результатами поиска — не зона (каталога нет).
- Кнопки дисков — только в теме «Современная»; в «Классической» диск — выпадающий список, туда не
  бросить.
- `Message::Drop`: результаты поиска в активной вкладке мешают только броску без каталога (на сам
  список).

Не делаем (следующая фаза): правая кнопка с меню «Копировать / Переместить / Ссылка» — libcosmic
`dnd_source` начинает перетаскивание только левой; нужен свой источник и операция «ссылка».
