# 146 — Сортировка большого каталога не в UI-потоке

Техдолг: Ctrl+F3…F6 на 100 000 файлов — 0,1–0,2 с в UI-потоке.

Замер (release, 100 000 записей): Ext 125 мс, Name 104, Size 75, Date 44; клон списка в `rebuild` — 7 мс. Время — сравнения (`natural_cmp`, ~1,7 млн); `sort_unstable_by` не быстрее.

- Больше `SORT_HERE_MAX` (20 000) строк: `Panel::set_sort_key` (только ключ) + перечитывание каталога в фоне — `load_tab` и так сортирует по ключу вкладки, `set_listing` того же каталога держит курсор (по имени) и отметки.
- Меньше — как было, сразу.
