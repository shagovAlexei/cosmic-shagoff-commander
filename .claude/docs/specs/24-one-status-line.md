# 24. Одна строка состояния

Статус: просьба пользователя («у нас две строки состояния — выше кнопок и ниже кнопок; объединим в одну, выше кнопок F1–F11»). Исправляет раскладку фазы 19.

## Решения

| Вопрос | Решение |
|---|---|
| Где | Одна строка над F-кнопками (как в TC). Строки состояния внизу каждой панели и строки окна под кнопками больше нет |
| Что в ней | Две половины, каждая под своей панелью: итоги панели («0 б из … , файлов …»), а когда открыт быстрый поиск / фильтр — его поле, при ошибке чтения каталога — ошибка. В половине активной панели справа — последнее сообщение (обычное / «идёт…» / ошибка — цветом, как в фазе 19), а без сообщения — сведения о файле под курсором |
| Ширина | Итоги 3/5 половины, сообщение / сведения 2/5; не переносятся, длинное — с многоточием (сведения — посередине) |
| F-кнопки выключены | Строка остаётся одна, внизу окна |
| Нечего показать справа (нет сообщения, курсор на `..`) | Итоги занимают всю половину |
| Боковая панель (F1, Ctrl+,) пристыкована | Строка делится по всей ширине окна, а панели уже: половины не совпадают с панелями (как и F-кнопки) — принято |
| Открыт просмотр (F3) | Только сообщение / сведения (панелей не видно) |

## Тесты

Логики нет (раскладка); проверено на снимках: итоги обеих панелей, сведения, сообщение «Скопировано», поле быстрого поиска.
