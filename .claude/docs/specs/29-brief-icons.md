# 29. Вид Brief и иконки по типу файла

Статус: решения приняты сами (пользователь: «продолжай по плану» — следующий пункт бэклога «Режимы Brief и эскизы, иконки по MIME»).

## Решения

| Вопрос | Решение |
|---|---|
| Ctrl+F1 / Ctrl+F2 | Как в TC: Brief / Подробно для активной вкладки активной панели. Пункты в меню «Вид» |
| Brief | Только имена (файл — `имя.расш`, каталог — `[имя]`), колонки сверху вниз, затем слева направо. Строк в колонке — сколько влезает по высоте; колонок — ширина панели / 200 px (не меньше одной), поровну делят ширину |
| Клавиши в Brief | ↑/↓ — соседний файл; ←/→ — та же строка в соседней колонке (за краем — первый / последний файл); PgUp/PgDn — на экран (строки × колонки); Home/End как обычно. В «Подробно» ←/→ ничего не делают |
| Прокрутка в Brief | По колонкам: видимые колонки сдвигаются так, чтобы курсор был на экране; колесо мыши — на колонку. Полосы прокрутки нет |
| Заголовок колонок | Остаётся в обоих видах: щелчок сортирует |
| Хранение | Вид — у каждой вкладки (`PaneState.brief`, по умолчанию «Подробно», старое состояние читается); Ctrl+T копирует вид |
| Иконки | Перед именем в обоих видах, 16 px, из темы иконок: каталог — `folder`, `..` — `go-up`, файл — по MIME из расширения (`mime_guess`: `text/x-rust` → `text-x-rust`, запасная `text-x-generic` / `<тип>-x-generic`), исполняемый без расширения — `application-x-executable`. Без настройки «выключить» |
| Эскизы | Нет: отдельный пункт бэклога (нужен фоновый декодер и кеш) |

## Ядро

- `viewport.rs`: `brief_rows(row_h, height)`, `brief_cols(width)`, `brief_first_col(cursor, rows, cols, first)` — первая видимая колонка, при которой колонка курсора на экране.
- `format.rs`: `icon_name(e) -> (String, &'static str)` — имя иконки и запасное.
- `session::PaneState.brief: Vec<bool>` (`#[serde(default)]`).

## Тесты

Core: `brief_rows` / `brief_cols` не меньше 1; `brief_first_col` — курсор правее экрана, левее, уже на экране; `icon_name` — каталог, `..`, `.rs`, неизвестное расширение, исполняемый, `.zip`.
App: Ctrl+F1 включает Brief у активной вкладки, Ctrl+F2 выключает; → в Brief сдвигает курсор на строки колонки и не выходит за конец; ← в «Подробно» не двигает; PgDn в Brief — на строки × колонки; Brief переживает сохранение / восстановление вкладок.
