# 187. Сравнение каталогов: с подкаталогами и только различия

TC: `cm_CompareDirsWithSubdirs` («Also mark subdirs not present in other dir»), `cm_DirMatch` — сравнение с показом только различий. У нас Shift+F2 (`sync::compare_lists`, фаза 14) отмечал только файлы.

- `compare_lists(left, right, dirs)`: с `dirs` ещё и каталоги, у которых напротив нет записи с тем же именем (не `..`; каталог против файла — конфликт, не отмечается); содержимое каталогов не сравнивается (это Ctrl+F12 «Синхронизация»).
- `Action::CompareListsSubdirs` — Shift+F2 с `dirs`; `Action::CompareListsDiffOnly` — Shift+F2 с `dirs`, затем `Panel::hide_unmarked` в обеих панелях (и без отметок — тогда пусто; строки, спрятанные прошлым разом, перед сравнением возвращаются) (из 181: скрытое возвращается уходом из каталога и Ctrl+F10).
- Меню «Выделение»: подменю «Сравнить каталоги» — «Файлы: отметить различия» (Shift+F2), «С подкаталогами…», «Показать только различия»; справка; кнопки `cm_CompareDirsWithSubdirs`, `cm_DirMatch`. В результатах поиска — отказ, как Shift+F2.
