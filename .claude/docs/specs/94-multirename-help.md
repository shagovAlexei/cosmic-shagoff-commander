# 94. Multi-rename: how to use it

The user: «непонятно как юзать». The dialog had only the mask fields.

- As TC: buttons under the name mask put a token at its end: `[N]`, `[N1-3]`, `[E]`, `[C]`,
  `[Y]-[M]-[D]`, `[h]-[m]-[s]`.
- «? Справка по маскам» shows every token, find / replace and an example under the preview, in the
  same scroll.
- That scroll is as tall as its content, at most 300 px and at most the panel's rows minus the
  fields (as the list dialogs): at 1036x530 the dialog's buttons were cut off.
