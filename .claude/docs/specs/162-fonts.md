# 162. Поиск шрифта; ширина колонок по размеру текста

ROADMAP «Шрифты, дальше» (без меню: его рисует libcosmic).

- Ctrl+, → «Шрифты»: поле «Поиск шрифта» над списком: в «Шрифт панелей» только семейства, где есть
  все слова (без учёта регистра); «Системный» всегда первый. Поиск не пишется в конфиг
  (`Message::FontFilter`), отбор — `drawer::fonts_found`.
- Ширины колонок (`config.columns`) хранятся для обычного размера текста (13), на экране —
  умножены на `text_scale` (`App::col_widths`): крупный текст не обрезает дату. Перетаскивание делит
  обратно. При размере 13 ничего не меняется.
