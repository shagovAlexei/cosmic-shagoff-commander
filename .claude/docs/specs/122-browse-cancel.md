# 122 — Ctrl+F: «Обзор сети» останавливается

`gio list network:///` мог идти долго, остановить его было нельзя: закрытый диалог оставлял `gio` работать впустую.

- `mount::browse(cancel)` идёт через `talk_until`, как `connect`: флаг убивает группу процессов `gio` → `Error::Cancelled`.
- `Dialog::Connect.browsing: Option<Arc<AtomicBool>>`. Кнопка во время поиска — «Поиск… (остановить)», нажатие ставит флаг. Esc / «Отмена» и закрытие диалога после подключения — тоже.
- Результат остановленного обзора (`Cancelled`, или пришедший, когда обзора уже нет) не показывается.
