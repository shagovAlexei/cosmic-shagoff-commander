# 140 — Ошибки отброшенных из очереди

Техдолг 69.

- Распаковка (Alt+F9) / извлечение из архива в очереди: задание хранит только каталог назначения; создание цели и план переноса из staging — при запуске (`archive::run`). Исправлять нечего.
- Операция из очереди, чей план не сложился при старте (`ops::plan`, например цель стала ссылкой на источник), отбрасывается; её причина теперь дописывается строкой под уже показанной ошибкой, а не заменяет её.
