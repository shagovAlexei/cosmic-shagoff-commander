# 66. Ветвь Ctrl+B

Как в TC (`cm_DirBranch` / `cm_DirBranchSel`):

- **Ctrl+B** — в панели все файлы текущего каталога и всех подкаталогов одним списком (каталоги сами
  не показываются; имя — путь от текущего каталога). Заголовок «Ветвь: …». Ещё раз Ctrl+B или
  Backspace — обычный вид.
- **Ctrl+Shift+B** — то же для отмеченных каталогов (или каталога под курсором).
- Работает как результаты поиска «В панель»: F3 / F4 / F5 / F6 / F8, отметки, сортировка, быстрый
  поиск и фильтр — по найденным файлам; Ctrl+M и Shift+F2 — нельзя (как в результатах).
- Ссылки на каталоги не разворачиваются; скрытые — по настройке панели.
- Читается в фоне («Читаю все файлы ниже…»); если вкладка за это время ушла в другой каталог —
  результат не применяется. Внутри архива и поверх результатов поиска — нельзя (сообщение).

Где: `core::listing::branch`; `Tab.branch`; `Action::Branch / BranchSel`, `Message::BranchListed`;
меню «Вид», справка, кнопки панели инструментов.

Не делаем: остановку долгого чтения (огромный `~`), каталоги в списке, ветвь внутри архива.
