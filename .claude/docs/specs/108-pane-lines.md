# 108 — Линия между панелями и рамка активной панели

Две настройки облика, Ctrl+, → «Интерфейс» и меню «Вид» (флажки):

- «Линия между панелями» — тонкая вертикальная линия (цвет разделителя темы) посередине промежутка между панелями, в обоих обликах; тянуть и двойной щелчок — как раньше. По умолчанию выключена.
- «Рамка активной панели» — классический облик: рамка цвета акцента вокруг активной панели (как карточка в «Современном»), у неактивной рамка не видна, ширина не меняется. В «Современном» рамка есть всегда — пункт там не показывается. По умолчанию выключена.
