# 120 — Сравнение: текущий блок виден

Текущий блок отличий был только числом «Отличие i из n»; после прокрутки мышью «Блок →» и ↓ / ↑ действовали от блока, которого может быть не видно.

- Строки текущего блока (от его начала до первой одинаковой строки, `diff::block_end`) подсвечены гуще (0,5 против 0,25) и отмечены «▸» перед номером строки.
- Прокрутка (`Message::DiffScrolled`): текущий блок хоть частью в виду — остаётся; иначе текущим становится первый блок в виду; в виду блоков нет — без изменений (`diff::block_in_view`).
- ↓ / ↑ (`diff::step`): текущий в виду — соседний; не в виду — первый ниже вида / последний выше.
