# 42. Фоновые операции

Пользователь (ручная проверка, пункты 3 и 13): при долгой упаковке нужно свернуть окно прогресса и работать дальше; строка состояния не показывает идущую операцию; полоса прогресса мелкая.

TC: в окне прогресса кнопка «В фоне» — панели снова работают, операция идёт.

Решения:
- Окно прогресса: крупнее полоса (girth 12), процент рядом с байтами, кнопки «В фоне» и «Отмена».
- «В фоне» (`Running.hidden`): окно не показывается, панели, вьюер, командная строка, диски работают. Над строкой состояния — строка операции: полоса, «Упаковка: 26 % — файл», «Показать» (снова окно), «Отмена».
- Вопросы операции (конфликт, ошибка) всплывают окном, как и раньше.
- Вторая операция, пока идёт первая, не запускается: «Дождитесь окончания операции» (очередь — не делаем).
- Esc при скрытом окне операцию не отменяет (только видимое окно / «Отмена»).
- Наблюдатель каталогов по-прежнему на паузе, пока идёт операция: по её окончании обе панели перечитываются.

Не делаем: очередь операций, несколько операций сразу, свёрнутое окно в панели задач.
