# 121 — Сравнение: счётчик только достижимых отличий

Сравнение держит первые `diff::ROWS_LIMIT` (100 000) строк. «Отличие i из n» считал и блоки за ними, до которых не дойти ↓ / «Блок →».

- `n` — блоки в показанных строках (`DiffDlg::blocks`).
- Есть блоки дальше: рядом «Ещё отличий за показанными строками: m» (`diff-count-past`); если в показанных строках отличий нет — только эта надпись.
