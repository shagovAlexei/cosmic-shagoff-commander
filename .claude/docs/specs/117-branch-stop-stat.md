# 117 — Ветвь: Esc останавливает и второй шаг

Ctrl+B читается в два шага: обход каталогов (Esc останавливал, 79) и сведения о каждом найденном файле (`lstat`, для строк панели). На миллионах файлов второй шаг тоже долгий, а Esc на нём не действовал.

- Признак «ветвь читается» (`Tab.branching`, «Чтение ветви… Esc — остановить») держится до прихода строк (`Message::Listed`), а не снимается после обхода.
- Esc на втором шаге — то же, что на первом: «Ветвь остановлена», вкладка возвращается к обычному виду каталога (частичный список не показываем: он выглядел бы как вся ветвь).
- `listing::entries` проверяет флаг остановки на каждом пути.
- Вкладка, которая не на виду, когда обход закончился, читает строки при показе — как раньше, без признака.
