# 105 — Правая кнопка отмечает (TC «Выделение правой кнопкой»)

Настройка Ctrl+, → «Панели» → «Правая кнопка отмечает файлы» (по умолчанию включена, как в TC).

- Включена: правое нажатие ставит курсор на строку; отпустили быстрее 0,5 с — отметка строки переключается (`..` не отмечается); держали дольше — по отпусканию открывается контекстное меню (отметки как при меню: строка не отмечена — остальные снимаются). На пустом месте: быстро — ничего, долго — меню каталога. Перетаскивание правой кнопкой (меню Копировать / Переместить / Ссылка) — как было, отметку не меняет.
- Выключена: правый щелчок сразу открывает меню (как до 105, «как в Windows»).
- Меню вкладки — всегда сразу.

Не делаем: отметка протягиванием с зажатой правой кнопкой (TC), меню, всплывающее во время удержания (виджет libcosmic открывает его только по отпусканию).
