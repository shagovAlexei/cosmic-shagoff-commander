# 126 — Ctrl+R во время перехода не отменяет его

Ctrl+R перечитывал `panel.cwd()` — каталог, который вкладка показывает. Пока список нового каталога в пути (после Enter, «В панель»), это старый каталог: Ctrl+R отменял переход, а результаты поиска снимал (`load_tab` убирает результаты при переходе в другой каталог).

- Ctrl+R перечитывает `Tab::target()` — куда вкладка идёт (или где она, если никуда).
