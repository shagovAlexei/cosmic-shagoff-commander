# 12. Архив как папка (только чтение)

Статус: на ревью.
Основа: [архитектурный спек](00-architecture-design.md), [архивы, фаза 11](11-archives.md), [эталон TC](../tc-reference.md).

## Решения

| Вопрос | Решение |
|---|---|
| Объём | Просмотр + извлечение наружу. Запись в архив — нет (отдельная фаза) |
| Как представлен путь | Обычный путь сквозь архив: `/home/u/a.zip/docs/img`. На диске его нет (`a.zip` — файл), `listing::scan` это замечает и перечисляет записи архива |
| Какие архивы — папки | zip, tar, tar.gz/bz2/xz/zst, 7z. Одиночные .gz/.bz2/.xz/.zst — обычные файлы |
| Вложенные архивы | Нет: zip внутри zip открывается как файл (Enter → извлечь и открыть) |
| Скорость | Кеш индекса одного (последнего) архива по ключу путь + размер + mtime |

## Поведение

Вход и выход:
- Enter или Ctrl+PgDn на архиве открывает его как папку.
- Backspace / `..`: на уровень выше; из корня архива — в каталог архива, курсор на архиве (это даёт `parent_of` как для обычного пути).
- Строка пути, вкладки, история (Alt+←/→, Alt+↓), Ctrl+D, сохранение вкладок работают с этим путём как с обычным. При восстановлении вкладки путь внутри существующего архива годен (`session::existing_dir`).
- Архив пропал, повреждён или не читается — ошибка в строке состояния, как у недоступного каталога.

Внутри архива:
- Курсор, отметки, Num+/−/*, сортировка, быстрый поиск и фильтр, Ctrl+R — как обычно.
- Колонки из записей архива: несжатый размер, mtime, права (`mode & 0o777`; нет прав в архиве — `0o644` у файлов, `0o755` у папок). Симлинк показывается файлом со стрелкой, как сейчас.
- Папки, у которых в архиве нет своей записи (`a/b/f.txt` без `a/`), показываются папками (размер 0, mtime самой новой записи внутри).
- Скрытые (начинаются с `.`) — по Ctrl+H, как обычно.
- F5: диалог пути (как сейчас, цель — другая панель) → `Job::Extract` в указанный каталог. `/` на конце не обязателен: цель всегда каталог.
- Ctrl+C: сразу `Job::Extract` в каталог другой панели, без диалога (файлы из архива нельзя положить в системный буфер — у них нет настоящего пути).
- Enter на файле: извлечь его во временный каталог и открыть `xdg-open`. F3: то же, программой просмотра из конфига.
- Только чтение: F4, F6, F7, F8, Shift+F8, Shift+F6/F2, Ctrl+M, Ctrl+X, Ctrl+V, Alt+F5, Alt+F9 в панели внутри архива, а также F5/F6/Ctrl+V/Alt+F9 с целью внутри архива (другая панель в архиве или путь в диалоге ведёт в архив) — ничего не делают, в строке состояния «Архив только для чтения».
- Watcher не следит за путём внутри архива.
- Свободное место в строке состояния для пути внутри архива не показывается (statvfs не удаётся — уже так).

Временный каталог: `$XDG_CACHE_HOME/shagoff-commander/<pid>/` (нет переменной — `~/.cache/...`). Не `$XDG_RUNTIME_DIR`: это маленький tmpfs в памяти, нужный службам сессии; большой файл из архива его бы забил (найдено на ревью). Каждое извлечение для открытия — в свежий подкаталог `<n>/`, чтобы одноимённые файлы не путались. Каталог `<pid>` удаляется при выходе; при запуске удаляются подкаталоги с pid, которых больше нет (`/proc/<pid>` не существует).

## Ядро

`archive.rs`:

```rust
/// "/x/a.zip/docs" → ("/x/a.zip", "docs"); "/x/a.zip" → ("/x/a.zip", ""). None if `p` is a real
/// dir or no ancestor is a regular file with a tree format (zip, tar.*, 7z).
pub fn split_path(p: &Path) -> Option<(PathBuf, PathBuf)>;
/// Direct children of `inner` as listing entries (no ".."); implicit dirs synthesized.
pub fn list(archive: &Path, inner: &Path, show_hidden: bool) -> io::Result<Vec<Entry>>;
/// Extract `names` (relative to `inner`) into `dest`: unpack machinery (staging, safe_path,
/// transfer(Move)), only the chosen subtrees, `inner` stripped. `completed` = the virtual paths
/// (`archive/inner/name`) extracted without skips.
pub fn extract(archive: &Path, inner: &Path, names: &[PathBuf], dest: &Path, h: &mut dyn Handler) -> Report;
/// Formats that open as folders.
impl Format { pub fn is_tree(self) -> bool; }
```

- Индекс архива: записи (путь после `safe_path`, тип, размер, mtime, mode) без чтения данных: zip — центральный каталог, 7z — заголовок, tar — заголовки (данные пропускаются крейтом). Записи с небезопасным путём в индекс не попадают.
- Кеш: `static Mutex<Option<(Key, Arc<Vec<Item>>)>>`, `Key = (PathBuf, u64 size, SystemTime mtime)`. Другой архив или изменившийся — читается заново.
- `split_path`: если `p` — существующий каталог (`metadata`), сразу `None`; иначе идём по предкам от длинного к короткому, первый предок, который обычный файл (`metadata`, симлинк на архив годен) с `is_tree()` форматом, — архив; остаток — `inner`.
- Выбор в `extract`: в `Stage::put` запись вне `inner/<name>` для всех `names` пропускается молча; у выбранных путь берётся относительно `inner`. Hardlink на файл вне выбора — пропуск с ошибкой (как наружу).

`listing::scan`: если `read_dir` вернул NotADirectory или NotFound и `archive::split_path` нашёл архив — `archive::list`. Других изменений навигации нет.

`session::existing_dir`: предок годен, если он каталог или `split_path` его узнаёт (архив существует).

## Приложение

- Enter: на файле с `is_tree()` форматом — `load(cwd/имя)`; внутри архива на файле — `Job::Extract` во временный подкаталог, по завершении — `xdg-open` извлечённого файла (если он появился). F3 внутри архива — то же с viewer.
- Ctrl+PgDn → `Action::Enter` (в TC Ctrl+PgDn — «войти»: в каталог или в архив; пара к Ctrl+PgUp = Backspace).
- `Running` получает `open: Option<(PathBuf, Vec<OsString>)>` — что запустить после задачи (argv для файла).
- Проверка «только чтение» — одна функция в `act()` до `dialog_for`; для F5/Ctrl+V с целью в архиве — ещё раз при запуске (путь из диалога).
- F5 внутри архива: `Dialog::Input { op: Copy }` как сейчас; при отправке, если источник в архиве, — `Job::Extract { archive, inner, names, dest }`, где `names` — имена отмеченных относительно `inner`.
- `OpKind::Extract` — заголовок «Извлечение».
- watcher: путь, который узнаёт `split_path`, не наблюдается.
- Временный каталог: `core::archive::temp_root()` + очистка при старте; удаление каталога `<pid>` при выходе (`Message::Exit`/закрытие окна).
- Строки `en` и `ru`; tc-reference: Enter/Ctrl+PgDn на архиве.

## Тесты

Core (tempdir):
- `split_path`: каталог → None; `/x/a.zip` → (a.zip, ""); `/x/a.zip/d/e` → (a.zip, d/e); несуществующий путь без архива → None; не-архив-файл в пути → None;
- `list`: zip, tar.gz, 7z: файлы и папки корня и подпапки; неявные папки; скрытые с/без `show_hidden`; несуществующий `inner` → ошибка NotFound;
- кеш: архив переписан (другой mtime/размер) → новый список;
- `extract`: один файл, папка целиком, два имени, конфликт (пропустить), отмена (нет staging), злая запись в выбранной папке не выходит наружу;
- `listing::scan` пути внутри архива; `session::existing_dir` пути внутри архива.

App: Enter на архиве переходит внутрь, Backspace из корня возвращает с курсором на архиве; F8 внутри архива — ошибка «только для чтения», нет задачи и диалога; F5 внутри архива → `OpKind::Extract`; F5 из обычной панели в панель-архив — ошибка.

Вручную (TESTING.md): зайти в zip, tar.gz, 7z; F5 папки наружу; Enter на картинке в архиве открывает её; Ctrl+C внутри архива; F8 внутри — сообщение; вкладка внутри архива восстанавливается после перезапуска.
