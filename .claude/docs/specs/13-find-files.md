# 13. Поиск файлов Alt+F7

Статус: одобрен.
Основа: [архитектурный спек](00-architecture-design.md), [выделение и маски](04-selection.md), [эталон TC](../tc-reference.md).

## Решения

| Вопрос | Решение |
|---|---|
| Объём | Ядро TC «Find Files»: маска имени, где искать, текст внутри файла, результаты списком, переход к найденному |
| Маска | Синтаксис масок Num+ (`core::mask`): `*.rs;*.toml`, `*.txt *.md`, `|` — исключения; пусто = `*` |
| Где искать | Каталог активной панели (редактируемый путь), рекурсивно, без ограничения глубины |
| Текст | Подстрока; флажок «С учётом регистра» (по умолчанию нет). Без регулярных выражений |
| Скрытые | Ищутся, если в панели показаны скрытые (Ctrl+H) |
| Симлинки | На каталоги — не заходим (петли); на файлы — проверяется имя, содержимое читается по ссылке |
| Другие ФС | Заходим (как TC), `/proc` `/sys` `/dev` `/run` пропускаем всегда |
| Внутри архивов | Нет (позже) |
| Результаты | Появляются по мере поиска; «Стоп» прерывает; счётчик найденного |
| Переход | Enter / «Перейти» на результате: активная панель → каталог файла, курсор на файле, диалог закрывается |
| «В панель» (Feed to listbox TC) | Нет (позже, в бэклог) |
| Фильтры даты/размера | Нет (позже) |

## Поведение

Alt+F7 (только чистый Alt) открывает диалог. Маска, текст и флажок регистра запоминаются в состоянии (`State::find`) при каждом запуске поиска и подставляются при следующем открытии, в том числе после перезапуска:
- «Искать файлы»: маска, по умолчанию `*`;
- «Где»: каталог активной панели (если панель внутри архива — каталог, где лежит архив);
- «Текст»: пусто — искать только по имени;
- флажок «С учётом регистра» (для текста);
- кнопки «Найти»/«Стоп» и «Перейти к файлу» стоят над списком (нижний ряд диалога обрезается в низком окне); «Найти» (Enter в поле) запускает поиск; повторное «Найти» начинает заново. После ↑/↓ по результатам Enter переходит к выбранному (как фокус списка в TC), пока снова не изменено поле;
- во время поиска: «Стоп»; под полями — текущий каталог (усечённый) и «Найдено: N»;
- список результатов: полный путь; ↑/↓ двигают выбор, Enter или двойной клик — переход; «Отмена»/Escape — закрыть (поиск останавливается).

Показывается не больше 1000 строк списка (дальше — строка «… и ещё N»), поиск при этом продолжается и считает все.

Ошибки чтения каталогов/файлов (нет прав) молча пропускаются.

Поиск по тексту: файл читается кусками по 256 КиБ с перекрытием `len(needle)` байт; без учёта регистра — кусок через `String::from_utf8_lossy(..).to_lowercase()` и искомое в нижнем регистре (кириллица работает). Двоичные файлы не отличаются от текстовых.

## Ядро: `search.rs`

```rust
pub struct Query {
    pub mask: Mask,
    pub text: Option<String>,
    pub case_sensitive: bool,
    pub hidden: bool,
}
/// Walk `root` depth-first (sorted by name per dir), calling `found` for every match and `dir`
/// for every dir entered (for the progress line). Stops as soon as `stop` is set.
pub fn find(root: &Path, q: &Query, stop: &AtomicBool, found: &mut dyn FnMut(PathBuf), dir: &mut dyn FnMut(&Path));
/// Does the file contain the text (per `q`)? Errors → false.
pub fn contains(path: &Path, q: &Query) -> bool;
```

Каталоги, на которые совпала маска, тоже результат (как TC), если текст не задан.

## Приложение

- keymap: Alt+F7 → `Action::FindFiles`.
- `Dialog::Find(Box<Find>)`: поля, флажок, результаты `Vec<PathBuf>`, всего найдено, текущий каталог, выбранная строка, `running: Option<Arc<AtomicBool>>`.
- Поиск — поток (`std::thread`), события через futures-канал, как `jobs`: `Found(Vec<PathBuf>)` пачками (не чаще раза в 100 мс), `Dir(PathBuf)`, `Done`. Сообщение несёт номер поиска: события старого поиска после «Найти заново» отбрасываются.
- Переход: всегда `load(side, parent, Some(name))` — родитель и курсор на имени, и для найденного каталога тоже (как TC).
- Пока открыт диалог, панели не реагируют на клавиши (как другие модальные); ↑/↓/Enter идут в список, Tab — между полями.
- Строки en и ru; tc-reference: Alt+F7 → 13.

## Тесты

Core (tempdir): маска по имени во вложенных каталогах; исключение `|`; скрытые с/без `hidden`; текст с учётом и без учёта регистра (кириллица); текст на границе кусков; симлинк-петля на каталог не зацикливает; `stop` прерывает; каталог совпадает по маске без текста и не совпадает с текстом.

App: Alt+F7 открывает диалог с путём панели; `Found` добавляет строки; событие с чужим номером поиска игнорируется; Enter на результате переводит панель (target = каталог, фокус на имени) и закрывает диалог.

Вручную (TESTING.md): поиск `*.rs` в проекте; текст «fn main»; Стоп на `/`; переход к файлу.
