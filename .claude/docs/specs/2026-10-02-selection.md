# Фаза 4: выделение как в TC

Дата: 2026-10-02. Статус: одобрен.
Основа: [архитектурный спек](2026-10-02-architecture-design.md), [фаза 3](2026-10-02-tabs.md), [эталон TC](../tc-reference.md) → «Выделение».

## Решения

| Вопрос | Решение |
|---|---|
| Курсор и отметки | Это разные вещи, как в TC. Отметки хранятся по настоящему имени (`os_name`), поэтому переживают пересортировку |
| Смена каталога | При переходе в другой каталог отметки сбрасываются. При перечитывании того же каталога остаются, кроме отметок пропавших файлов |
| `..` | Не отмечается никогда |
| Num+ / Num− / Num* | Действуют только на файлы, как в TC по умолчанию |
| Ctrl+A, Ctrl+Num+ / Ctrl+Num− | Выделить всё (файлы и папки) / снять всё |
| Маска | Синтаксис TC: шаблоны через `;`, исключения после `\|`, символы `*` и `?`, регистр не важен. `*.*` совпадает и с именами без точки. Пустая маска означает `*` |
| Цвет отмеченных | Текст цветом destructive из темы (в TC красный). Остаётся красным и под курсором |
| Мышь | Ctrl+клик ставит курсор на строку и переключает её отметку |

## Ядро

- `mask.rs`:
  - `Mask::parse(&str) -> Mask`;
  - `Mask::matches(&str) -> bool`.
- `Panel`:
  - `toggle_mark()` — Space;
  - `toggle_mark_and_move(delta)` — Insert и Shift+↓ (+1), Shift+↑ (−1);
  - `mark_by_mask(&Mask, on)` — только файлы;
  - `invert()` — только файлы;
  - `mark_all(on)` — всё, кроме `..`;
  - `is_marked(&Entry)`;
  - `marked_totals() -> Totals`.

## Приложение

- Клавиши:

| Клавиша | Действие |
|---|---|
| Insert, Shift+↓ | MarkDown |
| Shift+↑ | MarkUp |
| Space | Mark |
| Num+ / Num− (физические `NumpadAdd` / `NumpadSubtract`) | SelectGroup / UnselectGroup — диалог с маской |
| Num* | Invert |
| Ctrl+A (физическая `KeyA`), Ctrl+Num+ | SelectAll |
| Ctrl+Num− | UnselectAll |
| Escape | Cancel — закрыть диалог |

- Диалог маски: `Application::dialog()`. Заголовок «Выделить группу» или «Снять выделение». Поле ввода со значением `*` получает фокус сразу при открытии. Enter или OK применяют маску, Escape или «Отмена» закрывают диалог. Пока диалог открыт, клавиши панелей не действуют.
- Строка состояния: «{отмечено байт} б из {всего} б, файлов {отм.} из {всего}, папок {отм.} из {всего}».
- Ctrl отслеживается по событию `ModifiersChanged`. Строки i18n добавляются в `en` и `ru`.

## Вне объёма

Подсчёт размера папки по Space, история масок, выделение мышью с Shift (диапазон), выделение по расширению (Alt+Num+) — всё это в бэклоге.

## Тесты

- **Ядро:**
  - маска: `*`, `?`, `;`, `|`, регистр, `*.*`, пустая маска;
  - отметки: `..` не отмечается, Insert сдвигает курсор, отметки переживают сортировку, перечитывание убирает отметки пропавших файлов, смена каталога сбрасывает отметки, маска и инверсия действуют только на файлы, `mark_all` включает папки, `marked_totals`.
- **Keymap:** все клавиши из таблицы, Ctrl+A в русской раскладке, `+` на основной клавиатуре → `None`.
- **Вручную** — чек-лист в `TESTING.md`.
