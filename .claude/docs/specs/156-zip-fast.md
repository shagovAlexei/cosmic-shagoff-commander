# 156. Быстрая запись в zip

ROADMAP «Архив, дальше: быстрая запись в zip без перепаковки всего архива». Было: любое изменение
(F5 / F6 / F7 / F8 / Shift+F6 / F4) распаковывает архив целиком и пакует заново — на большом zip это
минуты. TC пишет в zip, не трогая остальные записи.

- Zip: новые записи — как при упаковке (`Packer`, права, время), прочие переносятся в новый архив
  «как есть» (`raw_copy_file`, без распаковки и сжатия; переименование — `raw_copy_file_rename`).
  Записывается в рабочий каталог рядом и переименовывается поверх, как раньше: отмена или ошибка
  оставляют архив нетронутым.
- Изменение на пустом дереве: F5 / F4 / F7 кладут в него только новое (`apply`, с прогрессом и
  ошибками как раньше); F8 и Shift+F6 — только переименование / пропуск записей.
- По-старому (целиком), когда может быть вопрос или особый случай: зашифрованные записи (пароль для
  новых), ссылки, повтор имени в архиве, имя уже занято (окно конфликта), записи нет (ошибка).

## Не делаем

- Дописывание в конец файла на месте (`new_append`): не атомарно.
- Быстрый путь для tar / 7z: у них нет оглавления с независимыми записями (tar.gz сжат целиком).
