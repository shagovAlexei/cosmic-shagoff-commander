# 132 — Ctrl+D после правки конфига снаружи

Строки открытого Ctrl+D — номера в `config.hotlist`. Список, изменённый снаружи (руками, другим окном), сдвигал номера: Delete (и Enter) брали не тот пункт.

- `apply_config`: `hotlist` изменился при открытом Ctrl+D — строки перестраиваются (`hotlist_refresh`), курсор остаётся на том же пункте (по подписи и пути).
