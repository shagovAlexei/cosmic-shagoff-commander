# 123 — Перемещение в архив удаляет только упакованное

F6 в архив и Alt+F5 «Переместить в архив» после упаковки удаляли исходные папки целиком (`ops::delete` → `remove_dir_all`). Файл, появившийся в папке за время упаковки, пропадал, не попав в архив.

- `ops::delete_kept(sources, kept, h)`: обходит источники (ссылки не раскрывает), удаляет файл / ссылку, только если `kept` подтверждает, что он упакован; папку — только опустевшую. `completed` — источники, удалённые целиком.
- F6 в архив: `Change::Add { move_sources }`; `repack::rewrite` после переименования нового архива на место старого сверяет каждый файл с его копией в рабочем каталоге, которая и упакована (тот же тип, тот же размер). `Job::Repack.move_sources` убран.
- Alt+F5: после упаковки — список записей нового архива (`archive::packed`: путь → ссылка, размер), путь относительно `base`. Архив не читается (пароль на именах) — не удаляем ничего.
