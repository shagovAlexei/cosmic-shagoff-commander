# 18. Справка, «О программе», настройки

Статус: по запросу пользователя: «F1 и пункт Help — помощь и все горячие клавиши, красиво; About — о программе, авторе, ссылка на git, на будущее кнопка доната (Stripe); пункт с настройками — все настройки, включая язык, тему, включение/отключение функций».

## Решения

| Вопрос | Решение |
|---|---|
| Где показывать | Боковая панель окна (context drawer libcosmic), как в cosmic-files: панели с файлами остаются видны и работают. Escape или × закрывает. Одна панель за раз; та же клавиша/пункт ещё раз — закрыть |
| Справка | F1 (в TC — справка), кнопка «F1 Справка» первой в F-панели, меню «Справка → Справка». Сверху — что это за программа и главные правила (две панели, курсор и отметки, операции над отмеченными или над файлом под курсором). Дальше разделы карточками в стиле настроек COSMIC: слева действие, справа клавиша. Разделы: Навигация, Выделение, Файлы, Архивы, Поиск и сравнение, Вкладки и каталоги, Диски и сеть, Вид, Окно |
| Полнота | Тест: каждая клавиша из таблицы меню есть в справке |
| О программе | Меню «Справка → О программе». Виджет About libcosmic (фича `about`, без новых зависимостей): название, значок, версия, описание, автор, лицензия GPL-3.0, ссылки «Исходный код» и «Сообщить об ошибке» (GitHub; открываются через `xdg-open`) |
| Поддержать проект | Раздел под About: текст и кнопка «Поддержать проект». Адрес — константа `DONATE_URL` (Stripe Payment Link: для неё не нужен сервер, это просто ссылка на страницу оплаты Stripe). Пока она пуста — кнопка неактивна, подпись «Скоро: оплата картой через Stripe» |
| Настройки | Ctrl+, (так в приложениях COSMIC; в TC — без клавиши), меню «Конфигурация → Настройки». Всё, что есть в конфиге, кроме избранного (свой диалог Ctrl+D) и формата упаковки, который запоминается сам — он тоже здесь, как формат по умолчанию |
| Пункты настроек | **Интерфейс:** язык (системный / English / Русский) — сразу; тема (системная / светлая / тёмная) — сразу; кнопки F-клавиш внизу (вкл/выкл). **Панели:** скрытые файлы (= Ctrl+H); Ctrl+W на последней вкладке (ничего / перейти в домашний каталог); домашний каталог для этого (пусто = `~`). **Программы:** просмотр F3 (пусто = `xdg-open`), правка F4 (пусто = `cosmic-edit`); команда с аргументами через пробел. **Архивы:** формат упаковки по умолчанию |
| Запись | Каждое изменение сразу пишется в cosmic-config и применяется (тем же путём, что правка файла конфига руками) |
| Новые поля конфига | `language: String` ("" = системный), `app_theme: AppTheme` (System/Light/Dark), `show_fkeys: bool` (true). Все с `Default` — старые конфиги читаются |

## Известные ограничения

- Строки самой libcosmic (заголовки «Ссылки», «Лицензия» в «О программе», «Закрыть» в боковой панели) идут на языке системы: её переводчик закрыт для приложений.
- ↑/↓ при наборе в поле настроек двигают курсор панели (поле их не перехватывает).

## Тесты

- язык: "" → системные, "ru" → ru, неизвестный → системные;
- F1 → Help, Ctrl+, → Settings; повторно — закрыть; Escape закрывает панель, а не снимает фильтр;
- каждая клавиша меню описана в справке;
- изменение настройки меняет `config` (без диска в тестах): скрытые файлы, F-кнопки, Ctrl+W, программы (пробелы в поле не теряются), формат;
- смена темы/языка возвращает задачу (тема) и меняет язык `fl!`.

Вручную (TESTING.md): F1, О программе (ссылки открывают браузер), Настройки: язык и тема меняются сразу, F-кнопки скрываются, F4 открывает выбранный редактор.
