# 17. Главное меню

Статус: решения приняты по TC (пользователь: «действуй»).
Основа: [эталон TC](../tc-reference.md), пункт бэклога «Главное меню вверху окна».

## Решения

| Вопрос | Решение |
|---|---|
| Где | В заголовке окна слева (`header_start`), как в cosmic-files: места по высоте не занимает |
| Виджет | `cosmic::widget::menu::bar`; справа у пункта его клавиша (libcosmic берёт её из таблицы `KeyBind → действие`) |
| Действие пункта | Тот же `Action`, что и у клавиши: `Message::Key(action)`, идёт в активную панель. Пока открыт диалог или идёт операция, пункты ничего не делают — как клавиши |
| Одна правда | Таблица клавиш меню проверяется тестом против `keymap::action`: меню не может показать клавишу, которая делает другое |
| Пункты | Только то, что уже умеем. **Файлы:** F3, F4, F5, F6, Shift+F6, F7, F8, Shift+F8 · Alt+F5, Alt+F9 · Ctrl+M, Ctrl+Shift+D · Выход Alt+F4. **Выделение:** Num+, Num−, Ctrl+A, Ctrl+Num−, Num* · Shift+F2. **Команды:** Alt+F7, Ctrl+Shift+S · Ctrl+D, Alt+↓, Ctrl+U · Ctrl+S, Ctrl+R · Ctrl+T, Ctrl+W. **Сеть:** Ctrl+F, Ctrl+Shift+F · Alt+F1, Alt+F2. **Вид:** «Скрытые файлы» флажком (Ctrl+H) · сортировка Ctrl+F3…F6 |
| Конфигурация | Не в этой фазе: окна настроек ещё нет (отдельный пункт бэклога вместе с выбором языка) |
| Клавиатура | F9 / Alt для входа в меню — нет: виджет меню libcosmic не умеет навигацию с клавиатуры |

## Тесты

- каждая клавиша таблицы меню через `keymap::action` даёт то же действие;
- у каждого пункта меню есть клавиша в таблице (иначе справа было бы пусто);
- пункт меню (`Message::Key`) делает то же, что клавиша (F7 открывает диалог), а при открытом диалоге — ничего.

Вручную (TESTING.md): меню видно в заголовке, пункты с клавишами, «Скрытые файлы» отмечен в соответствии с Ctrl+H.
