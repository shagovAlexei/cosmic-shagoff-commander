# 22. Поиск файлов: «В панель», фильтры, регулярные выражения

Статус: решения приняты сами (пользователь: «погнали дальше» — следующий пункт бэклога «Поиск: «В панель», поиск в архивах, фильтры даты/размера/атрибутов, регулярные выражения»).

## Решения

| Вопрос | Решение |
|---|---|
| Объём | «В панель», фильтры размера и даты, регулярное выражение для текста. Поиск в архивах и фильтр атрибутов — нет (остаются в бэклоге: архивам нужен свой обход индексов) |
| «В панель» (Feed to listbox) | Кнопка в диалоге. Активная вкладка панели диалога показывает все найденное (не только первые 1000 строк списка): имя — путь от каталога поиска (`src/a.rs`), строка пути — «Результаты поиска: каталог». F3, F4, F5, F6, F8, Shift+F6, Ctrl+C, отметки работают как обычно: у записи полный путь. Ctrl+R и перечитывание после операций проверяют файлы заново (удалённые, переименованные и перенесённые пропадают, новые не появляются). Отмечены каталог и файл в нём — операция берёт только каталог. Ctrl+M и Shift+F2 в результатах недоступны (имена — пути). Backspace или `..` — в каталог поиска; любой переход (Enter на каталоге, кнопка диска, история, Ctrl+\\, избранное), даже в сам каталог поиска, — уходит из результатов. Корень результатов — каталог, где искали, а не поле «Где», исправленное после поиска |
| Размер | «Размер от, КБ» и «до, КБ», целые, включительно (`до 5` = до 5120 байт). Задан хоть один — каталоги не находятся (у них нет размера) |
| Дата | «Не старше, дней»: изменён за последние N суток (и каталоги тоже) |
| Регулярное выражение | Флажок; относится к тексту внутри файлов (не к маске имени — для имени есть маски). Синтаксис крейта `regex`, без учёта регистра — и для кириллицы. `^` и `$` — начало и конец строки. Файл читается окнами из целых строк с перекрытием до 4 КБ: совпадение длиннее 4 КБ на границе окон может быть пропущено |
| Ошибки | Не число в фильтре, «от» больше «до» или неверное выражение — текст ошибки вместо «Найдено», поиск не запускается |
| Запоминание | Новые поля не запоминаются между открытиями (маска, текст, регистр — как раньше) |

## Устройство

- `core::search::Query`: `regex`, `min_size`, `max_size`, `newer_than`; `Query::default()`; `search::regex(text, case)`.
- `core::listing::entries(paths, root)`: найденное как записи панели (`os_name` — полный путь, `cwd.join(os_name)` = файл).
- `app`: `Tab.results: Option<(root, Arc<Vec<PathBuf>>)>`; `load_tab` вместо чтения каталога берёт `entries`, если путь — `root`; любой другой путь снимает результаты.

## Тесты

Core: фильтр размера (каталоги не находятся), даты, регулярное выражение (кириллица без учёта регистра, с учётом, неверное); `entries` (имя от корня, полный путь, удалённый пропущен).
App: «В панель» берёт все результаты (больше 1000), Backspace возвращает в каталог поиска; неверный фильтр и неверное выражение не запускают поиск.
