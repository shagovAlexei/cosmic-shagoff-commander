# 65. Ctrl+Q на каталоге внутри архива

Как для обычного каталога (63): «Каталог: файлов N, каталогов M, размер», но считается по оглавлению
архива (`archive::usage` из кешированного индекса — ничего не распаковывается). Каталоги без своей
записи (`a/b/f` без `a/b/`) тоже считаются. `..` — по-прежнему пояснение.
