# 15. Сравнение файлов по содержимому

Статус: одобрен (пользователь: «действуй», решения по TC).
Основа: [архитектурный спек](00-architecture-design.md), [эталон TC](../tc-reference.md).

## Решения

| Вопрос | Решение |
|---|---|
| Клавиша | Ctrl+Shift+D (в TC «Compare by content» без клавиши по умолчанию) |
| Какие файлы | Ровно два отмеченных файла в активной панели; иначе файл под курсором слева и файл под курсором справа. Иначе — сообщение «Выберите два файла» |
| Вид | Две колонки: номер строки и текст слева и справа, строки выровнены; фон: удалено (только слева), добавлено (только справа), изменено (обе) |
| Алгоритм | Построчный diff (крейт `similar`, Myers), без игнорирования пробелов/регистра |
| Двоичные / большие | Если в первых 8 КиБ есть NUL, файл не UTF-8 или больше 20 МБ — побайтное сравнение, только итог «Одинаковые» / «Различаются» |
| Навигация | ↓ / «Следующее отличие», ↑ / «Предыдущее»; прокрутка к блоку; сверху «Отличий: N» или «Файлы одинаковые» |
| Сколько строк | Показываются первые 10 000 выровненных строк (дальше — строка «… ещё N»); счётчик отличий — по всему файлу |
| Правка | Нет (позже: копирование блока в другую сторону, редактирование) |

## Ядро: `diff.rs`

```rust
pub enum Kind { Same, Deleted, Inserted, Changed }
pub struct Row { pub kind: Kind, pub left: Option<(usize, String)>, pub right: Option<(usize, String)> }
pub enum Outcome { Text { rows: Vec<Row>, blocks: Vec<usize> }, Binary { same: bool } }
/// `blocks`: index of the first row of every run of non-Same rows.
pub fn compare(a: &Path, b: &Path) -> io::Result<Outcome>;
pub fn rows(a: &str, b: &str) -> (Vec<Row>, Vec<usize>);
```

Изменённый блок (удаление и вставка подряд) выравнивается попарно: строка i удаления рядом со строкой i вставки (`Changed`), остаток — `Deleted` или `Inserted`.

## Приложение

- keymap: Ctrl+Shift+D → `Action::CompareFiles`.
- Чтение и diff — в `spawn_blocking`; до результата диалог показывает «Сравнение…».
- `Dialog::Diff(Box<DiffDlg>)`: имена файлов, результат, текущий блок; моноширинный текст, строки фиксированной высоты, прокрутка к блоку через `scrollable::scroll_to`.
- Строки en и ru; tc-reference: Ctrl+Shift+D.

## Тесты

Core: одинаковые файлы; вставка, удаление, замена (выравнивание пар); блоки; пустой файл против непустого; двоичные одинаковые/разные; файл > лимита идёт побайтно; нет перевода строки в конце.
App: Ctrl+Shift+D с двумя отмеченными / с курсорами в двух панелях открывает диалог; без файлов — сообщение; ↓/↑ двигают текущий блок; результат с чужим id не применяется.
Вручную: две версии текста; двоичные файлы; одинаковые.

## Вне фазы

Редактирование и перенос блоков, игнорирование пробелов/регистра, сравнение по словам внутри строки, синхронная прокрутка как отдельные панели, сравнение каталогов в окне diff.
