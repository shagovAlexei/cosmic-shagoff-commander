# 62. Быстрый просмотр Ctrl+Q

Как в TC: Ctrl+Q (меню «Вид», кнопка `cm_SrcQuickview`) — вместо неактивной панели показывается файл
под курсором активной, во встроенном просмотрщике (текст / hex / картинка, кодировки, перенос).
Ещё раз Ctrl+Q — панель возвращается.

- Просмотр идёт за курсором: стрелки, мышь, быстрый поиск, смена каталога, Tab (просмотр переезжает
  на другую сторону и показывает файл новой активной панели).
- Клавиши остаются у панелей (F5, F8, Enter… работают как обычно); у просмотра — только кнопки режима,
  кодировки и переноса. Поиск F7, N / P, Esc — у полноэкранного F3.
- Каталог, `..`, файл внутри архива — пояснение вместо содержимого.
- F3 при открытом Ctrl+Q — обычный полноэкранный просмотр (быстрый закрывается).

Где: `Lister.quick: Option<PathBuf>`; `App::quick_follow` после каждого сообщения (как
`save_state`); `App::viewer()` — открыт ли полноэкранный; `view::view` рисует просмотр вместо
неактивной панели.

Не делаем: сведения о каталоге (размер содержимого, как в TC), просмотр файлов внутри архива.
