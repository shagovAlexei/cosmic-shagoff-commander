# 157. Найденное в архивах — «В панель»

ROADMAP «Поиск, дальше: найденное в архивах — в «В панель»». Было: «В панель» отбрасывала файлы из
архивов («в панель не попадает», 22 / 33). TC кладёт в список и их.

- Строки: файлы на диске — как раньше (`listing::entries`), из архивов — из оглавления
  (`archive::found_entries`: имя — путь от корня поиска, `a.zip/docs/f.txt`; `os_name` — весь путь).
- F3 / F4 / Enter на такой строке: файл лежит не в каталоге панели — `located` берёт его каталог из
  пути строки, дальше как внутри архива (извлечь во временный, открыть).
- F5 / F6: источники из разных мест разбиваются (`archive::split_by`): каталог архива — своя задача
  извлечения, файлы на диске — одна; задачи идут в очередь. F8: перепаковка на архив.

## Не делаем

- Ctrl+M и Shift+F2 в результатах — по-прежнему «не поддерживается».
