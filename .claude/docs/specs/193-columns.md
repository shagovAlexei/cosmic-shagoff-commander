# 193. Колонки полного вида

TC: `cm_CustomColumnConfig`; режимы вида (`cm_ConfigViewModes`, `cm_*CustomView…`) — не в этой фазе.

- `core::columns::Col` — Ext, Size, Date, Attr, Owner, Group; `Config.col_set` держит ключи показанных (по умолчанию как раньше — первые четыре), порядок фиксирован (`Col::ALL`), имя всегда первое.
- Ширины: у первых четырёх — `Config.columns`, правятся перетаскиванием границы в заголовке; у Владельца и Группы — постоянные (`Col::FIXED_W`). `viewport::visible_cols` берёт срез ширин: узкая панель убирает колонки справа, как раньше.
- Вид → «Колонки» ▸ (флажки, `Action::ToggleCol`). Владелец и группа из `Entry.owner` и `/etc/passwd`, `/etc/group` (`Owners::user` / `group`). Сортировки по ним нет.
- ResetColumns возвращает и набор. Не делаем: порядок колонок, режимы вида по маске, свои колонки по содержимому, ширину Владельца / Группы.
