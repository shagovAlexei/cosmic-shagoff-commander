# 26. Сеть: сохранённые соединения, обзор, отмена

Статус: решения приняты сами (пользователь: «давай дальше» — следующий пункт бэклога «Сеть: обзор сетевого окружения (smb/avahi), сохранённые соединения и пароли (keyring), отмена подключения»).

## Решения

| Вопрос | Решение |
|---|---|
| Сохранённые | После удачного Ctrl+F адрес запоминается в конфиге (`connections`), последний — первым, без повторов, не больше 20. Пароль из адреса (`sftp://bob:pw@host`) вырезается до сохранения. В диалоге Ctrl+F — список «Сохранённые»: клик подставляет адрес, корзина — забыть |
| Пароли (keyring) | Нет: нужен клиент Secret Service по D-Bus (новая зависимость). Пароль вводится каждый раз; позже отдельной фазой |
| Обзор сети | Кнопка «Обзор сети»: `gio list network:///` (сеть Windows, серверы, объявленные в локальной сети через avahi) — имя и адрес; клик подставляет адрес. Один уровень, без захода внутрь `smb:///` |
| Отмена | Esc во время «Подключение…» (без открытых диалогов) останавливает `gio mount`: процесс и всё, что он запустил (своя группа процессов), получают SIGKILL. В строке состояния «Подключение отменено». Монтирование, которое gvfs уже начал сам, может доделаться в фоне |
| Чей результат | Ctrl+F отвечает своим сообщением с адресом: монтирование флешки из Alt+F1 в это время не путается с подключением |

## Тесты

Core: `remember` (первым, без повтора, предел, без пароля), `without_password`, разбор `network:///` (без адреса — пропуск), отмена `talk` (скрипт-заглушка со `sleep`, отмена — быстро, вместе с дочерним процессом). Настоящий `gio` в тестах не запускается.
App: после удачного подключения адрес сохранён без пароля, Alt+F1 в это время его не сохраняет; в следующем Ctrl+F он в списке, клик подставляет; Esc ставит флаг отмены, «Подключение отменено», адрес не сохранён; «забыть» и результаты обзора.
