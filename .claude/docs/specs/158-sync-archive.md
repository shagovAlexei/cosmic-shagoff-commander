# 158. Синхронизация с архивом

ROADMAP «Синхронизация, дальше: с архивом». Было: Ctrl+Shift+S при панели в архиве — «только для
чтения». TC синхронизирует и с архивом.

- Одна сторона — папка в архиве (zip, tar.*, 7z): `sync::list` читает её из оглавления
  (`listing::scan`, ничего не распаковывая). «По содержимому» там не сравнивает: такие файлы — «различаются».
- План → задачи (`sync::archive_plan`): из архива — одно извлечение (имена от её папки, вложенные
  пути), в архив — добавление на каждый целевой каталог (`inner/` — «в эту папку»), удаление в архиве —
  одна перепаковка, на диске — в корзину. Задачи — в очередь.
- Обе стороны в архивах — по-прежнему «только для чтения».
- Попутно: конфликт при добавлении в архив называл путь временного каталога; вопросы и прогресс
  перепаковки теперь называют пути через архив (`repack::Shown`).
