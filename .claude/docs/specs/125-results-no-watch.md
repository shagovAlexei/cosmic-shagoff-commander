# 125 — Результаты поиска не перечитываются на каждое изменение

Вкладка с результатами поиска («В панель») или ветвью (Ctrl+B) на каждое событие watcher в своём каталоге перечитывала все результаты — `stat` каждого, миллион для большого дерева.

- `Message::Changed`: вкладка с `results` не перечитывается. Обновить — Ctrl+R (TC тоже не обновляет такие списки сам).
- Обычный каталог — как раньше.
