# 46. Окно «Файл уже существует» как в TC

Ручная проверка (пункт 19): окно конфликта непохоже на TC.

- Сверху, как в TC «Подтверждение замены»: «Заменить:» — путь существующего, его размер и дата; «Файлом:» — то же у нового. Более новый — дата цветом акцента и «новее»; больший — размер цветом.
- Кнопки — сетка 3×3 одинаковой ширины: Заменить (основная), Заменить все, Заменить старые / Пропустить, Пропустить все, Отмена / поле имени, Переименовать, Переименовать все. Ответы те же (`Resolution`).
- Кнопки — `button::custom`: у текстовой кнопки libcosmic ширина уходит строке с подписью, сама кнопка остаётся по содержимому.

Не делаем: «Сравнить» (окно сравнения посреди операции), «Дописать», просмотр картинок.
