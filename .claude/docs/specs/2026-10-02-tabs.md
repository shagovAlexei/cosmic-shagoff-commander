# Фаза 3: вкладки

Дата: 2026-10-02. Статус: одобрен.
Основа: [архитектурный спек](2026-10-02-architecture-design.md), [фаза 2](2026-10-02-dual-pane.md), [эталон TC](../tc-reference.md) → «Вкладки».

## Решения

| Вопрос | Решение |
|---|---|
| Полоса вкладок | Показывается только при 2+ вкладках (TC по умолчанию) |
| Новая вкладка (Ctrl+T) | Вставляется сразу после текущей и становится активной. Это копия текущей: тот же каталог, сортировка, курсор и прокрутка; каталог заново не читается |
| Закрытие (Ctrl+W, средняя кнопка, двойной клик по вкладке) | Последнюю закрыть нельзя. Если закрыть активную, активной становится правая соседка, а если её нет — левая |
| Переключение | Ctrl+Tab — следующая, Ctrl+Shift+Tab — предыдущая, по кругу. Клик по вкладке выбирает её и делает панель активной |
| Заголовок вкладки | Имя каталога, для корня `/`. Ширина до 160 px, длинное имя обрезается «…» |
| Модификаторы (техдолг фазы 2) | Клавиша срабатывает только при точном совпадении модификаторов. Shift+Tab, Alt+Enter, Shift+стрелки ничего не делают — Shift+стрелки займёт фаза 4. Любая комбинация с Alt или Super не обрабатывается |

## Ядро

`tabs.rs` — `Tabs<T> { items: Vec<T>, active: usize }`. Список никогда не бывает пустым.

- `new(first)`;
- `items()`, `items_mut()`, `active_index()`, `active()`, `active_mut()`;
- `open_after(item)` — вставить сразу после активной и сделать её активной;
- `close(i) -> bool` — `false`, если вкладка последняя или индекс за пределами. Активная сдвигается так, как описано в таблице выше;
- `select(i)` — индекс за пределами игнорируется;
- `next()` / `prev()` — по кругу.

Кроме того:
- `Panel` получает `Clone`;
- `format::dir_title(&Path) -> String` — последний компонент пути или `/`.

## Приложение

- `Pane` переименован в `Tab` и получил стабильный `id: u64` (счётчик в `App`). `App.panes: [Tabs<Tab>; 2]`.
- Результат чтения `Listed` несёт `id` вкладки. Если вкладки с таким `id` больше нет, результат отбрасывается. Если вкладка неактивна, результат всё равно применяется к ней. Проверка устаревшего пути (`pending`) работает внутри вкладки, как раньше.
- `Scrolled` относится к активной вкладке панели.
- При смене вкладки (выбор, Ctrl+Tab, закрытие, новая вкладка) вызывается `scroll_to(offset)` этой вкладки, чтобы восстановить её прокрутку.
- Keymap:
  - Ctrl+T → NewTab, Ctrl+W → CloseTab — по физическим `KeyT` и `KeyW`;
  - Ctrl+Tab → NextTab, Ctrl+Shift+Tab → PrevTab;
  - для всех остальных клавиш модификаторы должны совпадать точно.
- Полоса вкладок стоит над строкой пути. Стиль активной вкладки тот же, что у курсора: акцент, если панель активна, иначе акцент с прозрачностью 35%.

## Вне объёма

Перетаскивание вкладок, закреплённые вкладки, сохранение вкладок между запусками (фаза 6), Ctrl+↑ (открыть каталог под курсором в новой вкладке) — бэклог.

## Тесты

- **Ядро:** все операции `Tabs`, особенно запрет закрыть последнюю вкладку и сдвиг активной при закрытии левее, правее и самой активной; `dir_title`.
- **Keymap:** новые клавиши, в том числе в русской раскладке; Shift+Tab, Alt+Enter, Shift+↓ и Ctrl+Shift+R → `None`.
