# 58. «Открыть с помощью»: все программы, история команд

Продолжение 56–57.

## Поведение

- **«Все программы…»** — строка перед «Другой программой…». Enter / щелчок — список заменяется всеми
  установленными программами (`applications/*.desktop` во всех `data_dirs`, первый каталог главнее,
  без `Hidden` / `NoDisplay` / не `Type=Application`), по имени без учёта регистра. Окно остаётся,
  курсор — в начало; «По умолчанию» работает и тут (программа станет умолчанием для типа файла).
- В списке по типу `NoDisplay`-программы остаются (это обработчики типов, они скрыты только из меню); `Hidden` и не-программы пропадают везде.
- **История «Открыть командой»:** окно открывается с последней командой, ↑ / ↓ листают прежние (как
  маски Num+); хранится в состоянии (`State.other_cmds`), без повторов, последняя первой.

## Не делаем

- Поиск по буквам в длинном списке программ, `applications/` в подкаталогах.
