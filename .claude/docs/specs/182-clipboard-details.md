# 182. Буфер: пути панелей, каталоги файлов, сведения о файлах

TC: `cm_CopySrcPathToClip`, `cm_CopyTrgPathToClip`, `cm_CopyPathOfFilesToClip`, `cm_CopyFileDetailsToClip`, `cm_CopyHdrFileDetailsToClip`, `cm_SaveDetailsToFile`, `cm_SaveHdrDetailsToFile`. Клавиш в TC нет.

- Выделение → подменю «Копировать в буфер»: имена и имена с путём (были), путь этой / другой панели, каталоги выделенных файлов (по разу, в порядке панели), сведения о файлах (с заголовками); после линии — «Сохранить сведения (с заголовками) в файл…».
- Сведения — `format::details_table`: колонки как в панели (имя без расширения / `[каталог]`, расширение, размер, дата, атрибуты) через Tab, строка на файл; размер каталога — посчитанный, иначе `<DIR>`. В буфер — выделенные (или под курсором, `Panel::target_entries`), в файл — все строки, кроме `..`.
- Файл: окно ввода с `details.txt` в каталоге панели (в архиве — рядом с ним), существующий не перезаписывается (`write_new`, как у выделения 181). Всегда UTF-8 (варианты A / W не нужны).
- Пути панелей — показываемые (`App::shown`: вложенный архив как `outer.zip/…/inner.zip`).
