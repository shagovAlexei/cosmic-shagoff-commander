# 148. Терминал: внешний на выбор и встроенный

Запрос пользователя: встроенный терминал вместо командной строки, включается в меню, по умолчанию
выключен; терминал по умолчанию в системе или выбор из установленных.

Ограничение: на Wayland чужое окно (cosmic-term, alacritty, kitty, foot) в наше не встроить —
XEmbed нет. Решение пользователя: **свой встроенный терминал + выбор внешнего из установленных**.

TC: своего терминала нет; командная строка, Shift+Enter — `cmd /k`, «Командная строка → Открыть
консоль» (`cm_ExecuteDOS`). Double Commander — встроенный терминал под панелями.

## Фаза A (148): внешний терминал на выбор

- `core::terminals`: установленные терминалы — `.desktop` с `TerminalEmulator` в `Categories`
  (как `openwith::all_apps`), плюс системный по умолчанию: `x-terminal-emulator` (Debian
  alternatives), иначе `$TERMINAL`, иначе первый найденный. У каждого — как передать команду:
  таблица известных (`cosmic-term -e`, `gnome-terminal --`, `konsole -e`, `xfce4-terminal -x`,
  `alacritty -e`, `kitty`, `foot`, `wezterm start --`, `xterm -e`), неизвестный — `-e`.
  Каталог — запуском в нём (`current_dir`), у всех работает.
- Конфиг `terminal_app: String` — `""` = системный по умолчанию, иначе id `.desktop`.
  Старое `terminal: Vec<String>` (Shift+Enter) остаётся для ручной правки: непустое и не
  умолчание — главнее (старые установки не меняются).
- Меню «Команды → Терминал» — подменю: «По умолчанию (имя)», затем установленные (флажок у
  выбранного). «Команды → Открыть терминал» — окно в каталоге активной панели.
- Shift+Enter в командной строке — в выбранном терминале.
- Кнопка тулбара `cm_ExecuteDOS` — то же «Открыть терминал».

## Фаза B (149): встроенный терминал

- Код терминала — из cosmic-term (`terminal.rs`, `terminal_box.rs`, `terminal_theme.rs`,
  `mouse_reporter.rs`; GPL-3.0, источник указан вверху файлов) в `crates/app/src/term/`:
  один терминал, без `pane_grid` / вкладок / профилей / поиска; `alacritty_terminal` в зависимостях.
- Конфиг `term_builtin: bool` (по умолчанию `false`), `term_shell: String` (`""` = `$SHELL`,
  иначе путь из `/etc/shells`), `term_height: f32` (строк, по умолчанию 12).
- Меню «Вид → Встроенный терминал» (флажок), «Команды → Оболочка» — подменю: «По умолчанию
  ($SHELL)», затем `/etc/shells` без повторов (`/bin/x` и `/usr/bin/x` — один).
- Включён: под панелями **вместо командной строки** (строка `path>` скрыта; F-кнопки на месте).
  Оболочка стартует при первом показе в каталоге активной панели; закрыта (`exit`) —
  перезапуск при следующем показе / щелчке.
- Каталог: при смене каталога активной панели, если оболочка простаивает (у pty нет своего
  процесса переднего плана: `tcgetpgrp(pty) == pid оболочки`), — ` cd -- 'путь'` + Enter
  (пробел впереди — не в историю bash/zsh с `ignorespace`). Занята (идёт программа) — не трогаем.
  Внутри архива — не следует (пути нет на диске).
- Фокус: щелчок в терминал — клавиши идут ему (все, кроме Ctrl+O); щелчок в панель — панелям.
  **Ctrl+O** (TC: «спрятать панели», посмотреть вывод консоли) — терминал на всю высоту /
  обратно; из панелей Ctrl+O ещё и отдаёт фокус терминалу.
- Высота — перетаскиванием верхней кромки (как разделитель панелей), запоминается.
- Копировать / вставить — Ctrl+Shift+C / Ctrl+Shift+V (как cosmic-term); колесо — прокрутка
  истории; цвета — тема COSMIC (тёмная / светлая), шрифт — моноширинный системный.
- Выключен — ничего не запускается, командная строка как была.

## Не делаем (пока)

Несколько терминалов / вкладки терминала, поиск по выводу, свои цветовые схемы, переназначение
клавиш терминала.

## Сделано иначе, чем в спеке (по живой проверке)

- Фаза A: выбор терминала — список (`Dialog::List`), не подменю: вложенные меню libcosmic во всплывающих окнах Wayland у нас не проверены.
- Фаза B: высота — в строках (`term_rows`, по умолчанию 8), не в пикселях.
- Оболочка стартует, только когда каталог активной панели прочитан, и сразу в нём (иначе `cd` набирался до приглашения).
- «Ждёт у приглашения» — не только передний план (`tpgid`): после Enter zsh ещё выполняет хуки, держа его; поэтому у оболочек с редактором строки ещё и терминал в «сыром» режиме (`ICANON` снят; `tcgetattr` на `/proc/pid/fd/0`). Иначе `cd` уходил во время команды (в `vim` — его вводом).
- Фокус: окно потеряло клавиатуру (Alt+Tab) — при возврате фокус терминала восстанавливается; щелчок по панели снимает его явно (строки панели забирают нажатие раньше терминала).
- Сфокусированный терминал забирает все клавиши, кроме Ctrl+O, — Enter не доходит до панелей.
- Ревью: перед `cd` строка очищается (Ctrl+E Ctrl+U) — недонабранная команда не выполняется с ним (bash / zsh вернут её Ctrl+Y); пока терминал в фокусе (`TermFocused`), клавиши, которые `route_event` пропускает при любом статусе (F-клавиши, Ctrl+…, Esc, Alt+L), приложение не берёт; размер шрифта и тема применяются к запущенному; выключение любой дорогой (`apply_config`) закрывает оболочку; оболочка не запустилась — не повторяет сама; занятая — проверяется не чаще 300 мс.
- Ctrl+` — терминал вкл / выкл (клавиша по просьбе пользователя), включённый сразу в фокусе; пропускается из терминала (`term::pass`). Двойной уход окна из фокуса подряд больше не теряет фокус терминала.
