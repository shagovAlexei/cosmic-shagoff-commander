# 25. Сравнение файлов: пробелы и регистр, отличия в строке, перенос блоков

Статус: решения приняты сами (пользователь: «да» — следующий пункт бэклога «Сравнение файлов: правка и перенос блоков, игнорировать пробелы/регистр, отличия внутри строки»).

## Решения

| Вопрос | Решение |
|---|---|
| Объём | Флажки «Без учёта пробелов», «Без учёта регистра»; подсветка отличия внутри изменённой строки; копирование блока в другую сторону и «Сохранить». Свободная правка текста — нет (позже) |
| Пробелы | Серии пробелов и табуляций считаются одним пробелом, в начале и в конце строки не считаются (как `diff -b` плюс хвостовые). Показывается текст как есть |
| Регистр | Сравнение строк в нижнем регистре (и для кириллицы) |
| С флажками | «Отличаются только концы строк» не говорится (строки равны «достаточно») |
| Отличие в строке | У изменённой пары строк — общее начало и общий конец, середина подсвечена ярче (как в TC — без пословного сравнения) |
| Перенос блока | «Блок →» / «← Блок»: строки текущего блока отличий на другой стороне заменяются строками этой стороны (блок, которого на другой стороне нет, вставляется; блок, которого нет на этой, удаляется на другой). Концы строк (CRLF / LF) и последний перевод строки — как были у изменяемого файла. Сравнение сразу пересчитывается, текущий блок — ближайший |
| Перенос по показанному | Блок берётся из строк на экране, а не из нового сравнения (сравнение, оборванное по времени, могло бы выровнять иначе). Блок, уходящий за 100 000 показанных строк, не переносится. Остальные строки файла остаются байт в байт (смешанные CRLF/LF не трогаются) |
| Сохранить | Пишет изменённые стороны через временный файл и переименование (сбой не оставит полфайла), права файла сохраняются; через ссылку — в настоящий файл, ссылка остаётся. Отказ (с сообщением): файл только для чтения, у файла другие жёсткие ссылки, файл изменён на диске после сравнения («сравните заново»). Пока пересчёт после переноса не закончился, сохранять нечего и флажки не переключаются. Владелец, ACL и xattr не сохраняются (как у операций) |
| Закрыть с несохранённым | Первое Esc / «Отмена» только предупреждает («Не сохранено: ещё раз Esc — закрыть без сохранения»), второе закрывает. Закрытие окна (× / Alt+F4) libcosmic отменить не даёт — несохранённое теряется |

## Тесты

Core: флажки (показ как есть; только пробелы — регистр всё ещё отличие); `inline` (середина, вставка, кириллица по границам символов, без перекрытия); `copy_block` в обе стороны, вставка в конец, удаление, CRLF и последний перевод строки цели; `save` (содержимое, права, без временного файла).
App: перенос блока помечает сторону несохранённой; «Сохранить» во время пересчёта ничего не пишет; после результата пишет файл; первое Esc предупреждает, после сохранения закрывает.
