# 61. Горячие буквы `&` в избранном

Как в меню TC: в названии избранного `&` перед буквой делает её горячей (`&Документы`, `My &Work`),
`&&` — просто `&` (`R&&D` → «R&D»). В меню Ctrl+D `&` не показывается, горячая буква подчёркнута.

- Горячая буква одна на всё меню — нажатие сразу выбирает пункт (каталог открывается, подменю —
  входит), без Enter.
- Одна буква у нескольких пунктов — курсор ходит по ним, ничего не открывая (как в Windows).
- Без горячей буквы — обычный переход по первой букве (59).
- Только Ctrl+D: в истории и дисках `&` — часть имени каталога.

Где: `core::quicksearch::hotkey` (показанное имя + буква и её место); `menu_row_with(hot)` —
подчёркивание через `rich_text`; `Message::CmdType` для `ListKind::Hotlist`.
