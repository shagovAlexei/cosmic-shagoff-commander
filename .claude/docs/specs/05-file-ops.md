# Фаза 5: файловые операции

Дата: 2026-10-02. Статус: одобрен.
Основа: [архитектурный спек](00-architecture-design.md), [фаза 4](04-selection.md), [эталон TC](../tc-reference.md) → «Файловые операции».

## Отличие от архитектурного спека

Движок свой, на `std::fs`, а не скопированный из cosmic-files. Их `operation/recursive.rs` построен на `compio` (io_uring) и привязан к их `App`, так что адаптация заняла бы столько же кода, сколько свой движок, и потянула бы тяжёлую зависимость. Решение принято пользователем на брейншторме.

## Решения

| Вопрос | Решение |
|---|---|
| Прогресс | Модальный диалог: текущий файл, полоса, «X из Y», «Отмена». Панели ждут. Фоновая очередь в бэклоге |
| Конфликт | Заменить / Пропустить / Заменить все / Пропустить все / Заменить старые / Отмена, с размером и датой обоих файлов. «Заменить старые» применяется ко всем дальнейшим конфликтам: заменяет, если источник новее |
| Ошибка | Повторить / Пропустить / Отмена. Сделанное не откатывается |
| На что действует | `Panel::targets()`: отмеченные, а если их нет — файл под курсором. `..` не берётся никогда |
| Цель F5/F6 (как в TC) | Существующий каталог — каждый источник кладётся внутрь. Один источник и цели нет — это новое имя. Несколько источников и цели нет — каталог создаётся. Относительный путь считается от каталога исходной панели |
| Защита | Каталог внутрь самого себя и файл на самого себя — ошибка до старта |
| Копирование | Без следования по симлинкам: симлинк копируется как симлинк. Права и дата изменения файла сохраняются. Запись идёт во временный `<имя>.shagoff-part`, затем `rename`, поэтому прерванная замена не портит существующий файл |
| Перенос | Сначала `rename`. При другом диске или слиянии с существующим каталогом — копирование и удаление: каждый источник удаляется только после успешного копирования, пропущенное остаётся на месте |
| Удаление | F8 и Delete — в корзину (крейт `trash`, freedesktop). Shift+F8 и Shift+Delete — безвозвратно, без разыменования симлинков. Всегда с подтверждением |
| F7 | Создаёт каталог (`create_dir_all`, можно `a/b`). Курсор встаёт на созданный каталог |
| Переименование (Shift+F6, F2) | Перенос одного файла в тот же каталог под новым именем. Занятое имя ведёт в диалог конфликта. Курсор встаёт на новое имя. То же имя — ничего не делать |
| После операции | С обработанных источников снимаются отметки. Обе панели перечитываются |
| Ctrl+T | Новая вкладка без отметок (техдолг фазы 4) |

## Ядро — `ops.rs`

```rust
pub trait Handler {
    fn progress(&mut self, done: u64, total: u64, current: &Path);
    fn conflict(&mut self, src: &FileInfo, dst: &FileInfo) -> Resolution;
    fn error(&mut self, path: &Path, err: &io::Error) -> ErrorChoice;
    fn cancelled(&self) -> bool;
}
pub fn plan(sources: &[PathBuf], dest: &Path) -> Result<Vec<(PathBuf, PathBuf)>, PlanError>;
pub fn transfer(method: Method, pairs: &[(PathBuf, PathBuf)], h: &mut dyn Handler) -> Report;
pub fn delete(paths: &[PathBuf], permanent: bool, h: &mut dyn Handler) -> Report;
```

- `Report { cancelled: bool, completed: Vec<PathBuf> }` — `completed` содержит источники, обработанные полностью. Они нужны, чтобы снять отметки.
- В `transfer` прогресс считается в байтах, в `delete` — в элементах.
- Движок синхронный, его запускают в рабочем потоке. С интерфейсом он общается только через `Handler`.

## Приложение

- Клавиши:
  - F5 → Copy, F6 → Move;
  - Shift+F6 и F2 → Rename;
  - F7 → Mkdir;
  - F8 и Delete → Delete;
  - Shift+F8 и Shift+Delete → DeletePermanent.

  Кнопки F5–F8 в нижнем ряду становятся активными.
- Диалоги собраны в одно перечисление `Dialog` (туда же переезжает маска из фазы 4):
  - ввод для Copy, Move, Mkdir, Rename;
  - подтверждение удаления: Enter подтверждает, для безвозвратного кнопка destructive;
  - конфликт;
  - ошибка.

  Пока операция идёт и другого диалога нет, показывается диалог прогресса.
- **Рабочий поток.** Обработчик шлёт события в UI через неограниченный канал (`Task::run`) и ждёт ответ на конфликт или ошибку через `std::sync::mpsc`. Отмена — общий `AtomicBool`. Прогресс отправляется не чаще 10 раз в секунду, плюс финальное значение.
- **Escape:**
  - диалог ввода или подтверждения — закрыть;
  - конфликт или ошибка — ответить «Отмена»;
  - прогресс — отменить операцию.

  Пока открыт диалог или идёт операция, клавиши панелей не действуют.
- Новые строки интерфейса добавляются в `en` и `ru`.

## Вне объёма

Фоновая очередь, «Переименовать» и «Сохранить оба» в конфликте, Shift+F5, групповое переименование, дата у каталогов при копировании, `~` в пути цели.

## Тесты

- **Ядро** (во временных каталогах):
  - `plan`: внутрь каталога, новое имя, несколько источников в несуществующую цель, внутрь себя, на себя;
  - копирование: файл, дерево, симлинк, права и дата;
  - конфликт: Заменить, Пропустить, Заменить все, Пропустить все, Заменить старые, Отмена;
  - отмена посреди файла: существующий целевой файл не тронут, `.shagoff-part` удалён;
  - перенос: rename и слияние с существующим каталогом через копирование и удаление;
  - ошибка чтения → Пропустить, остальное скопировано;
  - безвозвратное удаление дерева;
  - `targets()`, `unmark()`.
- **Keymap:** новые клавиши.
- **Вручную:** корзина и всё, что связано с интерфейсом.
