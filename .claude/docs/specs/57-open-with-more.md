# 57. «Открыть с помощью»: значки, другая программа, по умолчанию

Продолжение 56.

## Поведение

- **Значки.** Слева в строке — значок программы из `Icon=` её `.desktop` (имя из темы или абсолютный
  путь). Нет значка — пустое место той же ширины, строки не скачут.
- **«Другая программа…»** — последняя строка списка, после черты. Enter / щелчок → поле ввода
  команды (`foot -e less`, `gimp`…). Команда идёт через `sh -c` в каталоге панели, файлы дописываются в
  конец отдельными словами в кавычках (`cmdline::quote`). Пустая команда — ничего.
- **«По умолчанию»** — кнопка в окне списка: программа под курсором становится программой по
  умолчанию для этого типа (`gio mime ТИП ID.desktop`), окно остаётся открытым, итог — в строке
  состояния. На «Другой программе…» кнопка ничего не делает.

## Где

- `core::openwith`: `App.icon`; `apps` возвращает и тип (`Found { mime, apps }`); `set_default(mime,
  desktop)`; `other_line(cmd, files)` — строка для `sh -c`.
- `app`: `ListItem.icon`; `Item::Other`; `InputOp::OpenWith`; `Message::OpenWithDefault`.

## Не делаем

- Запоминание введённых команд, выбор программы из полного списка всех `.desktop`.
