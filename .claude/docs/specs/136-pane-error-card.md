# 136 — Ошибка чтения панели — тоже карточкой

В 134 карточкой стали сообщения окна (`App.status`), а ошибка чтения каталога (`Tab.error`) осталась в половине строки состояния своей панели и обрезалась.

- `status_popup`: карточки ошибок обеих панелей (если есть), затем сообщение окна; у каждой свой × (`Message::Dismiss(Some(side))` / `Dismiss(None)`).
- `pane_status`: вместо ошибки — итоги.
- Время жизни прежнее: ошибка панели — до следующего действия в ней.
