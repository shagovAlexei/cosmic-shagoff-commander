# 56. «Открыть с помощью» в контекстном меню

## Что

Правый щелчок по файлу → «Открыть с помощью…» → список программ, которые умеют открывать этот тип
файла (как в проводнике Windows / Nautilus). В TC такого пункта своего нет — он берёт его из меню
оболочки Windows; у нас меню своё, поэтому пункт свой.

## Поведение

- Пункт есть в меню строки для файлов (и архивов), не для каталогов. Клавиши нет (как в TC).
- Тип файла — `gio info -a standard::content-type` (по содержимому, не только по расширению).
- Программы — `gio mime <тип>`: сначала программа по умолчанию, затем остальные (зарегистрированные и
  рекомендованные), без повторов. Имя — `Name[язык]` / `Name` из `.desktop` (поиск в
  `$XDG_DATA_HOME/applications` и `$XDG_DATA_DIRS/*/applications`); не нашли `.desktop` или
  `Hidden=true` — программа пропускается. Справа в строке — имя `.desktop`-файла.
- Окно — тот же TC-список, что Alt+F1 / Ctrl+D (`Dialog::List`, вид `OpenWith`): ↑/↓, Enter, щелчок, Esc.
- Запуск: `gio launch <файл .desktop> <файлы…>`; файлы — `Panel::targets()` (отмеченные или под
  курсором; каталоги среди отмеченных тоже передаются — программа решает сама).
- Внутри архива — сообщение «Не внутри архива» (файлы ещё не распакованы), окно не открывается.
- Программ нет / `gio` упал — сообщение в строке состояния.

## Где

- `core::openwith`: разбор вывода `gio info` и `gio mime`, разбор `.desktop`, поиск файла по id,
  `apps(file, lang)` (запускает `gio`, вызывается в `spawn_blocking`), `launch_argv`.
- `app`: `Action::OpenWith`, `ListKind::OpenWith`, `Message::OpenWithApps`.

## Не делаем

- Значки программ в списке, «Другая программа…» (ввод команды), запоминание выбора как программы
  по умолчанию, `.desktop` в подкаталогах `applications/` (id `kde-foo` → `kde/foo.desktop`).
