# 133 — Избранное: папка с именем не в UTF-8

Настройки — текст (RON): путь не в UTF-8 в них не записать. «Добавить текущую папку» для такой папки молча ничего не сохраняло, ошибка была только в логе.

- Добавление такой папки отказывает сразу: диалог закрыт, в строке состояния `hotlist-not-utf8`.
- Любая ошибка записи избранного (`save_hotlist`) — в строке состояния (`config-not-saved`), не только в логе.
