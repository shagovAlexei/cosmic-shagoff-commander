# 189. Части окна и ширина панели

TC: `cm_VisButtonBar`, `cm_VisDriveButtons`, `cm_VisDirTabs`, `cm_VisCurDir`, `cm_VisTabHeader`, `cm_VisStatusBar`, `cm_VisCmdLine`, `cm_VisKeyButtons`, `cm_50Percent`, `cm_100Percent`.

- `config::Part` — восемь частей окна; `Config.show_*` на каждую (новые: панель инструментов, кнопки дисков, вкладки, строка пути, заголовки колонок, строка состояния — все по умолчанию да; F-кнопки и командная строка — прежние `show_fkeys` / `show_cmdline`). `Config::shows` / `shown`, `Setting::Show(Part, bool)` вместо `ShowFkeys` / `ShowCmdline`.
- Вид → «Части окна» ▸ — флажки `Action::Vis(Part)`; кнопки панели инструментов с именами TC.
- Скрытая строка пути показывается, пока её правят (`cm_EditPath`). Скрытая строка состояния — только итоги; сообщения (карточки) остаются.
- «Панели по 50 %» (`Split50`): разделитель посередине, обе панели. «Панель на 100 %» (`Wide`, флажок): только активная панель на всю ширину (Tab показывает другую), строка состояния — её половина; снова — обе. `State.wide` хранит это между запусками.
- Не делаем: прочие `cm_Vis*` (плоский интерфейс, две строки дисков, кнопки истории); Ctrl+Q при 100 % — вторая панель скрыта, просмотр не виден.
