# 70. Операции: маска имени, «Переименовать старый», порядок очереди

Из ROADMAP «Операции, дальше». Как в TC (`tc-reference.md`: F5, Shift+F5, конфликт, окно прогресса).

1. **Маска в цели F5 / F6** (`core::ops::mask_name`, `plan`). Последняя часть цели с `*` или `?` —
   маска: каждый источник копируется в каталог этой части под именем по маске. С точкой — имя и
   расширение отдельно (по последней точке), без точки — всё имя. `*` — остаток части источника,
   `?` — её следующий символ, прочее — буквально (не съедает символ). Пустое / `.` / `..` → `BadName`.
2. **Shift+F5 при отметках** — диалог Copy для всех отмеченных с `*.*` (относительно каталога панели).
   Без отметок — как раньше (файл под курсором, его имя).
3. **«Переименовать старый»** (`Resolution::RenameOld`): существующий файл — `rename_noreplace` в
   первое свободное `unique_name`, затем запись под исходным именем. При упаковке поверх архива —
   так же. В диалоге конфликта — вместо «Отмена» во втором ряду; «Отмена» — кнопка диалога (Esc).
4. **Порядок очереди**: ↑ на строке очереди (`Message::QueueUp(i)`) меняет её с предыдущей.
