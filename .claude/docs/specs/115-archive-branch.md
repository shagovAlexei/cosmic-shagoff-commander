# 115 — «Ветвь» (Ctrl+B) внутри архива

Ctrl+B / Ctrl+Shift+B в каталоге архива (zip, tar.*, 7z) — все файлы под ним плоским списком, как на диске; раньше — «В результатах поиска недоступно».

- Список — по оглавлению архива (уже закешированному), без распаковки. Esc чтение оглавления не прерывает (как и вход в архив).
- Скрытые: любой каталог или файл ниже корня ветви, начинающийся с точки.
- Строки: имя — путь ниже корня ветви (`docs/img/p.png`). В отличие от диска, где `os_name` — полный путь, здесь он тоже относительный: код архивов собирает путь внутри архива как `inner.join(os_name)`, так F3 / F4 / F5 / F6 / F8 работают без изменений (F8 перепаковывает архив, ветвь перечитывается).
- Ctrl+Shift+B: отмеченные каталоги — по строкам панели (на диске их нет).
