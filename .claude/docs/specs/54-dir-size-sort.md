# 54. Сортировка по посчитанному размеру папок

Из ROADMAP («Размер папок, дальше»).

- По размеру папки идут по посчитанному размеру (Space, Alt+Shift+Enter), непосчитанные — как 0, то есть по имени до подсчёта (как в TC). Папки по-прежнему над файлами.
- Пришёл размер, а панель отсортирована по размеру — папка сразу встаёт на место, курсор остаётся на своей строке (`Panel::set_dir_size` → `resort`). Повторное чтение того же каталога порядок не меняет.
- Уход из каталога останавливает его подсчёты (`Tab::counting`, флаг для `props::usage`); остановленный подсчёт ничего не присылает (раньше присылал 0, и при быстром возврате папка получала размер 0).
