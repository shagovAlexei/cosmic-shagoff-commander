# 20. Свой просмотрщик F3 (Lister)

Статус: решения приняты сами (пользователь: «давай новую фазу, что там по порядку» — первый открытый пункт бэклога «Свой Lister для F3: текст, hex, картинки»).

## Решения

| Вопрос | Решение |
|---|---|
| Где показывается | На месте двух панелей в главном окне (меню, строка состояния остаются; F-кнопки скрыты). В TC — отдельное окно; у нас так проще с клавиатурой (одно окно — одна раскладка) и без управления окнами. Отдельное окно — потом, если понадобится |
| Когда F3 открывает Lister | Новая настройка «Встроенный просмотрщик» (`internal_viewer`, по умолчанию включена). Выключена — F3 как раньше запускает `viewer` (`xdg-open`). В архиве: файл извлекается во временный каталог (как сейчас) и открывается в Lister |
| Режимы (клавиши как в TC) | `1` текст, `3` hex, `4` картинка. Выбор при открытии: расширение png/jpg/jpeg/gif/bmp/webp/ico/svg → картинка; NUL в первых 8 КБ → hex; иначе текст. `2` (binary) из TC нет |
| Текст | UTF-8 (битые байты — `�`); BOM UTF-16 LE/BE и UTF-8 — распознаются. Tab → 4 пробела. Строка длиннее 4096 символов режется на несколько строк (иначе одна строка минифицированного JS убивает отрисовку). Перенос по ширине окна (`W` в TC) — нет, горизонтальная прокрутка |
| Hex | `00000010  48 65 6C 6C 6F 20 77 6F  72 6C 64 0A 00 00 00 00  Hello world.....` по 16 байт |
| Картинка | Вписывается в окно, не увеличивается. Кодеки: png, jpeg, ico (уже в libcosmic) + gif, webp, bmp (фичи крейта `image`); svg — через `widget::svg`. Нечитаемая картинка — пустое поле, `1`/`3` показывают байты |
| Большие файлы | Читается не больше 32 МБ; дальше — строка «Показаны первые 32 МБ из N». Чтение и разбор — в `spawn_blocking` |
| Навигация | ↑ ↓ PgUp PgDn Home End — прокрутка, ← → — по горизонтали; колесо и полосы прокрутки. `N` / `P` — следующий / предыдущий файл панели (курсор панели тоже двигается, каталоги пропускаются) |
| Поиск | `F7` — поле поиска в строке Lister; Enter ищет вниз от верхней видимой строки (без учёта регистра). `F3` — следующее, `Shift+F3` — предыдущее. Найденная строка подсвечена и прокручена в вид. В hex — поиск байтов UTF-8 запроса с учётом регистра. Не найдено — сообщение в строке состояния |
| Закрыть | `Esc`, `Q` (если открыто поле поиска, Esc сначала закрывает его). Кнопки: Текст / Hex / Картинка, Поиск, ← Пред., След. →, Закрыть |
| Чего нет | Выделение и копирование текста, кодировки кроме UTF-8/UTF-16, перенос строк, масштаб шрифта и картинки, Ctrl+Q (быстрый просмотр в панели), печать |

## Устройство

- `core::lister`: `Doc { bytes, total, name }` (обрезанные байты + полный размер), `Mode`, `detect(name, bytes)`, индекс строк `lines(bytes) -> Vec<Range<usize>>` (по `\n`, `\r\n`, длинные режутся по границе символа), `line_text(bytes, range)` (UTF-8 lossy, табы), `hex_rows(len)`, `hex_row(bytes, row)`, `find_line(...)`, `find_bytes(...)`. UTF-16 перекодируется в UTF-8 при загрузке.
- `app::lister`: состояние (`Lister { path, doc, lines, mode, offset, height, hit, search }`) и вид; виртуализированный список (только видимые строки, как панели и сравнение файлов).
- Клавиши без модификаторов, которых нет в общей таблице (`1 3 4 N P Q ← →`, `Shift+F3`), — отдельная функция `keymap::lister_key`; приложение смотрит на них только когда Lister открыт.

## Тесты

Core: выбор режима (картинка по расширению, NUL → hex, текст); индекс строк (`\n`, `\r\n`, последняя без `\n`, пустой файл); разрезание длинной строки по границе символа (кириллица); UTF-16 LE с BOM; hex-строка (полная и неполная); поиск строки вперёд/назад без учёта регистра (кириллица), поиск байтов; обрезка по лимиту.
App: F3 открывает Lister (а не внешнюю программу), Esc закрывает; F3 с выключенной настройкой — как раньше; `N` переводит курсор панели на следующий файл, пропуская каталоги; `3` переключает в hex; поиск находит строку и запоминает её.
