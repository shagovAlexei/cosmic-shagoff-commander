# 155. Архив внутри архива

ROADMAP «Архив, дальше: вложенные архивы». TC: Enter на архиве внутри архива открывает его
(распаковав во временный каталог); изменения — с вопросом о перепаковке во внешний.

- Enter на zip / tar.* / 7z внутри архива: извлечь во временный каталог (как F3 / Enter на файле),
  затем открыть копию в панели как архив. Было: `xdg-open`.
- Путь показывается, где архив лежит: `/d/outer.zip/sub/inner.zip/…` (строка пути, хлебные крошки,
  `путь>`); такой путь (щелчок по части, `cd`) ведёт в копию. `App::nested`: копия → каталог внешнего.
- Backspace / Enter на `..` в корне копии — во внешний архив, курсор на вложенном.
- Только чтение: копия во временном каталоге — правка бы потерялась. Изменения (F4, F7, F8,
  Shift+F6, F6 из, F5 / F6 в, Ctrl+X / Ctrl+V, Alt+Enter, Ctrl+M, Shift+F4) — «только для чтения» до
  диалога; запасной заслон — в `start_queued` на любое `Repack` / `Cross` в копию.

## Не делаем

- Перепаковку вложенного архива во внешний после изменения (TC спрашивает) — пока только чтение.
- Восстановление вкладки во вложенном архиве после перезапуска: временный каталог удаляется при
  выходе, вкладка откроется ближе к корню.
