# 130 — Щелчок по другой панели убирает ошибку

Ошибка панели держится до следующего действия в ней; Tab (действие в покидаемой панели) её убирал, щелчок мышью по другой панели — нет.

- `App::click_pane` (щелчок левой / правой кнопкой по строке или пустому месту): ошибка покидаемой панели и той, по которой щёлкнули, убирается; быстрый поиск закрывается; панель становится активной.
