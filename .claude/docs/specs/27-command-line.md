# 27. Командная строка

Статус: решения приняты сами (пользователь: «да» — следующий пункт бэклога «Командная строка внизу окна, как в TC (`путь>`); скрывается через конфиг»).

## Решения

| Вопрос | Решение |
|---|---|
| Где | Между строкой состояния и F-кнопками, на всю ширину окна: подпись `путь активной панели>` и поле ввода (как в TC). Нет, пока открыт просмотр F3 |
| Как попасть | Как в TC: печатаемый символ (без Ctrl/Alt), который панель не использует, уходит в командную строку и ставит в неё фокус. Пробел — в строку, только если она не пустая, иначе отметка. Клик по полю тоже |
| Что работает, пока фокус в строке | ↑ ↓ Tab — курсор панели и смена панели (поле их не берёт, как в TC); F-клавиши, PgUp/PgDn, Insert, Ctrl+… — как в панели. Стёрли строку до конца — фокус уходит, и Backspace снова «на уровень вверх» |
| Enter | Непустая строка выполняется в каталоге активной панели; строка очищается и попадает в историю. Enter в панели при непустой строке (фокус ушёл кликом) — тоже выполнить |
| Как выполняется | `sh -c "<строка>"` в каталоге активной панели, без терминала, вывод не показывается (в TC так же: окно консоли закрывается). Ошибка запуска (каталог внутри архива, нет `sh`) — в строку состояния |
| Shift+Enter | В терминале, окно остаётся открытым (в TC — `cmd /k`): `<terminal> sh -c "cd <каталог> && <строка>; exec \"${SHELL:-sh}\""` (каталог явно: у профиля терминала может быть свой). Терминал — настройка `terminal` в конфиге, правится руками (программа и аргументы, по умолчанию `cosmic-term -e`) |
| `cd` | Выполняется самим приложением: `cd` — домой, `cd путь` — относительно каталога панели, `~` — домой, кавычки вокруг пути снимаются, `..` сворачивается без обращения к диску. Путь в архив тоже работает (как переход в панели) |
| Ctrl+Enter / Ctrl+Shift+Enter | Имя / полный путь файла под курсором в конец строки (через пробел, в кавычках, если в нём есть пробел или знак оболочки). На `..` — ничего |
| Ctrl+P | Путь активной панели в конец строки (как в TC) |
| История | Последние 20 строк, последняя сверху, без повторов; хранится в состоянии (`~/.local/state/…/commands`). Ctrl+E — предыдущая команда (по кругу). Alt+F8 — список истории, Enter подставляет команду в строку. Ctrl+X (следующая в TC) занят «вырезать» — нет |
| Esc | Очищает строку (если закрывать больше нечего: диалог, поиск, просмотр…) |
| Скрыть | Настройка «Командная строка» (`show_cmdline`, по умолчанию вкл.). Выключена — символы не перехватываются, Ctrl+Enter / Ctrl+P / Ctrl+E / Alt+F8 ничего не делают |

## Ядро

Новый модуль `cmdline.rs`:

```rust
pub enum Cmd { Cd(PathBuf), Run(String) }
pub fn parse(line: &str, cwd: &Path, home: &Path) -> Option<Cmd>; // пустая → None
pub fn quote(word: &str) -> String;       // для вставки имени
pub fn append(line: &str, word: &str) -> String;
pub fn remember(list: &[String], line: &str) -> Vec<String>; // 20, без повторов
pub fn previous(list: &[String], line: &str) -> Option<String>; // Ctrl+E по кругу
```

## Приложение

- `App.cmdline: String`, своё `cmd_id`; `Message::CmdInput / CmdSubmit / CmdType(char)`.
- `route_event`: символ без Ctrl/Alt, для которого `keymap` ничего не нашёл, → `CmdType`.
- `FieldKey` пересылается в панель всегда, когда нет диалога и боковой панели (раньше — только из быстрого поиска и просмотра).
- Поле ввода считает Ctrl+Enter обычным Enter: `CmdSubmit` при зажатом Ctrl вставляет имя (с Shift — путь), а не выполняет. После вставки курсор переводится в конец (`focus` у уже сфокусированного поля курсор не двигает).

## Тесты

Core: `parse` (пусто, `cd`, `cd ~/x`, `cd ..`, `cd "a b"`, `cd /abs`, команда с пробелами), `quote` (простое имя, пробел, `'`), `append` (пустая строка, с пробелом в конце), `remember` (сверху, без повторов, 20), `previous` (по кругу, пустая история).
App: символ уходит в строку и Пробел — только в непустую; Enter выполняет и чистит, `cd` меняет каталог панели; Ctrl+Enter вставляет имя; Ctrl+E подставляет; Esc чистит; `show_cmdline = false` — символ не перехватывается; F5 из поля строки работает.
