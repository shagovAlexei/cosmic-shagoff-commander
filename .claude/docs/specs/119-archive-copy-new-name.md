# 119 — F5 в архив под новым именем

F5 одного файла в несуществующий путь внутри архива (`a.zip/new.txt`) создавал каталог `new.txt/` с файлом внутри. На диске то же самое — файл под новым именем (TC, `ops::plan`).

- `repack::apply`, `Change::Add`: один источник, `inner` — не каталог в архиве и без `/` в конце → последний компонент `inner` — новое имя, файл кладётся в его родителя. Иначе как было: внутрь `inner`.
- Приложение сохраняет `/` в конце ввода в `inner` (`split_path` собирает путь из компонентов и теряет его).
- Архив → архив (`cross`) идёт через тот же `Change::Add`. Один файл на самого себя по имени (`a.zip/x` → `a.zip/x`) — «нельзя скопировать в себя», как на диске.
