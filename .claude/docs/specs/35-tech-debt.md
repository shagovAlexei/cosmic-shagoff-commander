# 35. Техдолг: маски в кавычках, имена в результатах поиска, кодировка во вьюере, строка состояния

Статус: решения приняты сами (пользователь: «давай по плану идём всё что можно сделать»). Пункты техдолга из ROADMAP, которые проверяются тестами.

| Пункт | Решение |
|---|---|
| Маска: `;` и `|` в кавычках | Внутри `"…"` оба символа — часть шаблона; исключения начинаются с первого `|` вне кавычек |
| Результаты поиска: сравнение с путём | Быстрый поиск, фильтр и Num+/Num− идут по последней части имени (`sub/a.rs` → `a.rs`); в обычном каталоге имён с `/` не бывает, поведение не меняется |
| Вьюер: кодировка | Без BOM и не UTF-8 (обрезанный в конце символ не в счёт) → 1251 / KOI8-R / 866, где в первых 64 КБ больше строчных русских букв сразу после другой русской буквы (слова идут подряд; одиночные акценты Latin-1 вроде `café` не считаются), и таких не меньше трети байтов ≥ 0x80; при равенстве — 1251; иначе как раньше (UTF-8 с «�»). Угаданная кодировка на следующий файл (N / P) не переносится, выбранная вручную — переносится |
| Строка состояния | Не наложение: сведения о файле упирались в итоги другой панели. Зазор 24 px справа у каждой половины |
