# 50. Shift+F4 — новый файл

Из плана (ROADMAP «Новое»): как в TC, Shift+F4 — «Редактировать новый файл».

- Окно с именем: по умолчанию — файл под курсором (TC так же).
- `core::ops::new_file`: создать пустой с `create_new` — существующий никогда не обнуляется; есть — открыть как есть.
- Открыть в редакторе (`editor`, по умолчанию cosmic-edit), перечитать каталог, курсор на файле.
- Имя — одно (без `/`); иначе сообщение. Внутри архива — «Архив только для чтения».
- Меню «Файлы → Новый файл…», строка в F1.
