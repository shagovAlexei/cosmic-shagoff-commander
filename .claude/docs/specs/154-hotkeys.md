# 154. Свои горячие клавиши

ROADMAP «Настройки, дальше: переназначение клавиш». TC: Настройка → Прочее → «Переопределить
горячие клавиши»: сочетание → команда `cm_*`.

- Конфигурация → «Горячие клавиши…»: список «сочетание → команда», «Добавить» / «Другая клавиша»
  (ждёт нажатия), «Удалить», «Только стандартные»; команда — выпадающий список: «— ничего (клавиша
  выключена)», затем пункты меню («Меню → пункт») и строки F1 с действием, каждое действие один раз.
- Конфиг `hotkeys: Vec<(String, String)>`: ("Ctrl+K", имя `Action` по `Debug`, "" — выключить).
  Неизвестное сочетание или команда — пропускаются.
- `core::hotkey::Bind` — разбор / запись `Ctrl+Alt+Shift+Key`. Буквы и цифры — по физической
  клавише (как стандартные: русская раскладка работает), прочие — по имени кода (`Backquote`,
  `NumpadAdd`, `F5`, `Enter`, `Up`…). Esc и одни модификаторы не назначаются.
- Свои пробуются раньше таблицы `keymap::action` (глобальный список: `route_event` без состояния
  приложения). Меню показывает свою клавишу у команды и не показывает выключенную.
- Ожидание нажатия: флаг `keymap::CAPTURE` (ставится по состоянию окна после каждого `update`),
  `route_event` отдаёт следующее нажатие окну как текст `Bind`.

## Не делаем

- Справка F1 показывает стандартные клавиши.
- F-кнопки внизу окна не меняются (они не клавиши).
- Клавиши вьюера (буквы `1 3 4 N P Q W A S K 8`) — своя таблица, не переназначаются.
