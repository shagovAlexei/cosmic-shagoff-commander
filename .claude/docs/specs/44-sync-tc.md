# 44. Окно синхронизации как в TC

Ручная проверка (пункт 4): окно непохоже на TC, счётчики «→ 0 ← 0 ≠ 0 = 3» непонятны.

- Пути левого и правого каталога — над своими половинами таблицы.
- Маска «Файлы» и флажки (С подкаталогами, По содержимому, Без учёта даты, Зеркало) — одна строка.
- «Показать:» — переключатели TC с подписью и числом: «→ вправо: N», «← влево: N», «≠ различаются: N», «= одинаковые: N». Вместо флажка «Показывать одинаковые»; «=» сначала выключен, как раньше. Строки ✕ видны всегда.
- Таблица: Имя / Размер / Дата — действие (кнопка, щелчок меняет) — Дата / Размер / Имя. Копируемые строки — цвет акцента, удаляемые — красным. Строки плотные.
- Под таблицей — «✕ в корзину: N» или подтверждение удаления.
- Ядро: `sync::Row::kind()` (вид строки) и `sync::counts` (числа для переключателей), с тестом.

Не делаем: поле пути с выбором каталога в окне, кнопка «Дубликаты/одиночные», контекстное меню строк.
