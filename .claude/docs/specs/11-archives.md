# 11. Упаковка и распаковка Alt+F5 / Alt+F9

Статус: одобрен.
Основа: [архитектурный спек](00-architecture-design.md), [операции](05-file-ops.md), [эталон TC](../tc-reference.md).

Пункт бэклога «Архивы как папки, упаковка и распаковка» разделён на две фазы: 11 — упаковка и распаковка (этот спек), 12 — архив как папка (только чтение, поверх кода чтения из 11).

## Решения

| Вопрос | Решение |
|---|---|
| Распаковка | Форматы zip, tar, tar.gz/tgz, tar.bz2/tbz2, tar.xz/txz, tar.zst/tzst, 7z, одиночные .gz/.bz2/.xz/.zst |
| Упаковка | Форматы zip, tar, tar.gz, tar.bz2, tar.xz, tar.zst, 7z |
| RAR | Нет: лицензия unrar несовместима с GPL |
| Внешние программы | Нет, только Rust-крейты |
| Определение формата | По расширению, без учёта регистра |
| Распаковка — как | Распаковать во временный staging внутри каталога назначения, затем `ops::transfer(Move)`: конфликты, part-файлы, отмена берутся из фазы 5 |
| Упаковка — как | Писать `.<name>.<pid>.<n>.shagoff-part` рядом с целью, в конце переименовать без замены |
| Пароли, уровень сжатия, маска распаковки | Нет (позже) |

## Поведение

### Alt+F5 «Упаковать»

Цели — `targets()` активной панели. Нет целей или идёт операция — ничего.

Диалог:
- путь архива: каталог другой панели + имя. Для одной цели — её имя без последнего расширения (`readme.txt` → `readme`, как в TC; у `.bashrc` расширения нет), для нескольких — имя текущего каталога (для `/` — `archive`). Плюс `.` + расширение формата. Поле редактируемое; путь с `/` на конце — каталог, имя архива в нём берётся по умолчанию;
- формат: список из `Format::PACK`. Смена формата меняет расширение в конце поля, если оно там было расширением одного из форматов; иначе дописывает новое. Выбор сохраняется в конфиг (`pack_format`);
- флажок «Переместить в архив»: после упаковки без пропусков исходные удаляются безвозвратно (`ops::delete(permanent)`); при любом пропуске или ошибке ничего не удаляется;
- флажок «Отдельный архив для каждого файла»: имя каждого — имя цели + расширение, в каталоге из поля пути (имя из поля тогда не используется).

Папки пакуются рекурсивно, пути в архиве — относительно текущего каталога панели. Симлинки пакуются как симлинки в zip и tar. В 7z симлинк пропускается молча и считается пропуском (то есть отключает «Переместить»). Права и mtime сохраняются (в zip — unix mode через external attributes).

Enter / «Упаковать» → `Job::Pack`. Escape / «Отмена» — закрыть.

### Alt+F9 «Распаковать»

Цели — `targets()` активной панели, из них берутся только те, у кого `Format::detect` что-то вернул. Архивов нет или идёт операция — ничего.

Диалог:
- путь: каталог другой панели, редактируемый;
- флажок «Каждый архив — в свою папку»: подкаталог с именем архива без расширения формата (`a.tar.gz` → `a`).

Enter → `Job::Unpack`.

### Общее

- Прогресс: при упаковке — по прочитанным байтам исходных файлов (сумма считается обходом до начала); при распаковке — по прочитанным байтам сжатого архива (позиция в файле).
- Отмена удаляет part-файл / staging. Уже перенесённое на место при распаковке остаётся.
- После задачи перечитываются обе панели. Курсор активной панели — на созданном архиве, если он в её каталоге.
- Watcher на время задачи на паузе (как у всех задач).

## Безопасность

### Распаковка

`safe_path(entry: &Path) -> Option<PathBuf>`:
- срезает ведущие `/` и `./`, убирает `.`-компоненты;
- `None` для пустого пути и пути с `..` или с компонентом-префиксом (Windows `C:`). Такая запись пропускается и идёт в отчёт как ошибка «небезопасный путь» (`ErrorChoice` спрашивается обычным образом).

Запись в staging:
- перед созданием любой записи проверяется, что ни один её родитель внутри staging не симлинк (`symlink_metadata`). Если симлинк — запись пропускается с ошибкой. Закрывает «симлинк `a → /etc`, затем `a/passwd`»;
- симлинк создаётся как симлинк, цель не проверяется и никогда не читается;
- hardlink tar → копия уже распакованного файла по `safe_path` внутри staging; иначе пропуск с ошибкой;
- устройства, FIFO, сокеты — пропуск молча;
- права: только `mode & 0o777`, у папок владелец всегда получает `rwx` (`| 0o700`), иначе в них нельзя писать и переносить; права и mtime папок ставятся после всех записей; mtime симлинков не ставится; владелец не ставится;
- время в zip (DOS, без пояса) читается и пишется в системном поясе (`TimeZone::system()`), точность 2 с;
- повторное имя внутри архива — последняя запись побеждает (существующий файл в staging заменяется, папка остаётся);
- повреждённый архив или ошибка чтения — `Handler::error`: «Повторить» читает архив с начала, «Пропустить» прекращает этот архив, но уже распакованное переносится на место; «Отмена» — стоп, staging удаляется;
- имена: tar — байты как есть (`OsStr`); zip без UTF-8-флага — CP437 силами крейта;
- zip-бомба отдельно не ограничивается: ENOSPC идёт через `Handler::error`, отмена работает.

Все архивы одной задачи распаковываются в один staging (с «в свою папку» — в `staging/<stem>`), затем один `ops::transfer(Method::Move, pairs, h)` для записей верхнего уровня staging → каталог назначения (липкие ответы «заменить все» действуют на всю задачу). Затем staging удаляется `fs::remove_dir_all` (симлинки не разыменовывает).

Имя staging: `.shagoff-unpack.<pid>.<n>` в каталоге назначения (создаётся `create_dir`, при `EEXIST` — следующий `n`). Каталог назначения создаётся, если его нет.

### Упаковка

- Если путь архива лежит внутри одного из исходных каталогов, part-файл и итоговый архив исключаются из обхода (сравнение по `(dev, ino)` part-файла).
- Нечитаемый файл — `Handler::error` с «Повторить / Пропустить / Отмена»; пропуск отключает «Переместить».
- Сокеты, FIFO, устройства — пропуск молча (как в `ops`), тоже отключает «Переместить».
- Симлинки не разыменовываются.
- Цель занята — `Handler::conflict`: «Заменить» удаляет старый архив и переименовывает part, «Пропустить» удаляет part.

## Ядро: `archive.rs`

Если файл вырастет — `archive/{mod,pack,unpack}.rs`.

```rust
pub enum Format { Zip, Tar, TarGz, TarBz2, TarXz, TarZst, SevenZ, Gz, Bz2, Xz, Zst }
impl Format {
    /// By extension, case-insensitive; .tgz/.tbz2/.txz/.tzst too.
    pub fn detect(name: &str) -> Option<Format>;
    /// "zip", "tar.gz", … (canonical extension, for pack and for stripping).
    pub fn ext(self) -> &'static str;
    /// Formats offered for packing.
    pub const PACK: [Format; 7];
}
/// Default archive file name for the pack dialog.
pub fn archive_name(targets: &[PathBuf], cwd: &Path, f: Format) -> String;
/// Pack dialog: swap a PACK extension at the end of `path` for `f`'s, or append it.
pub fn with_format(path: &str, f: Format) -> String;
/// `(sources, archive path)` per archive: one group, or one per target with `separate`.
pub fn groups(targets: &[PathBuf], cwd: &Path, path: &Path, f: Format, separate: bool) -> Vec<(Vec<PathBuf>, PathBuf)>;
/// `name` with the extension of its detected format removed ("a.tar.gz" → "a").
pub fn stem(name: &str) -> &str;
pub fn safe_path(entry: &Path) -> Option<PathBuf>;
/// `completed` = sources of archives written without skips (for "move to archive").
pub fn pack(f: Format, base: &Path, groups: &[(Vec<PathBuf>, PathBuf)], h: &mut dyn ops::Handler) -> ops::Report;
/// `completed` = archives unpacked without skips.
pub fn unpack(archives: &[PathBuf], dest: &Path, own_dir: bool, h: &mut dyn ops::Handler) -> ops::Report;
```

Зависимости core: `zip` (deflate, bzip2, zstd), `tar`, `flate2`, `bzip2`, `liblzma` (статическая сборка), `zstd`, `sevenz-rust2`. Все MIT/Apache/BSD.

## Приложение

- keymap: Alt+F5 → `Action::Pack`, Alt+F9 → `Action::Unpack` (только чистый Alt). Кнопки F-панели не меняются: слоя Alt у них нет.
- dialogs: `Dialog::Pack { path, format, move_after, separate }`, `Dialog::Unpack { path, own_dir, archives }`.
- jobs: `Job::Pack { format, base, groups: Vec<(Vec<PathBuf>, PathBuf)>, move_after }` (одна группа или по группе на цель), `Job::Unpack { archives, dest, own_dir }`.
- config: `pack_format: String`, по умолчанию `"zip"`; неизвестное значение → zip.
- Строки `en` и `ru`; tc-reference: Alt+F5/Alt+F9 → фаза 11.

## Тесты

Core (tempdir):
- круговой тест для каждого формата из `PACK`: дерево с файлом, вложенной папкой, пустой папкой, симлинком (кроме 7z), кириллическим именем → упаковать → распаковать в другой каталог → то же содержимое, mode, mtime (секунды);
- одиночные `.gz`, `.bz2`, `.xz`, `.zst` → файл без расширения;
- `detect`: все расширения, регистр, `.tgz`, не-архив; `stem`; `archive_name` для одной цели, нескольких, `/`;
- `safe_path`: `../x`, `a/../../x`, `/etc/x` → `etc/x`, `./a` → `a`, пустой;
- злые tar, собранные в тесте: `../x`, симлинк-родитель `a → <вне>` + `a/f`, hardlink наружу, устройство — вне каталога назначения ничего не появляется;
- конфликт при распаковке: заменить / пропустить через существующий `Handler`;
- отмена посреди упаковки и посреди распаковки: нет part-файла и staging;
- упаковка папки в архив внутри этой же папки: архив не содержит себя;
- обрезанный архив: ошибка, «Пропустить» оставляет уже распакованное, staging удалён;
- цель упаковки занята: заменить / пропустить.

App: Alt+F5 открывает `Dialog::Pack` с ожидаемым путём; смена формата меняет расширение; Enter запускает `Job::Pack`; Alt+F9 без архивов среди целей ничего не делает, с архивом — открывает диалог.
