# 72. Ссылки (Ctrl+Shift+F5) и перетаскивание правой кнопкой

ROADMAP «Drag & drop, дальше». Как в TC: Ctrl+Shift+F5 создаёт ссылку; бросок после перетаскивания
правой кнопкой спрашивает «Копировать / Переместить / Ссылка».

- **Ссылка.** `Action::Link` (Ctrl+Shift+F5, меню «Файлы»), диалог `InputOp::Link` как у F5 (путь —
  каталог другой панели). Пары — `ops::plan` (каталог, маска, имя для одного), `ops::symlinks`:
  символическая ссылка на абсолютный путь источника, существующее имя не заменяется (ошибка).
  Мгновенно, без задачи; обе панели перечитываются. В архиве — отказ (`read_only`, `inside_archive`).
- **Правая кнопка.** libcosmic `dnd_source` начинает только левой → своя копия `dnd.rs` (MPL-2.0,
  источник в начале файла): начинает и правой, `on_start(right)`. Правое нажатие не перехватывается
  (курсор, контекстное меню — на отпускание — работают). `Message::DragStart(Some(files))` запоминает
  файлы правого перетаскивания; `Message::Drop` с теми же файлами → `Dialog::DropMenu` (кнопки →
  `Message::DropAs(op)` → тот же диалог с каталогом броска). Другие файлы (левая кнопка, другая
  программа) — как раньше.

Не делаем: меню у указателя (окно по центру), картинку под указателем; ссылки внутри архивов.
