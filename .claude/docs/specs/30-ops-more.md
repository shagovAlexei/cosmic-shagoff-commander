# 30. Операции: Shift+F5, переименование при конфликте, даты каталогов, `~`

Статус: решения приняты сами (пользователь: «продолжай по плану, проверку пропустим»). Drag & drop отложен: в headless-проверке нет Wayland DnD. Фоновая очередь операций — отдельная фаза.

## Решения

| Вопрос | Решение |
|---|---|
| Shift+F5 | Как в TC: копия файла под курсором в той же папке. Диалог F5 с именем файла в поле; относительный путь — от текущего каталога (как в F5). То же имя — «Нельзя скопировать файл сам в себя». Отметки не учитываются (TC тоже берёт файл под курсором). В архиве — отказ, как F5 из архива в архив |
| «Переименовать» в конфликте | Поле с предложенным именем `имя (1).расш` (первое свободное) и кнопка «Переименовать»: этот файл пишется под введённым именем. Если и оно занято — вопрос снова. Пустое имя, `.`, `..`, `/` — кнопка неактивна |
| «Переименовать все» | Липкий ответ, как «Заменить все»: каждый следующий конфликт получает первое свободное `имя (N).расш` без вопроса. Это и есть «сохранить оба» |
| Даты каталогов | Каталог, созданный копированием (и переносом между дисками), получает дату изменения исходного — после того, как в него записано содержимое. В существующий каталог (слияние) дата не переносится |
| `~` в пути цели | F5 / F6 / Shift+F5: `~` и `~/путь` раскрываются в домашний каталог (`session::expand_home`) |

## Ядро

- `ops::Resolution` теряет `Copy`, получает `Rename(String)` и `RenameAll`.
- `ops::unique_name(dst)` — `a.txt` → `a (1).txt`, `a (2).txt`…; без расширения — `a (1)`; `.bashrc` → `.bashrc (1)`.
- `Transfer::destination` — общий для файла, ссылки и быстрого переноса: куда писать (сам `dst`, одобренная замена или новое имя), повторяет вопрос, пока новое имя занято.
- `Transfer::dir` ставит mtime созданному каталогу.

## Тесты

Core: `unique_name` (расширение, без, скрытый, занятые `(1)`); конфликт «Переименовать» — старый цел, новый под новым именем; новое имя тоже занято — вопрос повторяется; «Переименовать все» спрашивает один раз; перенос с «Переименовать» (быстрый путь); дата скопированного каталога равна исходной.
App: Shift+F5 открывает диалог с именем файла; копия появляется рядом; `~/x` в поле F5 — копия в домашнем; кнопка «Переименовать» отправляет `Rename(имя)`.
