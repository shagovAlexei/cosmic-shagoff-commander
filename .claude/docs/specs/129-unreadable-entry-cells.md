# 129 — Каталог `r--`: пустые ячейки

В каталоге, который можно прочитать, но нельзя войти (`r--` без `x`), `stat` файлов не работает: у них были размер 0, дата 1970 и права `---------`.

- `Entry::unknown()`: известны только имя и тип (`mode`, `size` = 0, `mtime` = эпоха, нет владельца).
- Такая строка: размер (у файла), дата и атрибуты пустые; у папки — `<DIR>`. Строка состояния (`format::details`) — только имя (та же проверка).
