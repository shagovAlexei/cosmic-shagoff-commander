# 178. Кодировка имён в архиве

TC `cm_ChangeArchiveEncoding`. Zip без флага UTF-8 хранит имена в OEM-кодировке Windows (cp866
на русской), крейт `zip` читает их как cp437 — в панели мусор.

## Решение

- `archive::zip_name` — одно место, где имя записи zip становится строкой; через него идут
  оглавление (`read_index`), распаковка (`read_zip`) и обход файлов (`files`: поиск, проверка),
  так что показанное и извлечённое имя совпадают.
- `NameEnc::Auto`: размеченное UTF-8 / ASCII — как есть; иначе UTF-8, если байты им являются
  (zip из Linux / macOS без флага); иначе cp866, если язык системы кириллический или байты
  читаются как русские слова (`looks_cp866`: все не-ASCII — буквы cp866, две подряд); иначе cp437.
  Локаль не главное: у многих система на английском, а интерфейс программы русский.
- Ручной выбор (cp866, cp1251, cp437, UTF-8) — Файлы → «Кодировка имён в архиве…» (`ListKind::NameEncoding`)
  для zip, в котором панель, или под курсором; хранится до выхода (`set_name_encoding`, как пароли);
  кэш оглавления учитывает кодировку; панели внутри перечитываются.

## Не делаем

- Изменение такого архива (repack по-прежнему отказывает: имена записались бы иначе).
- Кодировки tar / 7z (там имена UTF-8 / UTF-16).
