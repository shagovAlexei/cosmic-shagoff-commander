# 144 — Маска `*.*`, подтома btrfs

Техдолг-1, два пункта.

- Num+ / Num- без истории масок открываются с `*.*`, как TC (было `*`; `*.*` и так совпадает с именами без точки).
- `drives::parse`: диск определялся устройством; подтома btrfs на устройстве `/` (`subvol=/@data` в `/media`) считались `/` и кнопки не имели. Теперь у btrfs ключ — устройство + `subvol=`; тот же подтом дважды — одна кнопка (предпочтение `/media`, как было).
