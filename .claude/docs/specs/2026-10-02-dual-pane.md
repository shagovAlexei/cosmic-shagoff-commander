# Фаза 2: две панели

Дата: 2026-10-02. Статус: одобрен.
Основа: [архитектурный спек](2026-10-02-architecture-design.md), [фаза 1](2026-10-02-core-panel.md), [эталон TC](../tc-reference.md).

## Цель

Окно с двумя панелями, по которым можно ходить с клавиатуры и мышью, как в TC. Файловых операций, выделения и вкладок пока нет.

## Решения

| Вопрос | Решение |
|---|---|
| Внешний вид | Компоновка как в TC, цвета из темы COSMIC (светлая и тёмная) |
| Старт | Обе панели в `~`. Аргумент `shagoff-commander <путь>` задаёт левую панель, путь нормализуется через `canonicalize`. Если путь не каталог или не открылся, панель открывается в `~` |
| Дата | `02.10.2026 13:49`, по местному часовому поясу (`jiff`) |
| Размер | В байтах, разряды отделены пробелом: `1 204 567`. У каталогов вместо размера `<DIR>` |
| Список файлов | Свой виджет: строки фиксированной высоты, отрисовываются только видимые. Готовая `table` из libcosmic не подходит: у неё нет курсора, отдельного от выделения, и она отрисовывает все строки |
| Горячие клавиши с буквами | Ctrl+R и Ctrl+\ привязаны к физической клавише, чтобы работали при русской раскладке |

## Ядро (`crates/core`)

- `Entry.mode: u32` — права из `PermissionsExt::mode()`, у симлинка берутся права цели.
- `format.rs`:
  - `size(u64) -> String` — `1 204 567`;
  - `date(SystemTime, &TimeZone) -> String` — `02.10.2026 13:49`;
  - `perms(u32) -> String` — `rwxr-xr-x`;
  - `display_name(&Entry) -> String` — каталог показывается как `[name]`. У файла, если есть расширение, отбрасывается `.ext`: оно выводится в своей колонке.
- `Panel::set_cursor(i)` — курсор на строку i, но не за конец списка (для клика мышью).
- `Panel::totals() -> Totals { bytes, files, dirs }` — итоги для строки состояния, без `..`.
- `viewport.rs` — чистая математика прокрутки:
  - `visible_range(len, row_h, offset, height) -> Range<usize>` — видимые строки плюс запас по 2 сверху и снизу;
  - `scroll_to_cursor(cursor, row_h, offset, height) -> Option<f32>` — новое смещение, чтобы курсор целиком попал в окно, или `None`, если он уже виден;
  - `page_rows(row_h, height) -> usize` — шаг для PgUp и PgDn: строк на экране минус одна, но не меньше 1.

## Приложение (`crates/app`)

- `App { panes: [Pane; 2], active: usize, tz }`, где `Pane { panel, scroll_id, offset, height, pending, error }`.
- **Загрузка каталога.** `load(side, path, focus)` записывает `pending = path` и читает каталог в `spawn_blocking`. Результат приходит как `Message::Listed`:
  - если `path != pending`, результат устарел и отбрасывается;
  - `Ok` → `set_listing`, ошибка очищается, курсор прокручивается в видимую область;
  - `Err` → текст ошибки показывается в строке состояния панели, панель остаётся на месте.
- **Клавиши.** Подписка `event::listen_with` берёт только `KeyPressed`, которые не обработал ни один виджет. `keymap::action(key, physical, modifiers) -> Option<Action>`:

| Клавиша | Action |
|---|---|
| Tab | SwitchPane |
| ↑ ↓ PgUp PgDn Home End | Up / Down / PageUp / PageDown / Home / End |
| Enter | Enter: каталог — войти, `..` — вверх с фокусом, файл — открыть через `xdg-open` |
| Backspace, Ctrl+PgUp | Parent (вверх, курсор на каталоге, из которого вышли) |
| Ctrl+\ | Root |
| Ctrl+R | Reload |
| Ctrl+F3 / F4 / F5 / F6 | Sort по имени / расширению / дате / размеру (повторное нажатие меняет направление) |

- **Мышь:**
  - клик по строке ставит туда курсор и делает панель активной;
  - двойной клик работает как Enter;
  - клик по заголовку колонки сортирует;
  - колесо прокручивает.
- **Прокрутка.** Смещение и высоту области `on_scroll` сообщает через `Message::Scrolled`. Пока scrollable не прислал первое событие, высота считается равной 400 px. После любого движения курсора `scroll_to_cursor` и `scrollable::scroll_to` держат курсор на экране.
- **Вид панели сверху вниз:**
  1. Строка пути. У активной панели фон цвета акцента.
  2. Заголовки: Имя, Расш., Размер, Дата, Атрибуты. У колонки сортировки стоит ▲ или ▼.
  3. Список, высота строки 22 px, текст не переносится. Курсор: в активной панели фон акцента и текст `on_accent`, в неактивной — акцент с прозрачностью 35%.
  4. Строка состояния: «0 б из 4 126 б, файлов 0 из 3, папок 0 из 2». Отметок пока нет, поэтому «выбрано» всегда 0. Если есть ошибка, вместо этого показывается её текст цветом destructive.
- **Нижний ряд кнопок:** F3 Просмотр, F4 Правка, F5 Копия, F6 Перемещ., F7 Каталог, F8 Удалить, Alt+F4 Выход. Работает только «Выход» (`iced::exit`), остальные неактивны до фаз 5–6.
- Все строки интерфейса заданы через `fl!` и есть в `en` и `ru`.

## Вне объёма

Выделение (фаза 4), вкладки (фаза 3), операции (фаза 5), кнопки дисков, Ctrl+H и watcher (фаза 6), иконки, изменение ширины колонок.

## Тесты

- **Ядро:** `format` (размер, дата в фиксированном поясе, права, отображаемое имя), `set_cursor`, `totals`, `viewport` (пустой список, края, курсор выше и ниже окна, `page_rows` при маленькой высоте).
- **Приложение:** `keymap` — каждая клавиша из таблицы, Ctrl+R и Ctrl+\ при русской раскладке (по физической клавише), стрелка с Ctrl → `None`.
- **Вручную** — чек-лист в `TESTING.md`.
