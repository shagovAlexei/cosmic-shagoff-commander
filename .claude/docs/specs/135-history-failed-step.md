# 135 — Неудачный шаг по истории не теряет показанный каталог

Alt+← / Alt+→ сдвигают позицию истории до чтения каталога. Каталог удалён — чтение не удалось, на экране прежний, а позиция на удалённом; следующий переход (`visit`) обрезал историю после неё, и показанный каталог пропадал.

- `History::seat(shown)`: позиция — на ближайшую запись показанного каталога.
- `Message::Listed` с ошибкой — `seat(panel.cwd())` (для обычного перехода ничего не меняет: `visit` бывает только при успехе).
