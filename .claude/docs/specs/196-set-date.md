# 196. Изменить дату и время

TC: `cm_SetAttrib` (поля даты и времени в окне атрибутов).

- `core::format::date_edit` / `parse_date` (jiff, часовой пояс программы), `core::props::set_times(paths, modified, accessed, recursive)` — `utimensat` по пути (`UTIME_OMIT` для неменяемого), у ссылки своё время, каталог после содержимого.
- Файлы → «Изменить дату и время…» (`Action::SetDate`, `Dialog::SetDate`, без клавиши): время изменения и время доступа, у каждого поле и флажок «менять» (набор в поле отмечает), даты первого файла, «Текущие дата и время», «И всё внутри каталогов» при каталоге среди файлов. Время создания и смены статуса в Linux не задаётся — подпись в окне. Не дата в отмеченном поле — ошибка, ничего не меняется. В архиве — отказ. Обе панели перечитываются.
