# 196. Изменить дату и время

TC: `cm_SetAttrib` (поля даты и времени в окне атрибутов).

- `core::format::date_edit` / `parse_date` (jiff, часовой пояс программы), `core::props::set_mtime(paths, to, recursive)` — `File::set_modified`, ссылки пропускаются, каталог после содержимого.
- Файлы → «Изменить дату и время…» (`Action::SetDate`, `InputOp::SetDate`, без клавиши): поле с датой первого файла; Enter — всем отмеченным (или под курсором); обе панели перечитываются. Не дата — ошибка в строке состояния, файлы не тронуты. В архиве и во вложенном архиве — отказ.
- Не делаем: «внутри каталогов» (в ядре есть `recursive`, в окне флажка нет), время доступа и создания, кнопку «Сейчас».
