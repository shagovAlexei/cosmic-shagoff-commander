# 07. Быстрый поиск (Alt+буквы) и фильтр панели (Ctrl+S)

Статус: одобрен.
Основа: [архитектурный спек](00-architecture-design.md), [фаза 6](06-mvp-finish.md), [эталон TC](../tc-reference.md).

## Решения

| Вопрос | Решение |
|---|---|
| Запуск поиска | Alt+символ, как в TC по умолчанию. Простые буквы оставлены для будущей командной строки |
| Совпадение | Начало имени без учёта регистра; `*` в начале — любое место; `?` — один символ |
| Буква без совпадений | Не принимается (как в TC) |
| Фильтр | Ctrl+S, то же поле. Живёт до Escape или смены каталога; Enter закрывает поле, фильтр остаётся |
| Отметки при фильтре | С файлов, скрытых фильтром, снимаются |

## Ядро

### `quicksearch.rs`

```rust
/// `doc` → `doc*`, `*отч` → `*отч*`; case-insensitive; `..` never matches.
pub fn matches(pattern: &str, name: &str) -> bool;
```
Использует `mask::glob` (делается `pub(crate)`), шаблон приводится к нижнему регистру так же, как в маске. Пустой шаблон совпадает со всем, кроме `..`.

### `Panel`

```rust
/// First match at or after `from` going `forward` (or before it going back), wrapping; `None` if nothing matches.
pub fn find(&self, pattern: &str, from: usize, forward: bool) -> Option<usize>;
pub fn filter(&self) -> Option<&str>;
/// Show only `..` and entries matching `pattern` (None = all). Cursor stays on the same name if
/// still visible, else clamps; marks on hidden entries are dropped.
pub fn set_filter(&mut self, pattern: Option<String>);
```
- `Panel` хранит полный список (`all`) и видимый (`entries`). Курсор, отметки, `targets()`, `totals()` работают по видимому.
- `set_listing` для того же каталога применяет текущий фильтр к новому списку (автообновление и Ctrl+R его не сбрасывают); для другого каталога фильтр снимается.
- `set_sort` сортирует оба списка.

## Приложение

### Состояние

```rust
pub struct Search { pub side: usize, pub text: String, pub filter: bool }
App.search: Option<Search>
```
Поле — `text_input` с фокусом внизу панели `side`, на месте строки состояния. При активном фильтре без открытого поля строка состояния начинается с `fl!("filter-status", pattern)`.

### Клавиши
- keymap: при Alt и `Key::Character(c)` из одного символа (`mods == ALT`) → `Action::QuickSearch(c)`. Alt+F1/F2 — как раньше; прочие Alt → `None`. Ctrl+S (физическая `KeyS`) → `Action::QuickFilter`.
- `QuickSearch(c)`: открыть поиск в активной панели (если уже открыт — дописать `c`), применить текст.
- `QuickFilter`: открыть поле фильтра с текущим фильтром панели (или пустым).
- Ввод в поле (`Message::SearchInput(text)`):
  - поиск: если `find(text, 0, true)` есть — принять текст и поставить курсор; иначе отклонить (поле не меняется);
  - фильтр: принять, `set_filter(Some(text))` (пустой текст — `None`).
- Пока поле открыто, `Message::Key`:
  - `Up`/`Down`: поиск — `find` от курсора ∓1 назад/вперёд; фильтр — обычное движение курсора;
  - `Enter` (и `on_submit`): закрыть поле; в режиме поиска — затем `act(Enter)`;
  - всё остальное: закрыть поле, затем выполнить действие как обычно.
- Escape (уже маршрутизируется как `DialogCancel`): если открыто поле — закрыть; в режиме фильтра — ещё и снять фильтр. Если поле закрыто, а в активной панели есть фильтр и нет диалога/операции — снять фильтр.
- Смена вкладки или панели закрывает поле (фильтр остаётся в своей вкладке).

## Тесты

Core:
- `matches`: префикс, регистр, кириллица (`Док`/`док`), `*` в начале, `?`, `..` не совпадает, пустой шаблон.
- `find`: вперёд/назад, по кругу, `None` без совпадений, `..` пропускается.
- `set_filter`: видимые записи, `..` остаётся, курсор на том же имени, отметки скрытых сняты, `None` возвращает всё; `set_listing` того же каталога сохраняет фильтр, другого — снимает; сортировка с фильтром.

App:
- Alt+буква открывает поиск и ставит курсор на совпадение; буква без совпадений отклоняется.
- ↓ в поиске — следующее совпадение.
- F5 из поиска закрывает поле и открывает диалог копирования.
- Enter из поиска на каталоге начинает переход.
- Ctrl+S + ввод фильтрует; Enter оставляет фильтр; Escape снимает.

keymap: Alt+буква (лат./кир.) → `QuickSearch`, Alt+Shift+буква → `None`, Ctrl+S → `QuickFilter`, Alt+F1 по-прежнему диски.

Вручную (TESTING.md): поле видно и в фокусе, ввод без Alt, Backspace, клик мышью по панели при открытом поле.

## Вне фичи

Выбор способа запуска (буквы / Ctrl+Alt), поиск по полному пути, подсветка совпадения в имени.
