# 192. Отдельное дерево

TC: `cm_SeparateTreeSwitch` (Ctrl+Shift+F8).

- `App.side_tree` (`SideTree { id, tree: core::tree::Tree, synced }`), `State.side_tree` хранит «включено». Столбец 220 px слева от обеих панелей (`view::side_tree`), строки как у Ctrl+F8.
- Следует за активной панелью: `App::side_tree_sync` после каждого `update` — если каталог активной панели (для архива — каталог рядом) сменился, встаёт на его строку или читает путь вниз (`tree_read`, `Message::TreeFilled` с `id` дерева).
- Щелчок (`SideTreeRow`) — активная панель идёт в каталог (запертая вкладка остаётся), двойной (`SideTreeToggle`) раскрывает / сворачивает.
- Не делаем: клавиши дерева (для этого Ctrl+F8), второе дерево (`cm_SeparateTree2`), ширину по перетаскиванию, виртуализацию строк.
