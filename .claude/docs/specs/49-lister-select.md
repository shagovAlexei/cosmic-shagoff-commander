# 49. Выделение текста во вьюере F3

Ручная проверка (пункт 9): во вьюере нельзя выделить текст.

- Как в TC Lister: нажать и тянуть мышью — выделение посимвольно (строки и моноширинные столбцы по координате с учётом прокрутки, `core::lister::pos_at`); Shift+щелчок продлевает; простой щелчок снимает.
- Ctrl+A — всё, Ctrl+C — в буфер (строки, как показаны, через `\n`; «Скопировано символов: N»). Esc сначала снимает выделение, потом закрывает.
- Подсветка выделенного в видимых строках; при смене строк (перенос, кодировка, режим, новый файл) выделение снимается.
- Ядро: `core::lister::Selection` (порядок концов, часть строки, текст), `pos_at`.
- Первое движение при входе мыши в область не сообщается: если нажали раньше, начало — по первому движению с нажатой кнопкой.

Не делаем: двойной щелчок по слову, выделение в режиме картинки, склейку частей перенесённой строки при копировании.
