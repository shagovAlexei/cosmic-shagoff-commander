# 64. Ctrl+Q внутри архива

Быстрый просмотр показывает и файлы внутри архива (zip, tar.*, 7z — что открывается как папка): файл
под курсором вынимается в свежий временный каталог (`archive::temp_root`), читается в память, копия
сразу удаляется. Без окна операции и без вопросов: в чистом каталоге конфликтов нет, любая ошибка —
пояснение «Нет просмотра». Курсор ушёл / просмотр закрыт — распаковка останавливается (`quick_stop`);
пауза 120 мс перед чтением, как для обычных файлов. Запись больше 32 МБ (столько читает просмотрщик) не вынимается — пояснение «открыть через F3». Каталог внутри архива — пояснение (подсчёт по
архиву не делаем).

Где: `core::archive::extract_one(archive, inner, name, dest, stop)`; ветка в `App::quick_follow`.
