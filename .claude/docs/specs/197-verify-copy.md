# 197. Проверка копий

- `Config.verify_copy` (по умолчанию нет; Ctrl+, → Панели «Проверять копии»); `ops::set_verify` — глобально, как другие переключатели core (`set_core_switches`, `apply_config`).
- `Transfer::copy_contents`: CRC32 считается по мере чтения источника; по окончании `read_back` — `sync_all`, `fadvise(DontNeed)`, чтение part-файла с начала, сравнение длины и CRC. Несовпадение — `io::Error` `why::VERIFY_FAILED` (с переводом), как любая ошибка записи: диалог «Повторить / Пропустить / Отмена»; part-файл удаляется. Перемещение удаляет оригинал только после успеха.
- Не делаем: флажок в диалоге F5 / F6, показ второго прохода в прогрессе, проверку при Ctrl+V из буфера и синхронизации сверх общего `ops::transfer` (они проверяются тем же кодом).
