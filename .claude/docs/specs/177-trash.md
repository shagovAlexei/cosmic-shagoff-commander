# 177. Корзина как каталог

TC `cm_OpenRecycled`: перейти в корзину, посмотреть, восстановить, удалить насовсем, очистить.

## Решение

Никакого виртуального пути: корзина freedesktop — обычный каталог `$XDG_DATA_HOME/Trash/files`
(на дисках — `.Trash-UID/files`, `.Trash/UID/files`), у каждого объекта верхнего уровня —
`info/<имя>.trashinfo` с `Path=` (URL-экранированный; на дисках — от корня диска).

- Команды → «Корзина» (`Action::OpenTrash`, кнопка `cm_OpenRecycled`): панель туда; каталоги
  создаются, если их ещё нет.
- `listing::scan` в `files/` кладёт в `Entry.target` исходный путь — строка состояния показывает
  `имя → откуда` (рендер диск не трогает).
- F8 / Delete в корзине (и ниже) — безвозвратно; `ops::delete` после удаления объекта верхнего
  уровня удаляет и его `.trashinfo` (`trashcan::forget`).
- «Восстановить» (`Action::Restore`, меню строки корзины `Ctx::Trash`): переименование на место,
  каталог создаётся; занятое имя не заменяется — ошибка в строке состояния. Вне корзины — отказ.
- Корзина — только настоящая: домашняя или `.Trash-UID` / `.Trash/UID` с нашим UID (не любой
  `Trash/files`, например из распакованного архива); путь в корзине диска — только внутри диска.
- F6 из корзины (и Ctrl+M в ней) — `.trashinfo` удаляется: у него больше нет объекта.
- «Очистить корзину…» (`Action::EmptyTrash`): все объекты всех корзин (`trash::os_limited::trash_folders`)
  через обычный `ConfirmDelete { permanent }` — с вопросом, прогрессом и отменой.

## Не делаем

- Колонки «Откуда» / «Когда удалён» (хватает строки состояния); восстановление из подкаталога
  удалённой папки; перенос между дисками при восстановлении (корзина всегда на диске объекта).

Логика — `crates/core/src/trashcan.rs`, тесты там же и `the_trash_deletes_for_good_and_restores`.
