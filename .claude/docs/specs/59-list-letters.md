# 59. Буквы в окнах-списках

Как в меню TC / Windows: в открытом окне-списке (Ctrl+D, Alt+F1 / F2, Alt+↓, Alt+F8, «Открыть с
помощью») буква переводит курсор на следующий пункт, название которого начинается с неё (без учёта
регистра, первая буква или цифра — «‹ Назад» ловится на «Н»). Повтор той же буквы — следующее
совпадение, по кругу. Нет совпадений — курсор стоит. Список прокручивается за курсором. Буква не
уходит в командную строку, пока окно открыто.

Логика — `core::quicksearch::next_with`; в app — ветка `Message::CmdType` для `Dialog::List`.
