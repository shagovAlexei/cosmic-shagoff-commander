# 112 — Размеры в байтах или в КБ / МБ / ГБ

Флажок «Размеры в КБ, МБ, ГБ» в меню «Вид» и в настройках (Ctrl+, → рядом с «Линией между панелями»); у TC — «Конфигурация → Показ → Формат размера».

- Включён: колонка «Размер» и итоги строки состояния — «5,4 МБ», «1,2 КБ».
- Выключен: всё в байтах с пробелами («5 368 709 120»; колонку можно расширить), итоги — точные байты.
- Пока не выбран (`human_sizes = None`): как у темы — «Современная» в КБ/МБ, «Классическая» — байты (в колонке до 999 999 999, дальше «45,1 ГБ»). Флажок показывает это; первое нажатие ставит противоположное. Итоги и сведения о файле под курсором в строке состояния — в том же виде.
- В диалогах (конфликт, свойства, прогресс) — по-прежнему точные байты.

Клавиши нет (у TC тоже).
