# 36. Две темы интерфейса: «Классическая» (TC) и «Современная» (COSMIC)

Статус: записано по просьбе пользователя («давай сделаем две темы, первое и вторая. запиши это в планы, потом будем переключать в настройках разные темы»). Логика не меняется — только отрисовка. Делать поверх #37 (`view.rs` менялся в #31 и #37).

## Решения

| Вопрос | Решение |
|---|---|
| Что такое «тема» | Набор правил отрисовки (`Skin`), не цвета: цвета по-прежнему из темы COSMIC (светлая/тёмная, акцент). Настройка `skin` в `Config` (`Classic` / `Modern`), по умолчанию — `Classic` (ближе к нынешнему виду); переключение в окне настроек (Ctrl+,) применяется сразу |
| «Классическая» (TC) | Плотнее: строка ~18 px, шрифт 12–13; разделители колонок и сетка заголовков, заголовки колонок как кнопки (▲▼); панель кнопок-инструментов под меню (перечитать, поменять панели, новая папка, поиск, сравнить, синхронизировать, настройки — те же `Action`); диски — выпадающий список `[c ▾]` + кнопки `\` и `..`, как в TC; строка пути — плоская полоса; F-кнопки — плоские, во всю ширину |
| «Современная» (COSMIC) | Компоновка TC остаётся (две панели, F-кнопки, командная строка), но: панели — скруглённые карточки с отступами; строка пути — «хлебные крошки» (`/ › home › shag`), щелчок по части — переход; строка ~26 px, иконки 20 px, размер — `12,3 КБ` вместо байтов; курсор — скруглённая подсветка; кнопки дисков — «таблетки»; F-кнопки — `button::standard` с подписью клавиши мельче |
| Где живёт | `crates/app/src/view/`: `mod.rs` (общая компоновка), `classic.rs`, `modern.rs` — только функции отрисовки строк, заголовков, полос. `Skin` даёт числа (`row_h`, отступы, размер иконок) — их же берёт математика прокрутки (`viewport` получает `row_h` параметром, `ROW_H` перестаёт быть константой) |
| Чего не делаем | Свои цветовые палитры (TC-синий фон и т. п.) — позже, отдельной настройкой; разные клавиши для тем — клавиши одни |

## План (кратко)

1. `Config.skin` + выбор в настройках (en/ru), `App::row_h()` из темы; все места с `ROW_H` (viewport, Brief, reveal, тесты) — через неё.
2. Разнести `view.rs` на `view/{mod,classic,modern}.rs`; «Классическая» = нынешний вид + плотность, разделители, панель инструментов, диски списком.
3. «Современная»: карточки, хлебные крошки (сообщение `Message::Drive(side, path)` уже есть), размеры по-человечески, крупнее строки и иконки.
4. Проверка: скриншоты обеих тем в headless (1036×530), светлая и тёмная тема COSMIC; тесты прокрутки с обоими `row_h`.
