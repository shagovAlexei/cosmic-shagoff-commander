# 14. Сравнение и синхронизация каталогов

Статус: одобрен (пользователь: «действуй», решения приняты по TC).
Основа: [архитектурный спек](00-architecture-design.md), [операции](05-file-ops.md), [эталон TC](../tc-reference.md).

## Решения

| Вопрос | Решение |
|---|---|
| Сравнить списки | Shift+F2, как Compare file lists в TC: в обеих панелях отмечаются файлы, которых нет напротив или которые новее; одинаковая дата и разный размер — отмечаются оба. Каталоги не отмечаются. Не рекурсивно |
| Синхронизация | Ctrl+Shift+S (в TC без клавиши по умолчанию, команда Synchronize dirs): диалог сравнения каталогов двух панелей |
| Сравнение | По имени; файл одинаков, если размер равен и mtime отличается не больше чем на 2 с (FAT, zip). Флажки «По содержимому» (при равном размере сравнить байты), «Без учёта даты» (только размер/содержимое) |
| Подкаталоги | Флажок «С подкаталогами», по умолчанию включён. Каталог, которого нет на другой стороне, — одна строка (копируется целиком) |
| Скрытые | Как в активной панели (Ctrl+H) |
| Направления | По умолчанию: есть только слева или слева новее → «→»; наоборот → «←»; разное без понятного «новее» (дата равна, размер разный; файл против каталога) → «≠», ничего не делается. Клик по стрелке строки: → / ← / пропуск |
| Синхронизировать | Копирует по выбранным стрелкам существующим движком (`ops::transfer(Copy)`), с прогрессом и ошибками; замена без вопроса — только если цель та же, что видело сравнение (размер и mtime); изменившаяся после сравнения или невиданная цель (флешка без учёта регистра, нечитаемый каталог) — обычный диалог конфликта. Удаления нет. Симлинк против файла/каталога — «≠», без стрелки. Смена флажков сравнения пересравнивает сразу |
| Внутри архивов | Нет: если хоть одна панель внутри архива — «Архив только для чтения» для синхронизации; Shift+F2 работает (только отметки) |

## Поведение

Shift+F2: ничего не копирует; отметки в обеих панелях заменяются результатом. `..` не отмечается.

Ctrl+Shift+S открывает диалог:
- сверху пути левой и правой панелей (только показ);
- флажки «С подкаталогами», «По содержимому», «Без учёта даты», «Показывать одинаковые» (по умолчанию нет);
- кнопка «Сравнить» запускает сравнение в фоне (повторная — заново); во время сравнения она «Стоп»;
- список строк: имя (относительный путь), слева размер и дата, стрелка, справа размер и дата; первые 1000 строк;
- итог: «→ N, ← M, ≠ K, = L»;
- «Синхронизировать» (активна, если есть хоть одна стрелка) закрывает диалог и запускает задачу копирования; после — перечитать обе панели;
- Escape / «Отмена» — закрыть (сравнение останавливается).

## Ядро: `sync.rs`

```rust
pub enum State { Same, LeftOnly, RightOnly, LeftNewer, RightNewer, Differ }
pub enum Dir { None, ToRight, ToLeft }
pub struct Info { pub size: u64, pub mtime: SystemTime, pub dir: bool }
pub struct Row { pub rel: PathBuf, pub left: Option<Info>, pub right: Option<Info>, pub state: State, pub dir: Dir }
pub struct Options { pub recursive: bool, pub content: bool, pub ignore_date: bool, pub hidden: bool }
/// Sorted by rel path; both-sided dirs are descended, not listed. Stops when `stop` is set (rows so far).
pub fn compare(left: &Path, right: &Path, o: &Options, stop: &AtomicBool) -> Vec<Row>;
pub fn default_dir(s: State) -> Dir;
/// Copy pairs for the rows' arrows: (to the right, to the left).
pub fn plan(left: &Path, right: &Path, rows: &[Row]) -> (Vec<(PathBuf, PathBuf)>, Vec<(PathBuf, PathBuf)>);
/// Shift+F2: names to mark in the left and in the right list (files only).
pub fn compare_lists(left: &[Entry], right: &[Entry]) -> (Vec<OsString>, Vec<OsString>);
```

`Panel::mark_names(&[OsString])` — заменить отметки этими именами.

## Приложение

- keymap: Shift+F2 → `Action::CompareLists`, Ctrl+Shift+S → `Action::SyncDirs`.
- `Dialog::Sync(Box<SyncDlg>)`; сравнение — `spawn_blocking`, результат `Message::SyncCompared(id, Vec<Row>)`; стоп-флаг ставится при закрытии (Drop), как у поиска.
- `Job::Sync { to_right, to_left }` → два `ops::transfer(Copy)` подряд с обработчиком, который на конфликт отвечает «Заменить».
- Строки en и ru; tc-reference: Shift+F2 и Ctrl+Shift+S.

## Тесты

Core: состояния (только слева/справа, новее, одинаковые в пределах 2 с, равная дата и разный размер, файл против каталога); «По содержимому» (равный размер, разные байты → Differ/новее по дате; одинаковые байты, разная дата → Same); «Без учёта даты»; рекурсия и одна строка для одностороннего каталога; скрытые; `plan` по стрелкам; `compare_lists`; `mark_names`.

App: Shift+F2 отмечает в обеих панелях; Ctrl+Shift+S открывает диалог; результат сравнения с чужим id игнорируется; клик по стрелке меняет направление; «Синхронизировать» запускает задачу; Ctrl+Shift+S при панели в архиве — «только для чтения».

Вручную (TESTING.md): две копии каталога с правками в обеих — Shift+F2; синхронизация в обе стороны; «По содержимому».
