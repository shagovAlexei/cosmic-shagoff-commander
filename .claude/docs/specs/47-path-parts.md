# 47. Путь по частям в классической теме

Ручная проверка (пункт 23): «путь — части-кнопки, щелчок по части переходит туда» нравится, нужно и в классической теме.

- Классическая: строка пути выглядит как прежде (текст на подсвеченной полосе), но каждая часть кликабельна (`mouse_area`, курсор-«рука»), как в TC. Глубокий путь прокручен к концу.
- Обе темы: щелчок по части (`Message::PathPart`) — переход туда, курсор на папке, через которую шли (`core::panel::child_toward`, как Backspace); панель становится активной.
- В результатах поиска строка пути прежняя («Результаты поиска: …»).
