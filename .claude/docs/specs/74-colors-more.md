# 74. Цвета по типам: фон строки, размер, возраст

Продолжение 73 (ROADMAP «Цвета, дальше»).

- У правила три новых поля (`colors::Rule`, `serde(default)` — старые конфиги читаются):
  - `bg` — фон строки `#RRGGBB`, пусто — нет;
  - `size` — `>N` / `<N`, N с `k` / `M` / `G` (1024, латиница или кириллица); только файлы;
  - `age` — `>N` / `<N` дней от изменения (будущая дата — 0 дней).
- Правило с неразбираемым цветом, фоном или условием не действует; в окне — `⚠` перед маской.
- Фон — не под курсором и не у отмеченных (их красный текст важнее). Текст строки на фоне — чёрный
  или белый по яркости. Пустой цвет имени при заданном фоне — текст строки, не акцент.
- Окно: «Размер» и «Возраст, дн.» в первом ряду (примеры — подсказкой в поле); «Текст» / «Фон»
  выбирают, что правят поле цвета и палитра; первый образец для фона — «Нет».
- У TC условия задаются шаблоном поиска; у нас — два поля, без атрибутов (позже).
