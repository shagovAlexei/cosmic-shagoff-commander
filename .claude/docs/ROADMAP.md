# Roadmap

Подробности по фазам MVP — в спеке `.claude/docs/specs/2026-10-02-architecture-design.md`. Перед началом каждой фазы и каждой фичи из бэклога проводим брейншторм.

## Фазы MVP

- [x] 0. Bootstrap: репозиторий, workspace, CI, документация, пустое окно
- [x] 1. core: `Panel`, `listing`, сортировка, тесты
- [x] 2. Две панели: таблица, курсор, Tab, навигация, строка пути, строка состояния, кнопки F-панели
- [x] 3. Вкладки
- [ ] 4. Выделение как в TC (Insert, Space, Num+, Num−, Num*)
- [ ] 5. Операции F5, F6, Shift+F6/F2, F7, F8, Shift+F8, прогресс, конфликты
- [ ] 6. F3 и F4 через внешние программы, кнопки дисков, watcher, конфиг. **MVP готов**
  - Конфиг хранится в файле. Формат решаем на брейншторме фазы 6: стандарт COSMIC (cosmic-config, файл на поле, живое обновление) или один файл в духе `wincmd.ini` (TOML)
  - Запоминать пути и вкладки обеих панелей между запусками
  - Опция «Ctrl+W на последней вкладке»: по умолчанию ничего не делать, а если включена — сбросить вкладку в домашний каталог (или в каталог, заданный в конфиге)

## Бэклог (после MVP)

Порядок обсуждаемый.

- Свой Lister для F3: текст, hex, картинки
- Быстрый поиск Alt+буквы и фильтр панели
- История Alt+←/→, hotlist Ctrl+D, Ctrl+U (поменять панели)
- Буфер обмена Ctrl+C/X/V, совместимый с cosmic-files
- Групповое переименование Ctrl+M
- Архивы как папки, упаковка и распаковка (Alt+F5, Alt+F9)
- Поиск файлов Alt+F7
- Сравнение и синхронизация каталогов
- gvfs: флешки, монтирование, сеть, SFTP (за основу `mounter/gvfs.rs` из cosmic-files)
- Командная строка внизу окна, как в TC (`путь>`); скрывается через конфиг
- Вкладки как в TC:
  - дублировать вкладку;
  - перенести вкладку в другую панель;
  - закрепить вкладку: закреплённую нельзя закрыть, в ней нельзя уйти из каталога, выход открывает новую вкладку;
  - переименовать вкладку (своя подпись вместо имени каталога)
- Режимы Brief и эскизы, иконки по MIME
- Drag & drop
- Меню и панель инструментов как в TC
- Окно настроек, переназначение клавиш
- Упаковка: deb, flatpak

## Техдолг

Найден на ревью, отложен.

- [x] Фаза 2: при старте нормализовать cwd (`canonicalize`), иначе для `/x/..` и относительных путей не работает переход на `..` (core, ревью фазы 1)
- [ ] Каталог с правом `r--` без `x` показывается пустым: если `metadata` не удалось, брать тип из `DirEntry::file_type()` (`listing.rs`)
- [ ] Тест: каталоги сверху для всех ключей сортировки и обоих направлений (`sort.rs`)
- [ ] Doc-комментарий к `Panel::set_show_hidden`: после вызова нужно перечитать каталог
- [x] Фаза 4: keymap игнорирует Shift/Alt у именованных клавиш (Shift+Tab, Alt+Enter работают как без модификатора) — помешает Shift+стрелкам (ревью фазы 2)
- [ ] Фаза 6 (watcher): два чтения одного пути — применяется старое, новое отбрасывается; заменить `pending: PathBuf` на счётчик поколений
- [ ] Backspace/Enter, пока каталог ещё читается, считаются от показанного cwd, а не от ожидаемого (теряются нажатия на медленной ФС)
- [ ] Ошибка в строке состояния висит до следующей успешной загрузки; текст без пути и не локализован
- [ ] Клик по частично видимой строке не докручивает её; после уменьшения окна курсор может уйти за край
- [ ] `totals()` считается на каждый кадр, сортировка больших каталогов в UI-потоке — кешировать итоги, сортировать в `spawn_blocking`
- [ ] Фаза 6: keymap возвращает `None` на любое Alt/Super — сузить, когда появятся Alt+F1/Alt+F2 (`keymap.rs`)
- [ ] После переключения вкладки возможен один кадр со старым смещением (общий scrollable); `restore_scroll` вызывается и когда ничего не изменилось
