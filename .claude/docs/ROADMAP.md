# Roadmap

Подробности по фазам MVP — в спеке `.claude/docs/specs/00-architecture-design.md`. Перед началом каждой фазы и каждой фичи из бэклога проводим брейншторм.

## Фазы MVP

- [x] 0. Bootstrap: репозиторий, workspace, CI, документация, пустое окно
- [x] 1. core: `Panel`, `listing`, сортировка, тесты
- [x] 2. Две панели: таблица, курсор, Tab, навигация, строка пути, строка состояния, кнопки F-панели
- [x] 3. Вкладки
- [x] 4. Выделение как в TC (Insert, Space, Num+, Num−, Num*)
- [x] 5. Операции F5, F6, Shift+F6/F2, F7, F8, Shift+F8, прогресс, конфликты
- [x] 6. F3 и F4 через внешние программы, кнопки дисков, watcher, конфиг. **MVP готов**
  - Конфиг: cosmic-config (`~/.config/cosmic/<APP_ID>/v1/`, файл на поле, правка применяется на лету); состояние — в `~/.local/state/cosmic/<APP_ID>/v1/`
  - Запоминать пути и вкладки обеих панелей между запусками
  - Опция «Ctrl+W на последней вкладке»: по умолчанию ничего не делать, а если включена — сбросить вкладку в домашний каталог (или в каталог, заданный в конфиге)

## Бэклог (после MVP)

Порядок обсуждаемый.

- [x] Свой Lister для F3: текст, hex, картинки, поиск, N/P (сделано, 20)
- Lister, дальше: отдельное окно, перенос строк `W`, кодировки (cp1251, koi8-r), выделение и копирование, масштаб, файлы больше 32 МБ (чтение по частям), Ctrl+Q — быстрый просмотр в другой панели
- [x] Быстрый поиск Alt+буквы и фильтр панели (сделано, 07)
- [x] История Alt+←/→, hotlist Ctrl+D, Ctrl+U (поменять панели) (сделано, 08)
- [x] Буфер обмена Ctrl+C/X/V, совместимый с cosmic-files (сделано, 09)
- [x] Групповое переименование Ctrl+M (сделано, 10)
- [x] Упаковка и распаковка Alt+F5 / Alt+F9 (сделано, 11)
- [x] Архивы как папки, только чтение: просмотр, F5/Ctrl+C наружу, Enter/F3 из архива (сделано, 12)
- [x] Запись в архив: F5/F6 в архив и из архива, F7, F8, Shift+F6, F4 с упаковкой обратно (сделано, 21)
- Архив, дальше: Ctrl+V / Ctrl+X и Ctrl+M в архиве, копирование из архива в архив, вложенные архивы, быстрая запись в zip без перепаковки всего архива
- [x] Поиск файлов Alt+F7 (сделано, 13)
- [x] Поиск: «В панель», фильтры размера и даты, регулярные выражения для текста (сделано, 22)
- Поиск, дальше: в архивах, фильтр атрибутов, регулярное выражение для имени, запоминание фильтров, «В панель» с клавиатуры
- [x] Сравнение и синхронизация каталогов: Shift+F2, Ctrl+Shift+S (сделано, 14)
- Синхронизация: режим «зеркало» (удалять лишнее), фильтр по маске, синхронизация с архивом
- [x] Сравнение двух файлов по содержимому Ctrl+Shift+D (сделано, 15)
- Сравнение файлов: правка и перенос блоков, игнорировать пробелы/регистр, отличия внутри строки
- [x] Монтирование: флешки из Alt+F1, сеть Ctrl+F (sftp/smb/ftp/dav через gvfs), отключение Ctrl+Shift+F (сделано, 16)
- Сеть: обзор сетевого окружения (smb/avahi), сохранённые соединения и пароли (keyring), отмена подключения
- [x] Строка состояния окна: сообщения (обычные / «идёт…» / ошибки) и сведения о файле под курсором — права, владелец, цель ссылки (сделано, 19)
- Командная строка внизу окна, как в TC (`путь>`); скрывается через конфиг
- Вкладки как в TC:
  - дублировать вкладку;
  - перенести вкладку в другую панель;
  - закрепить вкладку: закреплённую нельзя закрыть, в ней нельзя уйти из каталога, выход открывает новую вкладку;
  - переименовать вкладку (своя подпись вместо имени каталога)
- Режимы Brief и эскизы, иконки по MIME
- Drag & drop
- [x] Главное меню в заголовке окна: Файлы, Выделение, Команды, Сеть, Вид; пункт = тот же `Action`, что и клавиша, клавиша подписана (сделано, 17)
- Меню, дальше: «Конфигурация» (вместе с окном настроек), в «Вид» — Brief / Подробно, колонки, шрифт; «Свойства» в «Файлы»; панель инструментов
- [x] Справка F1, «О программе», настройки Ctrl+, (язык, тема, F-кнопки, скрытые файлы, Ctrl+W, программы F3/F4, формат упаковки) в боковой панели (сделано, 18)
- Настройки, дальше: переназначение клавиш; кнопка «Поддержать проект» — вписать ссылку Stripe Payment Link в `DONATE_URL` (`drawer.rs`)
- Упаковка: deb, flatpak
- Операции: фоновая очередь (несколько операций одновременно, панели не ждут); «Переименовать» и «Сохранить оба» в диалоге конфликта; Shift+F5 (копия в той же папке); сохранять дату каталогов при копировании; `~` в пути цели

## Техдолг

Найден на ревью, отложен.

- [ ] 22: в результатах поиска быстрый поиск, фильтр и Num+ сравнивают с путём (`sub/a.rs`), а не с именем файла
- [ ] 22: watcher на каталоге поиска перечитывает все результаты на каждое событие (миллион результатов — миллион stat); Ctrl+R хватило бы
- [ ] 22: Ctrl+R / событие watcher между «В панель» и приходом списка снимают результаты (редко)

- [ ] 21: F6 в архив удаляет источники целиком (`remove_dir_all`) после упаковки — файл, появившийся в каталоге-источнике за время упаковки, удалится, не попав в архив
- [ ] 21: F4 из архива — `mtime` запоминается до ответа: если «Обновить» закончилось ошибкой или отменой, это изменение больше не предлагается (до следующего сохранения)
- [ ] 21: F5 одного файла в несуществующий путь внутри архива (`a.zip/new.txt`) создаёт каталог `new.txt/`, а не файл под новым именем

- [ ] 20: Lister — поиск строки выделяет память на каждую строку (на 32 МБ логе «не найдено» заметно тормозит); для ASCII-запроса искать по байтам без выделений
- [ ] 20: Lister — картинка декодируется при первой отрисовке в UI-потоке, байты картинки копируются в `Handle` (до +32 МБ); картинка больше 32 МБ — пустое поле без объяснения
- [ ] 20: Lister — индекс строк 16 байт на строку (файл из одних `\n` на 32 МБ ≈ 512 МБ)
- [ ] 20: Lister — N/P внутри архива: если извлечение отменено или не удалось, курсор панели уже на новом файле, а показан старый

- [x] Фаза 2: при старте нормализовать cwd (`canonicalize`), иначе для `/x/..` и относительных путей не работает переход на `..` (core, ревью фазы 1)
- [x] Каталог с правом `r--` без `x` показывается пустым: если `metadata` не удалось, брать тип из `DirEntry::file_type()` (`listing.rs`)
- [x] Тест: каталоги сверху для всех ключей сортировки и обоих направлений (`sort.rs`)
- [x] Doc-комментарий к `Panel::set_show_hidden`: после вызова нужно перечитать каталог
- [x] Фаза 4: keymap игнорирует Shift/Alt у именованных клавиш (Shift+Tab, Alt+Enter работают как без модификатора) — помешает Shift+стрелкам (ревью фазы 2)
- [x] Фаза 6 (watcher): два чтения одного пути — применяется старое, новое отбрасывается; заменить `pending: PathBuf` на счётчик поколений
- [x] Backspace/Enter, пока каталог ещё читается, считаются от показанного cwd, а не от ожидаемого (теряются нажатия на медленной ФС)
- [x] Ошибка в строке состояния висит до следующей успешной загрузки; текст без пути и не локализован
- [x] Клик по частично видимой строке не докручивает её; после уменьшения окна курсор может уйти за край
- [ ] `totals()` считается на каждый кадр, сортировка больших каталогов в UI-потоке — кешировать итоги, сортировать в `spawn_blocking`
- [x] Фаза 6: keymap возвращает `None` на любое Alt/Super — сузить, когда появятся Alt+F1/Alt+F2 (`keymap.rs`)
- [ ] После переключения вкладки возможен один кадр со старым смещением (общий scrollable); `restore_scroll` вызывается и когда ничего не изменилось
- [x] До фазы 5: Ctrl+T копирует отметки в новую вкладку (в TC новая вкладка без выделения) — сбрасывать в `Tab::duplicate`
- [x] Маска: TC принимает и пробел между шаблонами (`*.rs *.toml`), у нас только `;`; диалог открывается с `*`, в tc-reference — `*.*` (поведение одинаковое)
- [ ] Ctrl в состоянии «зажат» после ухода фокуса из окна — проверить, приходит ли `ModifiersChanged(empty)` на Wayland
- [ ] Проверить вручную (фаза 4, отложено пользователем): Ctrl+R перечитывает каталог и отметки при этом сохраняются (у пропавших файлов снимаются)
- [x] Операции: цель с `/` на конце для одного файла (каталога нет) → ошибка ENOTDIR; в TC `/` на конце значит «в каталог» — создавать его

- [x] Фаза 6: свободное место не локализовано («12.0 G свободно из 450 G» вместо «12,3 ГБ»); на границах округления «100.0 G», «1024 K» (`format::human`)
