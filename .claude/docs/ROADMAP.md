# Roadmap

Подробности по фазам MVP — в спеке `.claude/docs/specs/00-architecture-design.md`. Перед началом каждой фазы и каждой фичи из бэклога проводим брейншторм.

## Фазы MVP

- [x] 0. Bootstrap: репозиторий, workspace, CI, документация, пустое окно
- [x] 1. core: `Panel`, `listing`, сортировка, тесты
- [x] 2. Две панели: таблица, курсор, Tab, навигация, строка пути, строка состояния, кнопки F-панели
- [x] 3. Вкладки
- [x] 4. Выделение как в TC (Insert, Space, Num+, Num−, Num*)
- [x] 5. Операции F5, F6, Shift+F6/F2, F7, F8, Shift+F8, прогресс, конфликты
- [x] 6. F3 и F4 через внешние программы, кнопки дисков, watcher, конфиг. **MVP готов**
  - Конфиг: cosmic-config (`~/.config/cosmic/<APP_ID>/v1/`, файл на поле, правка применяется на лету); состояние — в `~/.local/state/cosmic/<APP_ID>/v1/`
  - Запоминать пути и вкладки обеих панелей между запусками
  - Опция «Ctrl+W на последней вкладке»: по умолчанию ничего не делать, а если включена — сбросить вкладку в домашний каталог (или в каталог, заданный в конфиге)

## Бэклог (после MVP)

Порядок обсуждаемый.

- Свой Lister для F3: текст, hex, картинки
- Быстрый поиск Alt+буквы и фильтр панели
- История Alt+←/→, hotlist Ctrl+D, Ctrl+U (поменять панели)
- Буфер обмена Ctrl+C/X/V, совместимый с cosmic-files
- Групповое переименование Ctrl+M
- Архивы как папки, упаковка и распаковка (Alt+F5, Alt+F9)
- Поиск файлов Alt+F7
- Сравнение и синхронизация каталогов
- gvfs: флешки, монтирование, сеть, SFTP (за основу `mounter/gvfs.rs` из cosmic-files)
- Командная строка внизу окна, как в TC (`путь>`); скрывается через конфиг
- Вкладки как в TC:
  - дублировать вкладку;
  - перенести вкладку в другую панель;
  - закрепить вкладку: закреплённую нельзя закрыть, в ней нельзя уйти из каталога, выход открывает новую вкладку;
  - переименовать вкладку (своя подпись вместо имени каталога)
- Режимы Brief и эскизы, иконки по MIME
- Drag & drop
- Меню и панель инструментов как в TC
- Окно настроек, переназначение клавиш
- Упаковка: deb, flatpak
- Операции: фоновая очередь (несколько операций одновременно, панели не ждут); «Переименовать» и «Сохранить оба» в диалоге конфликта; Shift+F5 (копия в той же папке); сохранять дату каталогов при копировании; `~` в пути цели

## Техдолг

Найден на ревью, отложен.

- [x] Фаза 2: при старте нормализовать cwd (`canonicalize`), иначе для `/x/..` и относительных путей не работает переход на `..` (core, ревью фазы 1)
- [x] Каталог с правом `r--` без `x` показывается пустым: если `metadata` не удалось, брать тип из `DirEntry::file_type()` (`listing.rs`)
- [x] Тест: каталоги сверху для всех ключей сортировки и обоих направлений (`sort.rs`)
- [x] Doc-комментарий к `Panel::set_show_hidden`: после вызова нужно перечитать каталог
- [x] Фаза 4: keymap игнорирует Shift/Alt у именованных клавиш (Shift+Tab, Alt+Enter работают как без модификатора) — помешает Shift+стрелкам (ревью фазы 2)
- [x] Фаза 6 (watcher): два чтения одного пути — применяется старое, новое отбрасывается; заменить `pending: PathBuf` на счётчик поколений
- [x] Backspace/Enter, пока каталог ещё читается, считаются от показанного cwd, а не от ожидаемого (теряются нажатия на медленной ФС)
- [x] Ошибка в строке состояния висит до следующей успешной загрузки; текст без пути и не локализован
- [x] Клик по частично видимой строке не докручивает её; после уменьшения окна курсор может уйти за край
- [ ] `totals()` считается на каждый кадр, сортировка больших каталогов в UI-потоке — кешировать итоги, сортировать в `spawn_blocking`
- [x] Фаза 6: keymap возвращает `None` на любое Alt/Super — сузить, когда появятся Alt+F1/Alt+F2 (`keymap.rs`)
- [ ] После переключения вкладки возможен один кадр со старым смещением (общий scrollable); `restore_scroll` вызывается и когда ничего не изменилось
- [x] До фазы 5: Ctrl+T копирует отметки в новую вкладку (в TC новая вкладка без выделения) — сбрасывать в `Tab::duplicate`
- [x] Маска: TC принимает и пробел между шаблонами (`*.rs *.toml`), у нас только `;`; диалог открывается с `*`, в tc-reference — `*.*` (поведение одинаковое)
- [ ] Ctrl в состоянии «зажат» после ухода фокуса из окна — проверить, приходит ли `ModifiersChanged(empty)` на Wayland
- [ ] Проверить вручную (фаза 4, отложено пользователем): Ctrl+R перечитывает каталог и отметки при этом сохраняются (у пропавших файлов снимаются)
- [x] Операции: цель с `/` на конце для одного файла (каталога нет) → ошибка ENOTDIR; в TC `/` на конце значит «в каталог» — создавать его
- [x] `Action::Cancel` больше не используется (Escape всегда идёт как `DialogCancel`) — удалить
- [ ] Проверить: доходят ли клики мыши до панелей под модальным диалогом прогресса (`Click`/`SelectTab` не проверяют `job`)
- [x] Фаза 6: свободное место не локализовано («12.0 G свободно из 450 G» вместо «12,3 ГБ»); на границах округления «100.0 G», «1024 K» (`format::human`)
- [x] Фаза 6: `home_dir` из конфига не проверяется: `~/work` или удалённый каталог → ошибка при Ctrl+W на последней вкладке (взять `session::existing_dir`, раскрыть `~`)
- [x] Фаза 6: список дисков может смениться, пока открыт Alt+F1 (флешку вынули) — Enter уйдёт не в тот диск; хранить копию списка в `Dialog::Drives`
- [x] Фаза 6: устройство `/` или home, смонтированное ещё раз в `/media/...`, даёт лишнюю кнопку (`drives::parse` не запоминает пропущенные устройства)
- [ ] Фаза 6: Ctrl+H при ошибке записи конфига работает только до перезапуска, ошибка лишь в логе
- [x] Фаза 6: путь-файл в командной строке игнорируется (открыть его каталог через `existing_dir`)
- [x] Фаза 6: F3/F4 на битом симлинке молча ничего не открывают
- [ ] Фаза 6: `is_dir` при восстановлении вкладок блокирует старт на мёртвом сетевом монтировании
