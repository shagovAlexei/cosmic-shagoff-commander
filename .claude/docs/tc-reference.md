# Total Commander: эталон поведения

Это источник истины для «как в TC». Колонка «Фаза» показывает, в какой фазе MVP (0–6) клавиша появляется. Пометка `backlog` значит «после MVP».

Если поведение отличается от TC намеренно, это записано в колонке «Примечание» с причиной.

## Раскладка окна (сверху вниз)

1. Меню (Файлы, Выделение, Команды, Сеть, Вид, Конфигурация, Запуск, Справка). Фаза: backlog.
2. Панель инструментов. Фаза: backlog.
3. Кнопки дисков отдельно над каждой панелью. Справа от них свободное и общее место на диске.
4. Вкладки панели.
5. Строка пути. У активной панели она подсвечена.
6. Заголовки колонок: Имя, Тип (расширение), Размер, Дата, Атрибуты. Клик сортирует, повторный клик меняет направление.
7. Список файлов:
   - `[..]` всегда сверху;
   - папки в квадратных скобках `[name]`, в колонке размера у них `<DIR>`;
   - курсор — рамка или подсветка;
   - отмеченные файлы — красный текст.
8. Строка состояния: «0 k из 1 234 k, файлов: 0 из 15, папок: 0 из 3».
9. Командная строка `путь>`. Фаза: backlog.
10. Ряд кнопок: `F3 Просмотр | F4 Правка | F5 Копия | F6 Перемещ. | F7 Каталог | F8 Удалить | Alt+F4 Выход`.

## Горячие клавиши

### Навигация

| Клавиша | Действие | Фаза | Примечание |
|---|---|---|---|
| Tab | Переключить активную панель | 2 | |
| ↑ ↓ PgUp PgDn Home End | Двигать курсор | 2 | |
| Enter | Войти в папку / открыть файл | 2 | Файл открывается через `xdg-open` |
| Backspace, Ctrl+PgUp | На уровень вверх | 2 | После перехода курсор стоит на папке, из которой вышли |
| Ctrl+\ | В корень | 2 | |
| Alt+← / Alt+→ | История назад / вперёд | 08 | У каждой вкладки своя, до 50 записей |
| Alt+↓ | Список истории каталогов вкладки | 08 | |
| Ctrl+U | Поменять панели местами | 08 | Вместе с вкладками; фокус на той же стороне |
| Ctrl+← / Ctrl+→ | Открыть папку под курсором в левой / правой панели | backlog | |
| Alt+F1 / Alt+F2 | Выбор диска для левой / правой панели | 6 | Список дисков, ↑/↓/Enter. COSMIC не перехватывает (проверено в фазе 6) |
| Ctrl+D | Избранные каталоги (hotlist) | 08 | Первый пункт — добавить текущий; Delete удаляет; хранится в конфиге `hotlist` |
| Alt+буквы | Быстрый поиск по имени | 07 | Поле внизу панели; префикс, `*` — любое место; ↑/↓ — следующее/предыдущее; Enter открывает; другая клавиша закрывает и выполняется |
| Ctrl+S | Быстрый фильтр панели | 07 | То же поле; Enter оставляет фильтр, Escape снимает |
| Ctrl+R | Перечитать панель | 2 | В TC перечитать ещё и F2, но у нас F2 = переименование (привычно в Linux) |

### Вкладки

| Клавиша | Действие | Фаза |
|---|---|---|
| Ctrl+T | Новая вкладка с текущим каталогом | 3 |
| Ctrl+W | Закрыть вкладку (последнюю закрыть нельзя) | 3 |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая вкладка | 3 |
| Клик / средняя кнопка / двойной клик по вкладке | Выбрать / закрыть / закрыть | 3 |

### Выделение

| Клавиша | Действие | Фаза | Примечание |
|---|---|---|---|
| Insert | Отметить/снять и сдвинуть курсор вниз | 4 | |
| Space | Отметить/снять | 4 | Для папки TC ещё считает размер, у нас это backlog. Привязан к физической клавише |
| Shift+↑↓ | Отметить диапазон | 4 | |
| Num+ | Выделить группу по маске (диалог, по умолчанию `*.*`) | 4 | Шаблоны через `;` или пробел, `"a b*"` в кавычках, исключения после `\|` |
| Num− | Снять выделение по маске | 4 | |
| Num* | Инвертировать выделение | 4 | |
| Ctrl+A, Ctrl+Num+ | Выделить всё | 4 | |
| Ctrl+Num− | Снять всё | 4 | |
| Ctrl+клик | Отметить/снять строку | 4 | |

### Файловые операции

Все операции применяются к отмеченным файлам, а если отметок нет — к файлу под курсором.

| Клавиша | Действие | Фаза | Примечание |
|---|---|---|---|
| F3 | Просмотр | 6 | Внешняя программа: `viewer` из конфига, по умолчанию `xdg-open`. Свой Lister — backlog |
| F4 | Правка | 6 | Внешний редактор, по умолчанию `cosmic-edit` |
| Shift+F4 | Создать файл и открыть в редакторе | backlog | |
| F5 | Копировать в другую панель (диалог с путём) | 5 | `/` на конце цели — «в каталог», он создаётся |
| Shift+F5 | Копировать в ту же папку под новым именем | backlog | |
| F6 | Переместить/переименовать в другую панель | 5 | |
| Shift+F6, F2 | Переименовать на месте | 5 | F2 — отличие от TC (там перечитать), так привычно в Linux |
| F7 | Создать папку | 5 | |
| F8, Delete | Удалить в корзину (с подтверждением) | 5 | В TC корзина зависит от настройки. У нас корзина по умолчанию |
| Shift+F8, Shift+Delete | Удалить безвозвратно (с подтверждением) | 5 | |
| Alt+F5 / Alt+F9 | Упаковать / распаковать | backlog | |
| Alt+F7 | Поиск файлов | backlog | |
| Ctrl+M | Групповое переименование | backlog | |
| Alt+Enter | Свойства | backlog | |
| Ctrl+C / Ctrl+X / Ctrl+V | Буфер обмена (совместимо с cosmic-files) | 09 | Вставка сразу, без диалога; после вставки вырезанного буфер очищается |

### Вид

| Клавиша | Действие | Фаза |
|---|---|---|
| Ctrl+F3 / F4 / F5 / F6 | Сортировка по имени / типу / дате / размеру | 2 |
| Ctrl+F1 / Ctrl+F2 | Вид Brief / Подробно | backlog |
| Ctrl+Q | Быстрый просмотр в другой панели | backlog |
| Ctrl+H | Показать/скрыть скрытые файлы | 6 |

У Ctrl+H нет прямого аналога в TC: так принято в Linux.
