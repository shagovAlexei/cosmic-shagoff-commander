# Total Commander: эталон поведения

Это источник истины для «как в TC». Колонка «Фаза» показывает, в какой фазе MVP (0–6) клавиша появляется. Пометка `backlog` значит «после MVP».

Если поведение отличается от TC намеренно, это записано в колонке «Примечание» с причиной.

## Раскладка окна (сверху вниз)

Две темы интерфейса (фаза 36, Ctrl+, → «Вид»): «Классический» (плотный, как TC; строка 20 px) и «Современный» (COSMIC: панели — карточки, строка 28 px, размеры в КБ/МБ). Раскладка, клавиши и логика одни; цвета — из темы COSMIC.


1. Меню (Файлы, Выделение, Команды, Сеть, Вид, Конфигурация, Запуск, Справка). Фаза 17: в заголовке окна Файлы, Выделение, Команды, Сеть, Вид; у пункта — его клавиша, пункт делает то же, что клавиша. Конфигурация — с окном настроек (backlog); Запуск и Справка — нет. Вход в меню с клавиатуры (F10/Alt в TC) — нет: виджет libcosmic не умеет.
2. Панель инструментов. Фаза 36: в теме «Классический» — кнопки с подсказками под меню (перечитать, подробно / кратко, скрытые, поменять панели, новая папка, поиск, сравнить каталоги, синхронизация, упаковать / распаковать, сеть, избранное, настройки); каждая — тот же `Action`, что и пункт меню. В «Современном» её нет.
3. Диски отдельно над каждой панелью, справа свободное и общее место на диске. «Классический» (36): выпадающий список дисков и кнопки `\` (корень) и `..` (вверх), как в TC; «Современный»: кнопки-«таблетки».
4. Вкладки панели.
5. Строка пути. У активной панели она подсвечена. Щелчок по части пути переходит туда, курсор — на папке, через которую шли (как в TC; фаза 47). «Классический»: обычный текст пути, части кликабельны. «Современный» (36): части — кнопки («хлебные крошки»).
6. Заголовки колонок: Имя, Тип (расширение), Размер, Дата, Атрибуты. Клик сортирует, повторный клик меняет направление. «Классический»: на полосе с разделителями, как кнопки TC.
7. Список файлов:
   - `[..]` всегда сверху;
   - папки в квадратных скобках `[name]`, в колонке размера у них `<DIR>` (после Space — размер);
   - размер от 1 ГБ — «45,1 ГБ» (колонка шире не становится; точно — в итогах строки состояния);
   - курсор — рамка или подсветка;
   - отмеченные файлы — красный текст.
8. Строка состояния: «0 k из 1 234 k, файлов: 0 из 15, папок: 0 из 3». У нас (фаза 24) — одна строка над F-кнопками, по половине под каждой панелью; в половине активной панели ещё сообщение или сведения о файле под курсором.
9. Командная строка `путь>`. Фаза 27: между строкой состояния и F-кнопками, скрывается в настройках. См. «Командная строка».
10. Ряд кнопок: `F3 Просмотр | F4 Правка | F5 Копия | F6 Перемещ. | F7 Каталог | F8 Удалить | Alt+F4 Выход`.

### Командная строка (27)

### Просмотр F3 (Lister)

Фаза 20. В TC — отдельное окно; у нас — на месте панелей в главном окне (меню и строка состояния остаются, F-кнопки скрыты).

| Клавиша | Действие | Примечание |
|---|---|---|
| ↑ ↓ PgUp PgDn Home End, ← → | Прокрутка | Строки длиннее 4096 символов режутся |
| W | Перенос строк по ширине окна | Фаза 32. По ширине на экране (табуляция — 4, широкие символы — 2), не по словам; при смене ширины окна строки переносятся заново. Кнопка «Перенос (W)» |
| A / S / K / 8 | Кодировка: ANSI (Windows-1251) / DOS (866) / KOI8-R / UTF-8 | Фаза 32. Как в TC (A, S); K и 8 — свои. Выпадающий список в строке Lister. Из hex переключает в текст; поиск ищет в перекодированном тексте. Перенос и выбранная вручную кодировка сохраняются при N / P. Фаза 35: файл без BOM, который не UTF-8, открывается в 1251 / KOI8-R / 866 — где больше строчных русских букв |
| 1 / 3 / 4 | Текст / hex / картинка | `2` (binary) из TC нет. При открытии: картинка по расширению (png, jpg, gif, bmp, webp, ico, svg), NUL в первых 8 КБ → hex, иначе текст (UTF-8, UTF-16 с BOM) |
| N / P | Следующий / предыдущий файл панели | Курсор панели тоже двигается; каталоги пропускаются |
| F7 | Поиск | Поле в строке Lister, Enter — вниз от верхней видимой строки, без учёта регистра; в hex — байты UTF-8 с учётом регистра |
| F3 / Shift+F3 | Найти следующее / предыдущее | Без запроса F3 открывает поле поиска |
| Esc, Q | Закрыть | Esc сначала закрывает поле поиска |

Буквы и цифры Lister привязаны к физическим клавишам, как остальные сочетания: работают в русской раскладке, но в AZERTY/Dvorak `Q` — это клавиша на месте латинской Q. Читается не больше 32 МБ файла (дальше — пометка). Нет: выделения и копирования текста, автоопределения кодировки, масштаба, печати, Ctrl+Q.

### Запись в архив

Фаза 21. zip, tar, tar.gz/bz2/xz/zst, 7z.

| Действие | Как | Примечание |
|---|---|---|
| F5 в архив | Другая панель в архиве или путь в диалоге ведёт в архив → файлы добавляются в этот каталог архива | Конфликт — тот же диалог «Заменить?» |
| F6 в архив / из архива | Добавить и удалить источники / извлечь и удалить из архива | Удаляется только то, что прошло без пропусков |
| F8, Shift+F8, Delete в архиве | Удалить записи | Всегда безвозвратно (корзины в архиве нет, как в TC); подтверждение говорит «безвозвратно» |
| F7, Shift+F6 / F2 в архиве | Папка / переименование | Имя уже есть — ошибка, архив не меняется |
| F4 в архиве | Извлечь во временный каталог, открыть редактор; раз в 2 с проверять файл, после сохранения — «Обновить архив?» | TC спрашивает после закрытия редактора; у нас редактор запускается отдельно, поэтому — по сохранению |

Архив переписывается целиком: распаковка рядом с ним, изменение, упаковка в тот же формат, замена одним переименованием. Отмена или ошибка оставляют прежний архив. Не сохраняются комментарий zip, настройки сжатия, владельцы записей tar, setuid/sticky, жёсткие ссылки; большой архив переписывается долго. Архив с записями, которые нельзя распаковать или упаковать обратно, и zip с именами в старой кодировке (cp866) не меняются — с объяснением.
