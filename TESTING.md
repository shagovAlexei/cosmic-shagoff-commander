# Тестирование

`just verify` = `cargo fmt --check` + `clippy -D warnings` + `cargo test`. Его запускаем перед каждым PR, CI запускает его же.

## Ручной чек-лист UI

Пункты добавляются по мере появления фаз.

- [ ] `cargo run -p shagoff-commander` открывает окно «Shagoff Commander»

### Фаза 2: две панели
- [ ] Старт: обе панели в `~`; `cargo run -p shagoff-commander -- /usr` открывает левую в `/usr`; несуществующий путь → `~`
- [ ] Tab переключает панель, подсветка строки пути и курсора меняется
- [ ] Tab ×5, затем Enter на папке: входит в папку, ни одна кнопка (Выход, закрыть окно) не срабатывает
- [ ] ↑↓ PgUp PgDn Home End; курсор не уходит за экран (проверить на `/usr/lib`)
- [ ] Enter на папке входит, на `..` выходит и ставит курсор на папку, из которой вышли; Backspace и Ctrl+PgUp — то же
- [ ] Enter на файле открывает его в программе по умолчанию
- [ ] Ctrl+\ → `/`, Ctrl+R перечитывает; оба работают в русской раскладке
- [ ] Ctrl+F3..F6 и клик по заголовку сортируют, повтор меняет ▲/▼, папки всегда сверху

### Просмотр F3 (20)

- [ ] F3 на двоичном файле — hex; на png/jpg/svg — картинка вписана в окно; `1` / `3` / `4` и кнопки переключают режим (`4` только у картинок)
- [ ] ↑ ↓ PgUp PgDn Home End, колесо, ← → на длинных строках
- [ ] F7, текст, Enter — строка подсвечена и прокручена в вид; F3 / Shift+F3 — следующее / предыдущее; нет совпадения — «Не найдено: …»
- [ ] N / P — соседние файлы панели, курсор панели тоже двигается, каталоги пропускаются
- [ ] Esc при открытом поле поиска закрывает поле, второй Esc — Lister; Q закрывает
- [ ] F3 на файле внутри архива — извлечение, затем Lister
- [ ] Файл больше 32 МБ — пометка «Показаны первые 32 МБ…»; FIFO — ошибка вместо зависания
- [ ] Настройки → «Встроенный просмотрщик» выключить: F3 запускает внешнюю программу
- [ ] Узкое окно (800 px, русский): кнопки переносятся, имя не ломается по буквам

### Запись в архив (21)

- [ ] F5 файла и каталога в панель, открытую внутри zip / tar.gz / 7z: появились в архиве; одноимённый файл — «Заменить?»
- [ ] F6 в архив — источники пропали; F6 из архива наружу — файл снаружи, из архива пропал
- [ ] F8 внутри архива — подтверждение «безвозвратно», запись пропала; Shift+F8 — то же
- [ ] F7 внутри архива — папка появилась (и вложенная `a/b`); имя уже есть — ошибка, архив не изменился
- [ ] Shift+F6 / F2 внутри архива — переименование
- [ ] F4 на файле в архиве: редактор открылся; сохранить — через 1–2 с «Файл изменён. Обновить архив?»; «Обновить» — изменение в архиве; «Отмена» — не спрашивает, пока не сохранить снова
- [ ] Отмена во время обновления большого архива — архив прежний, рядом нет `.shagoff-unpack.*`
- [ ] Ctrl+M, Ctrl+V внутри архива — «Архив только для чтения»
