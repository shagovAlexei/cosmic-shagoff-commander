# Тестирование

`just verify` = `cargo fmt --check` + `clippy -D warnings` + `cargo test`. Его запускаем перед каждым PR, CI запускает его же.

## Ручной чек-лист UI

Пункты добавляются по мере появления фаз.

- [ ] `cargo run -p shagoff-commander` открывает окно «Shagoff Commander»

### Фаза 2: две панели
- [ ] Старт: обе панели в `~`; `cargo run -p shagoff-commander -- /usr` открывает левую в `/usr`; несуществующий путь → `~`
- [ ] Tab переключает панель, подсветка строки пути и курсора меняется
- [ ] Tab ×5, затем Enter на папке: входит в папку, ни одна кнопка (Выход, закрыть окно) не срабатывает
- [ ] ↑↓ PgUp PgDn Home End; курсор не уходит за экран (проверить на `/usr/lib`)
- [ ] Enter на папке входит, на `..` выходит и ставит курсор на папку, из которой вышли; Backspace и Ctrl+PgUp — то же
- [ ] Enter на файле открывает его в программе по умолчанию
- [ ] Ctrl+\ → `/`, Ctrl+R перечитывает; оба работают в русской раскладке
- [ ] Ctrl+F3..F6 и клик по заголовку сортируют, повтор меняет ▲/▼, папки всегда сверху
- [ ] Клик ставит курсор и активирует панель, двойной клик = Enter, колесо прокручивает
- [ ] `/root` (нет прав): ошибка в строке состояния красным, панель осталась на месте
- [ ] Быстрые повторные Backspace: панель оказывается в последнем каталоге, без «прыжков»
- [ ] Длинные имена обрезаются «…», не переносятся; заголовки стоят над своими колонками
- [ ] Светлая и тёмная тема: курсор и строка пути читаемы
- [ ] «Alt+F4 Выход» закрывает окно, остальные F-кнопки неактивны

### Фаза 3: вкладки
- [ ] Одна вкладка — полосы нет; Ctrl+T — появилась полоса, новая вкладка справа от текущей, тот же каталог и курсор
- [ ] Ctrl+Tab / Ctrl+Shift+Tab переключают по кругу; клик по вкладке выбирает её и активирует панель
- [ ] Ctrl+W закрывает текущую; на последней ничего не происходит; средняя кнопка и двойной клик по вкладке закрывают
- [ ] Ctrl+T и Ctrl+W работают в русской раскладке
- [ ] Вкладка с `/usr/lib`, прокрученная вниз, и вкладка с `~`: при переключении у каждой своя прокрутка и курсор
- [ ] При 2+ вкладках в каждой из них ↓/PgDn за край экрана прокручивает список (курсор не уходит за экран)
- [ ] Во вкладках разных панелей каталоги независимы; Tab по-прежнему переключает панели
- [ ] Shift+Tab и Alt+Enter ничего не делают
