# Тестирование

`just verify` = `cargo fmt --check` + `clippy -D warnings` + `cargo test`. Его запускаем перед каждым PR, CI запускает его же.

## Ручной чек-лист UI

Пункты добавляются по мере появления фаз.

- [ ] `cargo run -p shagoff-commander` открывает окно «Shagoff Commander»

### Фаза 2: две панели
- [ ] Старт: обе панели в `~`; `cargo run -p shagoff-commander -- /usr` открывает левую в `/usr`; несуществующий путь → `~`
- [ ] Tab переключает панель, подсветка строки пути и курсора меняется
- [ ] Tab ×5, затем Enter на папке: входит в папку, ни одна кнопка (Выход, закрыть окно) не срабатывает
- [ ] ↑↓ PgUp PgDn Home End; курсор не уходит за экран (проверить на `/usr/lib`)
- [ ] Enter на папке входит, на `..` выходит и ставит курсор на папку, из которой вышли; Backspace и Ctrl+PgUp — то же
- [ ] Enter на файле открывает его в программе по умолчанию
- [ ] Ctrl+\ → `/`, Ctrl+R перечитывает; оба работают в русской раскладке
- [ ] Ctrl+F3..F6 и клик по заголовку сортируют, повтор меняет ▲/▼, папки всегда сверху
- [ ] Клик ставит курсор и активирует панель, двойной клик = Enter, колесо прокручивает
- [ ] `/root` (нет прав): ошибка в строке состояния красным, панель осталась на месте
- [ ] Быстрые повторные Backspace: панель оказывается в последнем каталоге, без «прыжков»
- [ ] Длинные имена обрезаются «…», не переносятся; заголовки стоят над своими колонками
- [ ] Светлая и тёмная тема: курсор и строка пути читаемы
- [ ] «Alt+F4 Выход» закрывает окно, остальные F-кнопки неактивны

### Фаза 3: вкладки
- [ ] Одна вкладка — полосы нет; Ctrl+T — появилась полоса, новая вкладка справа от текущей, тот же каталог и курсор
- [ ] Ctrl+Tab / Ctrl+Shift+Tab переключают по кругу; клик по вкладке выбирает её и активирует панель
- [ ] Ctrl+W закрывает текущую; на последней ничего не происходит; средняя кнопка и двойной клик по вкладке закрывают
- [ ] Ctrl+T и Ctrl+W работают в русской раскладке
- [ ] Вкладка с `/usr/lib`, прокрученная вниз, и вкладка с `~`: при переключении у каждой своя прокрутка и курсор
- [ ] При 2+ вкладках в каждой из них ↓/PgDn за край экрана прокручивает список (курсор не уходит за экран)
- [ ] Во вкладках разных панелей каталоги независимы; Tab по-прежнему переключает панели
- [ ] Shift+Tab и Alt+Enter ничего не делают

### Фаза 4: выделение
- [ ] Insert отмечает и идёт вниз; Space отмечает на месте; Shift+↓/↑ отмечают и двигают; `[..]` не отмечается
- [ ] Отмеченные строки красные; отмеченная строка под курсором — красная полоса; читаемо в светлой и тёмной теме
- [ ] Строка состояния: отмеченные байты/файлы/папки из общего числа
- [ ] Num+ → диалог «Выделить группу», `*.rs` выделяет только файлы `.rs`, папки не трогает; Num− снимает по маске
- [ ] В открытом диалоге стрелки/Insert/Tab не трогают панели, Escape закрывает, Enter применяет
- [ ] Num* инвертирует файлы; Ctrl+A и Ctrl+Num+ выделяют всё, включая папки; Ctrl+Num− снимает всё
- [ ] `+` на основной клавиатуре не открывает диалог; Ctrl+A работает в русской раскладке
- [ ] Ctrl+клик переключает отметку; отметки переживают сортировку и Ctrl+R; при смене каталога сбрасываются

### Фаза 5: файловые операции
- [x] F5: диалог с путём другой панели; копирует файл/отмеченные/папку с вложенными; права и дата сохранены
- [x] F5 на `..` без отметок — ничего; F5 папки в её же подпапку — ошибка в строке состояния, ничего не тронуто
- [x] Конфликт: диалог читаем; Заменить / Пропустить / Заменить все / Пропустить все / Заменить старые / Отмена работают
- [x] Большой файл (1+ ГБ): прогресс идёт, «Отмена» и Escape останавливают; заменяемый файл цел, `.shagoff-part` не осталось
- [x] F6 в каталог на том же диске — мгновенно; на другой диск (если `/tmp` и `~` на разных ФС) — копирование и удаление
- [x] Shift+F6 / F2 — переименование, курсор на новом имени; занятое имя → диалог конфликта
- [x] F7: `new`, `a/b/c` — создано, курсор на созданном
- [x] F8 / Delete — в корзину (видно в корзине COSMIC Files), подтверждение, Enter подтверждает
- [x] Shift+F8 / Shift+Delete — безвозвратно, красная кнопка; симлинк на папку удаляется без цели
- [x] После операции отметки сняты с обработанных, обе панели перечитаны
- [x] Нет прав (копировать из `/root` или в `/`) → диалог ошибки: Повторить / Пропустить / Отмена
- [x] Ctrl+T — новая вкладка без отметок
- [x] Во время операции клавиши панелей не действуют; кнопки F5–F8 внизу работают как клавиши

### История, избранное, обмен панелей (08)
- [x] Alt+←/→ ходят по каталогам вкладки; Ctrl+R и автообновление не добавляют записей; у новой вкладки (Ctrl+T) та же история

### Буфер обмена (09)

### Групповое переименование (10)
- [x] Ctrl+M на отмеченных файлах открывает диалог, в таблице «Было → Станет» все отмеченные; Ctrl+M работает на русской раскладке

### Архивы (11)

### Архив как папка (12)

- [x] Скрытые ищутся только при включённом Ctrl+H; симлинк-петля не зацикливает

### Сравнение и синхронизация (14)
- [x] Две копии каталога, в каждой свои правки: Shift+F2 отмечает в обеих панелях новые и изменённые файлы; на одинаковых каталогах — «Каталоги одинаковые» в строке состояния
- [x] Ctrl+Shift+S: список различий со стрелками; клик по стрелке → ← пропуск; итог внизу меняется
- [ ] «Синхронизировать» копирует в обе стороны; перед заменой существующего файла — диалог конфликта (Заменить / Заменить все / Пропустить); лишние не удаляются
- [x] «По содержимому»: файлы с разной датой и одинаковым содержимым — «=»; «Без учёта даты» сравнивает только размер
- [x] «С подкаталогами» выкл — только верхний уровень; Escape во время сравнения большого дерева закрывает
- [x] Ctrl+Shift+S, когда одна панель внутри архива, — «Архив только для чтения»
